## 1. 编码与对称性论证

### 1.1 模型、变量与归一化

与 `code/worst_case_lp.py`（冻结框架，本任务只 import 不改）以及
`results/H_F_partial_enumeration.py` 完全同一套：

- 变量：2^n 个 f(S) 与 2^n 个 f̃(S)（列号 S 与 N+S，N=2^n）。
- f 单调（f(S) ≤ f(S∪e)）、submodular（d_e(S∪e′) ≤ d_e(S)）、f(∅)=0；f̃ 任意、f̃(∅)=0。
- f̃ 只受 Definition 1 的 single-element 误差带约束：对**所有** S 与 e∉S，
  d_e(S)/η_u ≤ d̃_e(S) ≤ η_o·d_e(S)，η = η_u·η_o。**f̃ 不要求单调、不要求 submodular**（D1 原文）。
- 归一化：固定一个 K-子集 O，令 f(O)=1，目标 min f(输出集)，再对 O 取 min。
  （任一实例按 f(O\*) 归一后是 O=O\* 的 LP 的可行点；反之 LP 最优解的真实比
  ≤ 目标值，两个 min 相等。这是 `code/worst_case_lp.py` 的既有约定。）

行构造直接复用 `H_F_partial_enumeration.model_rows` 与 `LPBuilder`，因此本脚本与 H-F 的
LP 是逐行同一套模型；差别只在"算法路径"那几行。

### 1.2 两个候选的精确定义与查询审计

**候选 A（top-m shortlist，m = K+1）**
1. 查询 f̃({e})（= d̃_e(∅)）对全部 n 个元素；
2. 取 f̃({e}) 最大的 m 个元素组成 shortlist M（**tie 由对手挑**）；
3. 查询 M 的全部 C(m,K)=K+1 个 K-子集的 f̃；
4. 输出 argmax_{A∈binom(M,K)} f̃(A)（**tie 由对手挑**）。

查询数 n + K + 1，每次查询集合大小 ≤ K。审计：n+K+1 ≤ nK 对本文全部 (K,n) 成立
（最紧的是 K=2,n=4：7 ≤ 8）。**候选 A 落在 L1 的 𝒜_lin 内（Q = nK，size ≤ K）。**

**候选 B（predictive greedy + 单轮 swap pass）**
1. 从 ∅ 起跑 K 步 predictive greedy：状态 S 上加 argmax_e d̃_e(S)（**tie 由对手挑**），
   得 T_0 = (g_1,…,g_K)（按加入顺序编号 slot 1..K）。查询数 Σ_{t<K}(n−t) ≤ nK，大小 ≤ K。
2. 一轮 swap pass。**扫描表是固定的**：外层 slot p = 1..K（按加入顺序），内层
   e ∈ [n]\T_0（按元素编号升序）。在每对 (p,e) 上查询 f̃(T − T[p] + e)，其中 T 是**当前**集合；
   若该值大于 f̃(T) 则接受交换（T[p] ← e）。恰好 K(n−K) 次查询，每次集合大小恰为 K。
   若某个 e 在此刻已经在 T 内（早前被换进来），跳过该对、不查询。

查询数 ≤ nK + K(n−K) ≤ 2nK，大小 ≤ K。
**审计：候选 B 的查询数超过 L1 corollary 里写死的 Q = nK**（例如 K=3,n=7：18+12=30 > 21）。
它仍是线性预算，但要套用 L1 必须把 Q 换成 2nK：并集界里的失败概率翻倍，
显式条件从 n ≥ 4K⁵ 变成 n ≥ 8K⁵（其余不变）。**这一条要写进正文，不能含糊。**

`swap_mode` 的两种读法（TASKS7 原文是"接受交换并更新 T，**继续扫描**（单轮）"）：
- `continue`（**主结果**，逐字读法）：接受后继续扫描该 slot 的后续 e；
- `first`（备读法）：接受后直接跳到下一个 slot，每个 slot 至多换一次。
两者是**不同的算法**（`first` 的查询更少，因此约束更少），数值上 `first` ≤ `continue`，见 §3.3。

### 1.3 (η_u, η_o) 的拆分：本文取 (η, 1)

两个候选的**每一条决策都是两个 f̃ 值的比较**：shortlist 比 f̃({e})；最终 argmax 比 f̃(A)；
greedy 每步比 d̃_e(S) = f̃(S∪e) − f̃(S)，公共项 f̃(S) 抵消后仍是比 f̃(S∪e)；swap 检查比
f̃(T−t+e) 与 f̃(T)。把 f̃ 换成 c·f̃（c>0）不改变任何一个比较的方向与相等关系，
而 (η_u, η_o)-band 变成 (η_u/c, c·η_o)-band，乘积不变。所以**最坏值只依赖乘积 η**
（与 H-F §1 的 scaling 论证逐字相同）。

本文**故意取 (η_u, η_o) = (η, 1)**（而不是 H-F 的对称拆分 (√η, √η)）：η ∈ {1.25,1.5,2,2.5}
时 LP 的每个系数都是有理数，witness 的 Fraction 精确复核才有可能。
拆分不变性有数值旁证（Gate 3，§4.3）。

### 1.4 每条决策 → 弱线性不等式；adversarial tie 与"严格大于"的关系

- shortlist（候选 A）：对 e ∈ M、e′ ∉ M 写 f̃({e′}) − f̃({e}) ≤ 0；
- 最终 argmax（候选 A）：对 A ∈ binom(M,K) 写 f̃(A) − f̃(A\*) ≤ 0；
- greedy 第 t 步（候选 B）：对 e ∉ S_t、e ≠ g_t 写 f̃(S_t∪e) − f̃(S_t∪g_t) ≤ 0；
- swap 检查 (p,e)（候选 B）：**拒绝**分支写 f̃(T−t+e) − f̃(T) ≤ 0，**接受**分支写
  f̃(T) − f̃(T−t+e) ≤ 0。

全部是**弱**不等式，等号处两个分支同时可行，对分支取 min 即自动实现 adversarial tie。
对候选 A 这就是算法本身（argmax 在 tie 上本来就没规定选谁）。

**对候选 B 的 swap 检查要多说一句**：算法写的是"**严格**大于才接受"，等号处规则说拒绝，
本来没有 tie。用弱不等式编码等于给了对手额外权力，得到的是"tie-adversarial 版 swap 规则"的最坏值，
它是严格规则最坏值的**下界**。这个差别是**真实存在**的：把 argmin 的 LP 解重建成显式实例后，
在**该实例上**跑严格规则得到的比值明显更高（例如 K=2,n=6,η=2.5：LP 值 21/65 = 0.3231，
同一实例上严格规则得 0.5077，§4.4 全表）。

**但这只是"不在该点取到"，不是"下确界更高"。** 把接受分支改成带余量的
f̃(T−t+e) ≥ f̃(T) + ε（ε>0 时严格包含于"严格大于"），重跑得到 value(ε)，
在 6 个配置 × ε ∈ {1e−8, 1e−6, 1e−4} 上得到 value(ε) = value(0) + O(ε)（§4.5 表）。
即 **value(ε) → value(0) 当 ε→0+**，所以严格规则算法的最坏比的**下确界**就等于本文报告的数
（只是取不到，是 inf 不是 min）。近似比是 inf 意义下的保证，所以表里的数就是要的数。

### 1.5 对称性论证（分支削减）

**候选 A**：算法完全等变（两步都是 argmax，没有用到元素编号顺序）。对任意置换 σ，
实例 (f,f̃) ↦ (f∘σ⁻¹, f̃∘σ⁻¹) 保持 LP 的模型行不变，并把分支 (M, A\*) 映到 (σM, σA\*)、
把 O 映到 σO，LP 值不变。群在分支上传递，故可**固定 M = {0,…,K}、A\* = {0,…,K−1}**，
让 O 跑遍全部 K-子集。再用该分支的稳定子群 Sym({0..K−1}) × Sym({K}) × Sym({K+1..n−1})
把 O 降到轨道代表（按三个块各取多少个元素）。
原始分支数 C(n,K+1)·(K+1) 降到 4 ~ 7 个 LP。**Gate 2 验证：轨道代表与全 O 枚举同值**（§4.2）。

**候选 B**：greedy 阶段等变，但 swap 阶段用到了元素编号的升序，**不等变**。合法的削减是：
对任一实例，取 σ 把（对手选定的）greedy 轨迹 g_1,…,g_K 映到 0,1,…,K−1，
并把补集 [n]\{g} **保序**地映到 K, K+1, …, n−1。因为扫描表的内层顺序只用到**补集内部**的
相对顺序（跳过的对不产生查询），σ 后的算法在 σ 后的实例上的执行与原来逐字对应。
故可**固定 greedy 轨迹为 0→1→…→K−1、扫描表为 K<K+1<…<n−1**；
**O 仍须跑遍全部 C(n,K) 个 K-子集**（此时残余对称群平凡，因为 slot 有顺序、扫描表有顺序）。

### 1.6 分支定界（候选 B）

DFS 走扫描表。**结点界**：slot 0..p−1 的占据者在该结点之下**已经定死**（后面的 slot 不再碰它们），
所以子树里每个叶子的 T_final ⊇ B := {cur[0],…,cur[p−1]}；由 f 单调得 f(T_final) ≥ f(B)。
又结点的约束集是每个叶子约束集的子集（关于实例是松弛）。
两条合起来：**LP(结点约束, 目标 f(B)) 是整棵子树的合法下界**，≥ 当前 incumbent 就剪。
这一步只花 1 次 LP，在每个 slot 扫完时做一次。
（H-F 用的是 profile-free 松弛做界；这里因为目标集合随分支变化，用"已定死前缀 + 单调性"更直接。）

超时时的**合法下界**（profile-free 松弛，`candB_relax_lb`）：对任意 profile 都成立的两族行
(i) f̃(T_final) ≥ f̃(T_0)（接受的交换只会抬高 f̃）；
(ii) 对 slot 0 与每个 e ∈ 扫描表，f̃(T_0 − g_1 + e) ≤ f̃(T_final)
（考察 (0,e) 时当前集合是 T_0 的 slot 0 换成某个 c，所以 T_cur − c + e = T_0 − g_1 + e 与 c 无关；
无论接受还是拒绝，这个值都 ≤ 之后持有集合的 f̃，从而 ≤ f̃(T_final)）。
再对最终集合 m 与 O 取 min。

## 3. 逐配置讨论

### 3.1 候选 A：为什么这么差，以及一个闭式猜想

数值在两条线上，20 个配置（外加 §4.6 的 12 个额外点）**逐位相符** [CONJECTURE]：

```
候选 A 的精确最坏值 =  1/((K−1)η + 1)      当 n = 2K
                     =  1/(K η)             当 n ≥ 2K+1（已验到 n = 8）
```

- n=2K 支：K=2,n=4 的 4/9, 2/5, 1/3, 2/7 与 K=3,n=6 的 2/7, 1/4, 1/5, 1/6 全部命中；
- n≥2K+1 支：K=2 的 n=5,6,**7,8** 与 K=3 的 n=7,**8** 共 24 个点全部命中 1/(Kη)。

两条线正好是 U_K 与 L_K 的"**只算第一项**"版本：
U_K = 1−(1−x)^K（x = 1/((K−1)η+1)）而候选 A 在 n=2K 只拿到 x；
L_K = 1−(1−y)^K（y = 1/(Kη)）而候选 A 在 n≥2K+1 只拿到 y。
机制很清楚：**shortlist 是按单元素 f̃ 值挑的**，对手把 K+1 个"看起来最大、彼此完全重叠"的元素
（f 上互为副本，边际增益互相吃掉）顶到前 m 名，把真正的 O 全部挤出 shortlist；
第 4 步无论怎么选，输出集合的 f 值只相当于一个元素的贡献。n 从 2K 涨到 2K+1 时对手多一个
自由元素可用来做诱饵，值再降一档（从 1/((K−1)η+1) 降到 1/(Kη)），之后就不动了。

解释上要注意：**这不主要是预测误差的锅**。若上面的闭式成立，η→1 时它给
1/K（n ≥ 2K+1）与 1/K（n=2K 时 1/((K−1)+1)=1/K），远低于经典的 1−1/e；
也就是说"用单元素值筛 shortlist"这个规则本身对 submodular 目标就不成立。
不过 **η=1 没有直接算**（本任务的 η 网格从 1.25 起），上面这句话是从闭式外推的，
写进正文前需要补一次 η=1 的 LP。总之候选 A 作为"打败 greedy"的候选**已经出局**。

**禁止声称**：上面的闭式对 n > 8 或 K > 3 成立（未算）；对 m ≠ K+1 的 shortlist 大小成立
（只算了 m=K+1）；候选 A 的值等于 1/(Kη) 是"信息论下界"（它只是这一个算法的值）。

### 3.2 候选 B：n = 2K 处恰好持平，n 变大后不再持平并严格变差

| η | K=2, n=4 | n=5 | n=6 | ρ_2（n-free） |
|---|---|---|---|---|
| 1.25 | 2/3 = ρ_2 | 13/20 = 0.650000 | 34/55 = 0.618182 | 2/3 = 0.666667 |
| 1.5 | 3/5 = ρ_2 | 7/12 = 0.583333 | 11/21 = 0.523810 | 3/5 = 0.600000 |
| 2.0 | 1/2 = ρ_2 | 1/2 = ρ_2 | 2/5 = 0.400000 | 1/2 = 0.500000 |
| 2.5 | 2/5 = ρ_2 | 2/5 = ρ_2 | 21/65 = 0.323077 | 2/5 = 0.400000 |

| η | K=3, n=6（精确） | n=7 区间 [下界, 上界] | ρ_3（n-free） |
|---|---|---|---|
| 1.25 | 92/147 = ρ_3 | [0.594096, 0.696970] | 92/147 = 0.625850 |
| 1.5 | 9/16 = ρ_3 | [0.513043, 0.590909] | 9/16 = 0.562500 |
| 2.0 | 7/15 = ρ_3 | [0.402985, **4/9 = 0.444444**] | 7/15 = 0.466667 |
| 2.5 | 7/18 = ρ_3 | [0.325926, **16/45 = 0.355556**] | 7/18 = 0.388889 |

读法：

- **n = 2K：swap pass 完全没有作用（值恰为 ρ_K，K=2 与 K=3 各四个 η，八格全中）。**
  机制：ρ_K 的最坏实例本来就满足"任何一次 swap 在 f̃ 上都不严格变好"，对手可以让所有
  K(n−K) 次检查全部打平（弱不等式下取拒绝分支），swap pass 空转，输出仍是 greedy 集。
  反过来 swap pass 也没被对手用来变得更差，因为 n=2K 时补集只有 K 个元素，
  对手要同时维持 greedy 轨迹与"接受一个坏交换"两件事，可行域反而更紧。
- **n ≥ 2K+1：值随 n 非增，且在已算到的最大 n 上全部严格劣于 ρ_K**。
  精确说：K=2、n=5 在 η ∈ {1.25,1.5} 已经严格劣于（差 −0.0167），在 η ∈ {2,2.5} 仍恰为 ρ_2；
  再加一个元素到 n=6，四个 η **全部**严格劣于（差 −0.048 到 −0.100）。
  所以"n=2K 持平"不是 n-稳定的现象，而是 n=2K 特有的
  （K=2 的 η=2 一行：1/2 → 1/2 → 2/5）。
  机制（从 certificate 直接读）：多出来的元素让对手能造一个 e，使 f̃(T−t+e) ≥ f̃(T)（打平即可接受）
  但 f(T−t+e) ≪ f(T)。**swap 用 f̃ 判断"是否改进"，误差带允许 f̃ 打平而 f 掉下去**，
  于是单轮 swap pass 是**净损失**。这与 H-F 的机制诊断同源：
  "枚举/交换带来的候选收益"和"用 f̃ 做选择带来的损失"是两件独立的事，n 一大后者占优。
- **η 越大掉得越多**（K=2,n=6：η=1.25 掉 0.048，η=2 掉 0.100），符合"损失来自 f̃ 的分辨率"这一解释。
- **K=3, n=7 只在 η ∈ {2, 2.5} 上定了案**（上界 4/9 与 16/45 已在 ρ_3 之下），
  η ∈ {1.25, 1.5} 的区间跨过 ρ_3，**未定**。注意 K=3,n=7 的两个已定格子的上界
  4/9 与 16/45 恰好等于 H-F 的 PE_1 在 n=7（η=2）与 n=8（η=2.5）的精确值；
  这**只是数值巧合的观察，没有做任何结构对应的检查**，不要当结论用。

**禁止声称**：候选 B 在 n=2K 等于 ρ_K 这件事对 n>2K 也成立（**已被 n≥5 证伪**）；
候选 B 的值在 n→∞ 有下确界（[OPEN]，K=2 在 n=4→5→6 仍在降，没算更大的 n）；
"swap pass 一定有害"是逐实例的（比较的是最坏保证；在具体实例上 swap 常常有用）。

但报告值必须写明用的是哪一种。

### 3.4 n = 2K 处有没有重现 H-F 式的"小 n 超越"？

**没有。** H-F 的 PE_1 在 n=2K=6 上严格优于 ρ_3（19/29、1/2、2/5 对 9/16、7/15、7/18），
本任务的两个候选在 n=2K 上分别是"大幅劣于"（候选 A）与"恰好持平"（候选 B）。
差别在于**枚举的宽度**：PE_1 把 n 个起点的 greedy 轨迹全部放进候选池（查询数 ~ n²K/…，
远超线性），而候选 A 只看 K+1 个元素、候选 B 只做一轮局部交换。
**在"线性查询预算"这个限制下，n=2K 的小 n 便宜没有被吃到。**
这一条对 L3 的 open-problem 段有用：H-F 的小 n 超越**不是**线性预算内可复制的。
