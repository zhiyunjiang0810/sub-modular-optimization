## 二、Criterion D（对陈述本身的反例搜索）

搜索对象是 `app:hardness` 的 hardness family 本身：
F_O(S) = θ^{−1/2}[1 − a^x(1 − y/K)]，G_O(S) = 1 − a^{x+y}（y ≤ τ）或
1 − a^{x+τ}(K−y)/(K−τ)（y ≥ τ），a = 1 − 1/(θK)，θ = θ̄。
违反 legality 就是反例，所以每个抽到的配置都在整个 count grid 上精确检查九件事：
θ̄ ≥ 1 且 a ∈ (0,1)；归一化 F̄(0,0)=0、F̄(0,K)=1、0 ≤ F̄ ≤ 1；O\* = O（即
max_{x+y≤K} F̄ 在 (0,K) 取到 1）；f 单调（两个方向一阶差分 ≥ 0）；f submodular
（xx、xy、yy 三个二阶差分 ≤ 0）；G 单调且零真实增益的边上预测增益也为零；
edge 极值 rmax = A、rmin = 1/(θB) 在真实边上取到，η_o = √θ A ≥ 1、η_u = √θ B ≥ 1
（判定在平方后的有理式上做），乘积 η_u η_o = rmax/rmin **恰等于 η**；
值 F̄(K,0)/F̄(0,K) = 1 − a^K **恰等于** H_{K,τ}(η) 且等于 L_K(θ̄)，
并且 ≤ K 元、与 O 不交的输出中 balanced 输出（|T| = K）最大；
给定拆分 η_u η_o = η 时 rescaling β = η_o/(√θ A) 把两端恰好搬到 (1/η_u, η_o)。
