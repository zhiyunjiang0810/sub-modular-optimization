**"所有与 greedy 同阶复杂度的算法，有限 K 下都不能改善 ρ_K(η)"——目前还不能写成已证。** 但这次可以实质推进：修复 F3 的一般构造，得到一个**不限制查询集合大小、适用于所有线性查询算法、完全由解析证明支撑**的上界。它距离等号只剩一个关于 K 指数衰减的项，该项目前不能删掉。

## 1. 现在可以得到的简单结论

模型：value-oracle model，一次 G(S) 查询记一次操作，允许查询任意 S ⊆ N。固定有限 K, η，比较所有 O(nK) 查询算法在 n → ∞ 时的最坏近似保证，记其最优值为 α_lin(K,η)。随机算法按期望近似比计算。

对 K ≥ 3, η > 1：

ρ_K(η) ≤ α_lin(K,η) ≤ min{ 1/η, ρ_K(η) + 1/(K(e^{K−1} − K − 1)) }.   (1)

这是允许任意大小查询的结果。主文可写：Among algorithms with linear oracle complexity, predictive greedy achieves the optimal approximation ratio up to an additive term exponentially small in K.

更紧的解析上界 W_K(η)（§3.5）。例：K = 3, η = 3/2：

9/16 ≤ α_lin(3, 3/2) ≤ 523/928 = 9/16 + 1/928 < 2/3.   (2)

| 对象 | 近似比 |
|---|---|
| predictive greedy | 0.562500 |
| 所有线性查询算法的上界 | 0.563578 |
| unconditional 上界 | 0.666667 |

固定 K 时 1/928 不随 n 增大而消失。η ≥ K 时 ρ_K(η) = 1/η，该区间不可能有严格低于 unconditional bound 的类上界。

## 2. 为什么不能直接写成精确最优

目标 α_lin(K,η) = ρ_K(η)   (3) 需要新的数学结果。当前构造路线的解析障碍：为抵抗任意大小查询，希望 G 在所有 y ≤ 1 状态上只依赖集合大小；为达到 ρ_K，精确轨迹的最后一段须满足 d_t = g_t/η；在只依赖 (x,y) 的构造里，submodularity 使后续 d_x 非增，而全域不可区分性给出 g_{x+1} ≥ (η/(η−1))(g_x − d_x)；进入紧等式状态后这些约束迫使后续 g_x, d_x 一直保持为正常数；对有 coherence 阶段的精确轨迹，顶层 F(x,K) 又被迫保持为 1，于是 F(x,0) 不能无限线性增长。因此必须略微提高平台增益使尾部能合法结束，正的超额项由此产生。这没有否定 (3)，但说明"把原构造延长一点再令误差趋零"走不通。

## 3. 新上界的解析证明 — [HAND-PROOF-UNREVIEWED]

不枚举子集、不枚举算法、不依赖 LP 的数值最优性。

### 3.1 修正截断位置

ν = η/(η−1),  Ψ(t) = (Kη − t − 1)ν^t − K(η−1).
m = min{z ∈ ℤ_{≥1} : Ψ(z) ≤ 0}.   (4)

等价于某一元方程唯一正根的上取整：φ(t) = ν^{−t}Ψ(t) = Kη − t − 1 − K(η−1)ν^{−t} 严格凹，φ(0) = K−1 > 0，φ(t) → −∞，恰有一个正根。又因 ν^{η(K−1)} > e^{K−1} > K，得

η(K−1) < m < Kη.   (5)

设 B_m = η(ν^m − 1) − m,  d = (ν^m/K − 1)/B_m.   (6)

两个关键恒等式：
d − 1/(m+1) = −Ψ(m)/(K(m+1)B_m) ≥ 0,  1/m − d = νΨ(m−1)/(KmB_m) ≥ 0,
故 1/(m+1) ≤ d ≤ 1/m.   (7)
另有 d − 1/(Kη) = (m − η(K−1))/(KηB_m) > 0.   (8)

### 3.2 构造

取使 V_j 最小的最大整数 j：j = max{0, min{K−1, K+1−⌈η⌉}}。记 Q = q^j, D = Qd, T = j + m, C = k_1/K。

r_x = q^x (x ≤ j);  r_x = Q − (x−j)D (j < x ≤ T);  r_x = 0 (x > T).
g_x = q^x/K (x ≤ j);  g_x = ηD − (ηD − Q/K)ν^{x−j} (j < x ≤ T);  g_x = 0 (x > T).   (9)
令 a_x = r_x − g_x。取 H = η_u G：

F(x,y) = 1 − r_x (y = 0);  F(x,y) = 1 − ((K−y)/(K−1)) a_x (y ≥ 1).
H(x,y) = C − r_x − (η−1)a_x (y = 0);  H(x,y) = C − η((K−y)/(K−1)) a_x (y ≥ 1).   (10)

### 3.3 合法性为什么闭合

截断参数给出 r_T = g_T, 0 ≤ r_T ≤ D   (11)，故最后一步可合法接到零残差。线性阶段 g_{x+1} = ν(g_x − D)，且 a_x − a_{x+1} = g_{x+1}/η   (12)。由此逐项：
1. g_x 非负非增，a_x 非负非增。
2. r_x − r_{x+1} 非增：初始阶段递减，平台为 D，最后一步不超过 D。
3. a_x − a_{x+1} 非增（由 (12)）。
4. r_x − r_{x+1} ≥ a_x − a_{x+1} ≥ 0。
5. K g_x ≥ r_x：平台阶段 K g_{j+ℓ} − r_{j+ℓ} = ℓD − K(ηD − Q/K)(ν^ℓ − 1)   (13)，关于 ℓ 凹，ℓ = 0 处为零，ℓ = m 处为 (K−1)r_T ≥ 0，故整个区间非负。

这些性质给出 F 的全部 DR 不等式。误差带：p_x = r_x − r_{x+1}, u_x = a_x − a_{x+1}，

| 边 | ΔF | ΔH |
|---|---|---|
| x 方向, y = 0 | p_x | p_x + (η−1)u_x |
| x 方向, y ≥ 1 | ((K−y)/(K−1)) u_x | η ΔF |
| y 方向, y = 0 | g_x | g_x |
| y 方向, y ≥ 1 | a_x/(K−1) | η ΔF |

因 0 ≤ u_x ≤ p_x，ΔF ≤ ΔH ≤ η ΔF；两个误差端点在 x = 0 的正增益 O-边达到。F(∅) = G(∅) = 0, F(O) = 1, 0 ≤ F ≤ 1。

### 3.4 为什么允许任意大小查询

由递推 H(x+1,0) = H(x,1) 对所有 x ≥ 0 成立   (14)，故 G 在整个 y ≤ 1 区域只依赖集合大小；x > T 时 F, G 饱和。任何泄漏隐藏 O 的查询须同时满足 y ≥ 2 且 |S| ≤ T + K   (15)。一次固定查询的泄漏概率 ≤ K²(T+K)²/(2n²)；对 cnK 次查询累计 ≤ cK³(T+K)²/(2n) → 0   (16)。随后 canonical-transcript 归纳与平均论证。

### 3.5 上界与 greedy 的差

与 O 不交的 K-集价值 W_K(η) = 1 − Q + (K−j)Qd，故

W_K(η) − ρ_K(η) = (K−j)Q[m − η(K−1)] / (Kη[η(ν^m − 1) − m]).   (17)

利用 K−j ≤ η, η(K−1) < m < Kη, ν^m > e^{K−1}，对 K ≥ 3：

0 < W_K(η) − ρ_K(η) < 1/(K(e^{K−1} − K − 1)).   (18)

K = 3, η = 3/2：j = 2, m = 4, Q = 9/16, D = 117/928，W_3(3/2) = 523/928。

## 4. 原 F3 的一个问题必须同时修正

仓库 results/F3_hardness_full.tex 使用 m = ⌈Kη⌉ − 1，并非一般合法：K = 3, η = 667/500 时该公式给 m = 4，却得到 r_T = g_T = −151089222203006/81950355825200625 < 0，F 的 O-边际为负，单调性失败。修正条件 (4) 给出 m = 3，并由上述一般证明闭合。之前有限参数检查通过，不足以承担一般定理。

## 5. 对主文叙事的建议

两层：已闭合的精确结论（查询大小 ≤ K 的线性类，有限 K 最优最坏比恰为 ρ_K）；一般结论（任意大小查询时，所有线性查询算法的最优最坏比至多比 ρ_K 高一个指数小项，并在明确参数下严格低于 unconditional bound）。最值得继续攻的是消掉指数小项证明 α_lin = ρ_K，或找到一个具有严格更好最坏保证的线性算法；当前不能预设等号成立。
