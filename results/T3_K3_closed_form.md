## 主结果

定义（对每个 K，j = 0,…,K−1）：

    k1 = (K−1)η + 1,   q = (K−1)η / k1 = 1 − 1/k1,
    V_j(η) = 1 − q^j · (1 − (K−j)/(Kη)).

**闭式**：reduced LP（`code/reduced_lp.py`）的最优值在段 η ∈ [K−j, K−j+1] 上等于 V_j(η)（j ≥ 1），在 η ∈ [K, ∞) 上等于 V_0 = 1/η。分段点恰为整数 η = 2, 3, …, K。

**[VERIFIED-SYMBOLIC]（K = 2, 3, 4，全部 9 个段）**：每段给出显式 primal 解 x_j(η) 与显式 dual 解 y_j(η)，两者都是 η 的有理函数；sympy 精确验证（i）x_j 在整段可行且目标 = V_j，（ii）y_j 满足 Aᵀy = c（全部等式，因为 primal 全变量 > 0 时 complementary slackness 强制等式）、y ≤ 0 在整段成立、bᵀy = V_j。符号不等式用精确 Sturm 根计数证明（分子多项式在开区间内无根 + 内点符号 + 端点符号，无穷段用 Cauchy root bound 截断）。因此 LP 值 = V_j 在每段上是符号级精确结论。

### 一般 K 的统一猜想

**[CONJECTURE，数值 VERIFIED-LP 于 K=2..6 × 41 点]**：对所有 K ≥ 2、η ≥ 1，

    ρ_K^LP(η) = min_{0 ≤ j ≤ K−1} V_j(η)，min 在段 [K−j, K−j+1] 上由 V_j 达到。

max |LP − min_j V_j| = 8.9e−16（205 个测试点，K=2..6）。两个一般 K 的辅助恒等式已 [VERIFIED-SYMBOLIC]（对符号 K, j）：
- V_j = V_{j−1} 的唯一交点在 η = K−j+1（所以分段点是整数 2..K）；
- V_{K−1}(1) = 1 − (1−1/K)^K（η=1 退化为经典 greedy 值）。

推论（对 R5 的 conjecture "ρ_K = 1/η iff η ≥ K"）：在 reduced LP 层面，K ≤ 4 已符号证实
（[K,∞) 段等于 1/η；[K−1,K] 段的 V_1 = (K²−K+1)/(K((K−1)η+1)) 与 1/η 唯一交点在 η=K，且 η<K 时 V_1 > 1/η）；一般 K 归约为上面的统一猜想。

## 证书的结构（对偶支撑集模式）

primal 最优解（每段 j，对 i 对称，g_{t,i} = G_t）：
- t < j（"consistency 步"）：d_t = q^t/k1，G_t = q^t/K，约束 sum(t)、cons(t) 紧；
- t ≥ j（"prediction 步"）：d_t = q^j/(Kη)，G_t = q^j 冻结，pred(t)、mono(t)、cons(t) 紧。
这个 x_j 对**所有** η ≥ 1 都可行（脚本符号验证），所以 LP ≤ min_j V_j 对一般 K 也成立（模 LP 构造本身）；难的方向（LP ≥ V_j）就是每段的对偶证书。

对偶支撑集（对 i 对称化后，按 (type, t) 收缩）：
- 段 j（K=3 为例）：j=2: {sum(0),sum(1),sum(2), cons(0),cons(1), pred(2)}；j=1: {sum(0),sum(1), cons(0),cons(1), pred(1),pred(2)}；j=0: {sum(0), cons(0),cons(1), pred(0),pred(1),pred(2)}。
- 模式：段 j 恰有 j+1 个 sum 乘子（t=0..j）、cons(t) t=0..K−2、pred(t) t=j..K−1（K=2,3,4 均如此，见 `T3_K3_closed_form.json` 的 `dual_multipliers`，全部是 η 的低次有理函数）。
- 边界因子直接给出分段点：段 j 的最后一个 sum 乘子含因子 (η − (K−j+1))，段 j 的第一个 pred 乘子含因子 (η − (K−j))；两者在段内 ≤ 0、在端点为 0。
- j=0 段（η ≥ K）的乘子特别整齐：y_sum(0) = −1/η，y_cons(t) = −(K−1−t)/(K(η−1))，y_pred(t) = −(η−(K−t))/(K(η−1))。这是"1/η 不可超越"的 LP 版对偶证书，可以直接翻译成手写证明。

对偶乘子数值表（K=2,3,4 × η ∈ {1.25, 1.5, 2, 2.5}，非零乘子 + 约束标注 + strong duality gap）在 `results/T3_duals.json`。
