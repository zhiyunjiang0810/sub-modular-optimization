# P0 — 正确的 band 定义与可行性 LP（TASKS9，预算 2 小时）

**总状态：PASS（结论是负面的，但明确、可复现、可直接写进论文的 open-problem 段）。**

一句话：把"任意大小查询"真正需要的 O-无关要求写成 LP 之后，(x,y)-对称族**不是不可行，而是退化**——
LP 在全部 54 配置 × 2 个 band 版本上都可行，但最优值几乎处处恰为 `1/η`（R2 的平凡界），
最优解就是 R2 的 modular 实例 `f̃ ∝ |S|`。这一族在任意大小查询下能证明的最好常数是 `1/η`，
永远拿不到 `L_K(η)`，更拿不到 `1 − e^{−1/η}`。

四条结果，各有 oracle：

1. **可行性** [VERIFIED-LP，216 个 LP = 54 配置 × 2 band × 2 变体]：**没有一个配置不可行**。
   TASKS9 P0 预期的 "IIS 不可行" 没有出现。原因在 §4.1：LP 规格只要求 `F ≤ 1` 于 `x+y ≤ K`，
   并没有要求顶行 `F(·,K) ≡ 1`；放开顶行以后 modular 解 `F = x/(ηK) + y/K`、`G = (x+y)/(ηK)`
   对**任何** band 都可行且零泄露。
2. **退化** [VERIFIED-LP，54×2 = 108 个 spec LP]：106/108 的最优值**精确等于 `1/η`**；
   另外 2 个（K=6、η=1.5、c=2、hypergeometric band）低于 `1/η` 但仍远高于 `L_K`，
   n 推到 1152 时收敛到 0.630547（`1/η = 0.666667`，`L_K(1.5) = 0.506730`，`1 − e^{−1/1.5} = 0.486583`）。
   全部 108 个值都 **> `L_K(η)`**，即这一族证不出比平凡界更强的东西。
3. **IIS 证书与人话引理** [VERIFIED-LP 有限参数，11 份证书]：因为 LP 可行，IIS 取自
   "LP + 目标割 `F(K,0) ≤ v* − 10⁻³`" 这个不可行系统。最小的一份只有 **11 行**（K=3, n=48, c=2, η=2,
   proxy band），证书**单独**就能证出 `F(K,0) ≥ 1/η`（重解验证，§4.3）。人话引理见 §4.4。
4. **J5 检查** [VERIFIED-LP]：108/108 个可行解在 `|S| = n−1` 与 `|S| = n−2` 的全部成对比较上
   `G` 值**相等**（最大差 0.0），即 J5 的 `N∖{e}` 攻击与"所有 (n−2)-集合"攻击都失效。
   这是**定义使然而非发现**：两版 band 在 `s = n−1, n−2` 上都覆盖全部可行 `y`，
   所以 O-无关约束直接把这些点拴在同一个 `Ĝ(s)` 上。代价就是第 2 条的退化。

复现见 §6。数据：`results/P0_band_lp.json`（216 条记录 + band 宽度样例 + 大 n 探针）、
`results/P0_band_lp_iis.json`（11 份 IIS 证书，含 Farkas 乘子）。脚本：`results/P0_band_lp.py`。

## 1. 两版 band 的定义与逐 s 宽度

对大小 `s` 的查询 `S`，`y = |S ∩ O|` 服从 hypergeometric(n, K, s)，均值 `sK/n`。
可行 `y` 区间是 `[max(0, s−(n−K)), min(K, s)]`，两版 band 都与它取交。

- **(i) proxy**（TASKS9 原文）：`B(s) = {y : |y − sK/n| ≤ t·max(1, σ_s)}`，
  `σ_s = √(sK/n·(1−s/n))`，`t = √(2 ln Q)`，`Q = n^c`。
- **(ii) hyper**（transcript 并集界真正需要的）：`B(s)` = 以众数为中心、使
  `P[|S∩O| ∉ B(s)] ≤ 1/(4Q)` 的最小 `y` 集合，尾概率用**精确 hypergeometric**（`Fraction` 精确有理）。

两版在全部 18 个 (K,n,c) 上都是**连续区间**（`noncontiguous = 0`，脚本里逐点检查）。

## 2. LP 规格

变量 `F(x,y)`、`G(x,y)`（`0 ≤ x ≤ n−K`，`0 ≤ y ≤ K`），`Ĝ(s)` 自由（`s = 0..n`）。
`x = |S∖O|`、`y = |S∩O|`；`f = F_O`、`f̃ = G_O`。

1. **归一化 / O 是 argmax**：`F(0,0) = 0`，`F(0,K) = 1`，`F(x,y) ≤ 1` 对一切 `x+y ≤ K`。
   于是 `max_{|S| ≤ K} f(S) = f(O) = 1 = OPT`。
2. **单调**：`Δ_x F ≥ 0`（`x < n−K`）、`Δ_y F ≥ 0`（`y < K`）。
3. **submodular**（count-grid 充分条件，`lem:app-count` 的用法）：
   `Δ_x²F ≤ 0`、`Δ_xΔ_y F ≤ 0`、`Δ_y²F ≤ 0`，在全部有定义的格点。
4. **单元素 η 带**：对每条 x-edge 与 y-edge，`d = ΔF`、`d̃ = ΔG`，约束 `d/η ≤ d̃ ≤ d`。
   这是拆分 `(η_u, η_o) = (η, 1)`，与 L2 一致。**只有乘积重要**：把 `G` 换成 `βG` 使每个 `d̃` 乘 `β`，
   拆分变成 `(η/β, β)`，乘积不变；`Ĝ` 被同一常数缩放，仍然只依赖 `|S|`，不泄露 O
   （与 `app:hardness` 的 "prescribed split" 段同一句话）。
5. **O-无关（关键约束）**：`G(x,y) = Ĝ(x+y)` 对一切满足 `y ∈ B(x+y)` 的格点。

目标：`min F(K,0)`（算法输出 `T`、`|T| ≤ K`、`T ∩ O = ∅` 时的比值上界）。

规模：K=6, n=384 时 5691 个变量、26659 行；单个 LP ≤ 11 秒（HiGHS，`time_limit = 60`）。

### 2.1 两个变体

- **`spec`**：上面的规格，逐字按 TASKS9 P0。
- **`capped`**：额外要求 `F(x,y) ≤ 1` 于**每个**格点。配合 `F(0,K) = 1` 与单调性，
  这等价于强制顶行 `F(·,K) ≡ 1`，也就是**现有 (x,y) 族的形状**（`app:hardness` 的
  `F_O = θ^{−1/2}[1 − a^x(1 − y/K)]` 在 `y=K` 处对 `x` 平坦，F3 §0 已经记录过这条）。
  所以 `capped` 回答的是"**现有形状**在真 band 下还剩多少"。

### 2.2 一个约定

`Ĝ(0)` 没有被约束，LP 对 `G, Ĝ` 同时平移不变（只有差分进入约束）。
解里出现的 `Ĝ(0) = −8` 之类的值没有意义；`N4` 的 LP 里加过 `Ĝ_0 = 0`，加不加不改变任何结论。

```
F(x,y) = x/(ηK) + y/K ,      G(x,y) = Ĝ(x+y) = (x+y)/(ηK) + const ,      F(K,0) = 1/η .
```

逐条核对：`F(0,0)=0`、`F(0,K)=1`；`x+y ≤ K` 时 `F = (x/η + y)/K ≤ K/K = 1`（`η ≥ 1`）；
modular ⟹ 全部二阶差分 = 0 ⟹ 单调 submodular；x-edge 上 `d = 1/(ηK) = d̃`（带的上端取等），
y-edge 上 `d = 1/K`、`d̃ = 1/(ηK) = d/η`（带的下端取等）；`G` **处处**只依赖 `|S|`，
所以对**任何** band（包括"全部格点"）都满足 O-无关，零泄露。

这正是 `RESEARCH_STATE.md` 的 **R2**：`f̃(S) = c|S|`、`f(S) = c(|S∩B|/η_o + η_u|S∩O|)`，比值 `1/η`。
换句话说，**P0 的 LP 把 R2 的实例重新发现了一遍，并且证明在这个族里再没有更好的**。

顶行不平是关键：`F(x,K) = x/(ηK) + 1 > 1` 对 `x ≥ 1`。LP 规格（按 TASKS9 P0）只要求
`F ≤ 1` 于 `x+y ≤ K`，OPT 归一化只用到 `max_{|S| ≤ K} f = f(O) = 1`，所以顶行可以超过 1。
**这就是"预期的 IIS 不可行"没有出现的全部原因**：一旦额外要求 `F ≤ 1` 处处（`capped`），
顶行被压平，值立刻退到 1.0（见 §4.5）。

### 4.4 人话引理（A 类证书的翻译）

最小的那份证书（K=3, n=48, c=2, η=2, proxy band，11 行）逐行是：

```
norm     F(0,0) ≥ 0 ,  F(0,K) ≥ 1
band_lo  y-edge (0,y) → (0,y+1) ,  y = 0,1,2      : ΔG ≥ ΔF/η
band_up  x-edge (x,0) → (x+1,0) ,  x = 0,1,2      : ΔG ≤ ΔF
oind     G(0,K) = Ĝ(K)  与  G(K,0) = Ĝ(K)
objcut   F(K,0) ≤ 1/η − 10⁻³
```

三步推导（每一步都在证书里）：

1. 沿 `x = 0` 的一列把 `band_lo` 加起来：`G(0,K) − G(0,0) ≥ [F(0,K) − F(0,0)]/η ≥ 1/η`。
2. 沿 `y = 0` 的一行把 `band_up` 加起来：`G(K,0) − G(0,0) ≤ F(K,0) − F(0,0) = F(K,0)`。
3. 两条路径的终点 `(0,K)`（就是 `S = O`）与 `(K,0)`（就是一个与 `O` 不交的 K-集合 `T`）
   **同在第 K 层**，都在 `B(K)` 里，所以 `G(0,K) = Ĝ(K) = G(K,0)`
   （证书只用到其中两个单向不等式 `G(0,K) ≤ Ĝ(K) ≤ G(K,0)`）。
   把 1、2 接起来：`F(K,0) ≥ G(K,0) − G(0,0) ≥ G(0,K) − G(0,0) ≥ 1/η`。

> **引理 P0（[VERIFIED-LP 有限参数]，54 配置 × 2 band，11 份 IIS 证书）**
> 任何只依赖 `(|S∖O|, |S∩O|)` 的构造，若预测器在大小为 `K` 的典型集合上 O-无关
> ——形式地：`{0, K} ⊆ B(K)`，即 `G(O) 与 G(T)` 对某个与 `O` 不交的 K-集合 `T` 被同一个 `Ĝ(K)` 拴住
> ——则单元素 η 带迫使 `f(T)/f(O) ≥ 1/η`。于是这一族在任意大小查询下能证明的
> **最好常数就是 R2 的平凡界 `1/η`**，与 `K` 无关，永远达不到 `L_K(η)`，更达不到 `1 − e^{−1/η}`。
> 数值上这个下界在 54 个配置里被 LP **取到**（modular 解，§4.1），所以 `1/η` 是紧的。

`{0, K} ⊆ B(K)` 只是**充分**条件：18 个 (K,n,c,band) 组合里只有 6 个满足它，
但 LP 在 52/54 格上仍然给出恰好 `1/η`（B 类证书走更长的链）。
这条"充分不必要"必须写清楚，不能说成"当且仅当"。

尺度注记：把 `G` 换成 `βG` 只把拆分从 `(η, 1)` 移到 `(η/β, β)`，乘积 `η` 与上面每一步都不变，
所以引理与 `η` 的拆分方式无关。

### 4.5 TASKS9 预期的那条链：它在 `capped` 变体里逐字成立

TASKS9 预判的机制是"band 在中等 s 覆盖全部 y ⟹ `G` 在 `y=K` 整行 O-无关 ⟹
x-edge 带约束把 `Ĝ` 拴死在 `F(·,K)` 上"。在 `spec` 里它不成立（顶行可以不平），
在 `capped` 里它**逐字成立**，并且 LP 值 = 1.0 把它量化了。逐步写出来（K=3, n=48, c=2, η=2,
proxy band，16 行 IIS，证书单独证出 `F(K,0) ≥ 1`）：

1. `F ≤ 1` 处处 + `F(0,K) = 1` + 单调 ⟹ **顶行平坦**：`F(x,K) = 1`，`Δ_x F(x,K) = 0` 对一切 `x`。
2. proxy band 在 K ≤ 4 时每层满覆盖（§1.2），所以顶行的每个点都在 band 里，
   顶行的每条 x-edge 两端都被 O-无关约束拴住 ⟹
   `Ĝ(s+1) − Ĝ(s) = ΔG = 0` 对一切 `s ≥ K`（`band_up` 给 `ΔG ≤ ΔF = 0`，`band_lo` 给 `ΔG ≥ 0`）。
   **`Ĝ` 被顶行拴死成常数**。
3. 第 `s ≥ K` 层上任何其它被 band 覆盖的边 `(x,y) → (x+1,y)` 或 `(x,y) → (x,y+1)`
   也共享同一个增量 `Ĝ(s+1) − Ĝ(s) = 0`（两个邻居的 `|S|` 都是 `s+1`），
   于是 `band_lo` 给 `ΔF ≤ η·0 = 0`：**第 `s ≥ K` 层出发的每条边的真实边际都是 0**。
4. 于是 `F` 在"第 K 层及以上"整片是常数。特别地
   `F(K,0) = F(K,1) = … = F(K,K) = F(K−1,K) = … = F(0,K) = 1`
   （先沿 `x=K` 走 y-edge，再沿 `y=K` 走 x-edge，每条边都在第 ≥ K 层）。
   **`F(K,0) = 1`，构造什么都证不出来。**

LP 值在全部 proxy/capped 格上恰为 1.0，与这条链一致（K=6、c=2 的几格例外，那里
proxy band 不满覆盖，第 2 步断掉，值落在 0.46–0.73，仍然 > `1/η`）。
这一段就是 P3 的 "why it is hard" 素材：**旧族的平顶不是可以修补的细节，
它在真 band 下直接把 `Ĝ` 拴成常数，再把 `F` 拉平。**

### 4.6 两版 band 的结论一致性

- `spec` 变体：52/54 格两版给出同一个数；2 格不同（§3.1），**方向是 hyper 更宽松**，
  但极限值 0.630547 仍远高于 `L_K`。**没有出现"一版可行一版不可行"的情况**（都可行）。
- `capped` 变体：两版差别很大（proxy 恒 1.0，hyper 0.402–1.0）。
  原因是 proxy 的 `t = √(2 ln Q) ≥ 3.9` 在 K ≤ 4 时超过整个 `y` 量程，band 失去内容（§1.2）。
  **结论：TASKS9 原文的 proxy band 在 K ≤ 4 上不可用**，做这类问题必须用 (ii)。

## 7. Caveats / 未完成 / 卡点

1. **没有出现不可行**，所以 TASKS9 预期的"IIS 不可行引理"不存在。交付的是等价强度的
   "目标割 IIS"（下界证书）。这是规格与预期的偏差，需要人工确认这个替代物可接受。
2. `K=6, η=1.5, c=2, hyper` 这一格在 TASKS9 给定的 n ≤ 64K 范围内**未收敛**（§3.1）。
   补跑了 n = 768, 1152 才看到极限。其它格不需要，因为它们已经贴着上界 `1/η`。
3. 引理 P0 只有有限参数的 LP 证据；`{0,K} ⊆ B(K)` ⟹ `F(K,0) ≥ 1/η` 的三步推导本身是手写的
   （§4.4），三步都短，但没有符号 oracle 跑过一般 `(K, η)`。
4. 只测了拆分 `(η_u, η_o) = (η, 1)`。尺度论证（§2 第 4 条）说只有乘积重要，
   但**没有**用 LP 重跑 `(√η, √η)` 复核。
5. 全部是网格（对称化）LP，没有做全格点 oracle 交叉验证（T2 曾在 (n,K) = (8,3) 上验证过
   symmetrization 在 relaxF 模式下正确；这里沿用）。
6. `capped` 变体的 §4.5 四步链只在 K=3 的 16 行 IIS 上逐行对照过；K=4、K=6 的 capped IIS 没跑
   （时间预算）。K=6、c=2 的 capped 值不是 1.0，说明第 2 步在那里断掉，与链一致，但没有证书。
7. **一个配置的 IIS 没跑出来**：`K=3, n=96, c=2, hyper, spec` 的 `v*` 被 HiGHS 报成
   0.500000010（`1/η` 的浮点噪声），加上 `v* − 10⁻³ = 0.499` 的割之后 HiGHS **没有**判成
   infeasible，于是这个配置被跳过，交付的是 11 份而不是 12 份证书。这是数值伪影
   （割值 0.499 明显低于真值 0.5），不是新的可行解；但没有用精确算术复核，记录备查。
   IIS 配置表里其余 11 个都正常。
8. 脚本在 `iis` 模式下曾有一个解包 bug（`iis()` 在系统可行时返回 3 元组而调用处按 4 元组解包），
   已修复并把余下配置补跑完。没有卡点超过 45 分钟。
9. 目标割用的是 `v* − 10⁻³` 的绝对偏移。`η = 3` 时 `v* = 1/3`，偏移相对值 0.3%，
   除第 7 条那一格外 HiGHS 没有报数值问题，但更严谨的做法是精确有理算术，本晚没做。
