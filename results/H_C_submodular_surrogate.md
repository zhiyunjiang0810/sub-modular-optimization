> **[VERIFIED-LP]** 对每个 K ≥ 2、每个 m ∈ {0,…,K−1}、每个 η ≥ 1 与每个拆分 η = η_u·η_o，
> §6 的显式实例（n = 2K，single-element 误差，对抗 tie）满足 f 与 f̃ 都单调 submodular、

>
> **[CONJECTURE，未升级]** 反向不等式 ρ_K^sub(η) ≥ min_m W_m(K,η) 仍无证书。

## 3. 最优解的紧约束结构与 W_m 的符号推导（Part E）

从 F4 的 LP 最优解（`F4_details.json`）读出的量：沿 greedy 轨迹记 d_t、d̃_t 为被选元素的真实／预测增益，
G_t、G̃_t 为 O 元素在 S^t 处的真实／预测增益（LP 最优解里 K 个 O 元素逐点相等），并引入

    A_t := f̃(S^t ∪ O) − f̃(S^t)      （"predicted residual coverage"）

在 K=4, η=2（m\*=2）处，最优解满足下列**等式**（逐条数值核对，偏差 ≤ 1e−9）：

| 关系 | 名称 | 成立范围 |
|---|---|---|
| A_t = K·d̃_t | greedy 打平 + f̃ submodularity 的 telescoping | t = 0,1,2 |
| A_{t+1} = A_t − d̃_t | f̃ 单调 | t = 0,1 |
| d̃_t = η_o·d_t | band 上界（被选元素） | 全部 t |
| A_m = (1 − Σ_{s<m} d_s)/η_u | band 下界 + f 的 coverage，在 t = m 处 | t = m = 2 |
| d_t = d_m | prediction 步冻结 | t ≥ m |

把这五条当作等式解出来（sympy，K、m、η_u、η_o **全部是自由符号**）：

    A_t = A_0 r^t,   A_0 = η_o / (1 + (η−1) r^m),   d_t = r^{min(t,m)} / (K (1 + (η−1) r^m)),
    Σ_{t<K} d_t = (K − m r^m) / (K (1 + (η−1) r^m)) = W_m(K, η).

**[VERIFIED-SYMBOLIC]** `value − W_m` 被 sympy 精确化简为 0（Part E1）；A_0 的闭式（E2）；
且这个值只通过乘积 η = η_u η_o 依赖于拆分（E3）。

这把 F4 §3 的"从数值边际增益表读出的规律"升级为**从一组有名字的等式出发的精确推导**。
但要说清楚：这些等式里有两条（A_t = K d̃_t、A_{t+1} = A_t − d̃_t）在有效不等式里的方向分别是
"A_t ≤ K d̃_t" 与 "A_{t+1} ≥ A_t − d̃_t"，**方向对下界证明不利**（前者给 d̃ 的下界要配 A 的下界，后者只给 A 的上界）。
所以 §3 是**上界方向**的机制说明，不是下界证明。这正是 §5 卡点的根源。

## 5. 卡点：路径变量层面的 reduced LP 太弱（Part D，负结果）

按 F4 §9 的第 1 条，本任务写了新模型的候选 reduced LP（`reduced_sub`，变量 O(K²)）：

变量（全部 ≥ 0）：d_t、d̃_t（t < K），g_{t,i}、g̃_{t,i}（t ≤ K，i < K），A_t（t ≤ K）。约束**逐条都是有效不等式**：

| 名称 | 不等式 | 来源 |
|---|---|---|
| cover_f | Σ_i g_{t,i} ≥ 1 − Σ_{s<t} d_s | f submodular + 单调，f(O)=1 |
| pred | g_{t,i} ≤ η d_t | band + greedy |
| mono | g_{t+1,i} ≤ g_{t,i} | f submodular |
| cons | g_{t,i} ≤ d_t + (1−1/η) g_{t+1,i} | coherence lemma R3(ii) |
| band_d / band_g | d_t/η_u ≤ d̃_t ≤ η_o d_t；g_{t,i}/η_u ≤ g̃_{t,i} ≤ η_o g_{t,i} | 单元素误差带 |
| greedy | g̃_{t,i} ≤ d̃_t | 算法按 f̃ 选，对抗 tie |
| **sub_gg / sub_dd** | g̃_{t+1,i} ≤ g̃_{t,i}；d̃_{t+1} ≤ d̃_t | **f̃ submodular（新）** |
| **Aup** | A_t ≤ Σ_i g̃_{t,i} | **f̃ submodular（新）**，telescoping |
| **Amono / Adrop** | A_{t+1} ≤ A_t；A_{t+1} ≥ A_t − d̃_t | **f̃ submodular / f̃ 单调（新）** |
| **Alo_f / Alo_ft** | A_t ≥ (1 − Σ_{s<t} d_s)/η_u；A_t ≥ 1/η_u − Σ_{s<t} d̃_s | band 沿链求和 + f 单调 |

在 K ∈ {2,3,4,5,6,8} × η ∈ {1, 1.25, 1.5, 2, 2.5, 3, 4} 的 42 个点上解这个 LP：

> **[VERIFIED-LP] 42/42 点的最优值恰等于 min_j V_j**（原模型的值），其中只有 19 个点碰巧也等于 min_m W_m
> （即那些两个闭式本来就重合的点）。例如 K=4, η=2：reduced_sub = 0.448979592 = 22/49 < 23/50 = min_m W_m。

也就是说：**上面这批"看起来该有的"f̃-submodularity 有效不等式，一条也没有提高路径变量层面的下界。**
显式的原因（把 base 模型的最优路径解代进去检查即可）：base 最优解取 A_t = (1 − P_t)/η_u 就同时满足 Aup、Amono、Adrop
与两条 Alo，因为 Adrop 恰好等价于 band 下界 d̃_t ≥ d_t/η_u。新块在这套变量里是**可满足的**，所以不切割。

**卡点一句话**：在全格点 LP 里，f̃ 的 submodularity 真正咬合的地方涉及**同时含多个 O 元素、又含部分 B 元素**的格点
（§4.4 的支撑就落在那里），而这些量在"沿 greedy 轨迹 + 单个 O 元素"的路径变量里根本没有名字。
要写出新模型的 reduced LP，必须先找到正确的二指标聚合变量（候选：f(S^t ∪ Y)、f̃(S^t ∪ Y) 按 |Y| 聚合，
再加 B 元素在这些状态上的增益），本任务在 45 分钟的时限内没有做出来。

## 6. 显式实例族：ρ_K^sub ≤ min_m W_m 的一般 K 证据（Part F，本任务的主结果）

把 §3 的紧约束系统"反解"回一个显式实例。基础集 n = 2K：B = {b_0,…,b_{K−1}}（greedy 按下标顺序选），
O = {o_0,…,o_{K−1}}。给定 K、m ∈ {0,…,K−1}、η = η_u η_o ≥ 1：

    r = 1 − 1/K,      D = 1 + (η−1) r^m,      A_0 = η_o / D,
    d_t = r^{min(t,m)} / (K D)          (t = 0..K−1),
    cut(S) = Σ_{t < m, b_t ∈ S} d_t,    y = |S ∩ O|,

    f(S)  =        Σ_{b_t ∈ S} d_t  + (y/K)·(1   −      cut(S))
    f̃(S) = η_o·Σ_{b_t ∈ S} d_t  + (y/K)·(A_0 − η_o·cut(S))

结构说明：两者都是"B 上的 modular 部分 + 一个 y 与 cut(S) 的双线性耦合项"，
耦合项 −(y/K)·cut(S) 是两个非负 modular 函数乘积的相反数，因而 submodular；
**只有前 m 个被选元素（coherence 步）压低 O 元素的增益，后 K−m 个（prediction 步）不压**。

它满足（逐条可手算，脚本用 F4 的 `verify_instance` 独立复核）：

- f(∅) = f̃(∅) = 0；两者都单调 submodular（f̃ 的 submodularity 违反量 ≤ 5.6e−16）；
- 单元素误差**恰好**是 (η_u, η_o)：B 元素的比值恒为 η_o；O 元素的比值 (A_0 − η_o·cut)/(1 − cut) 随 cut 从 A_0 单调降到 **1/η_u**，
  在 cut = Σ_{t<m} d_t 处取到；乘积恰为 η；
- greedy 在每一步与 O 元素**恰好打平**（预测 O 增益 = A_0 r^{min(t,m)}/K = d̃_t），对抗 tie 下依次选 b_0..b_{K−1}；
- OPT = max_{|S|≤K} f(S) = f(O) = 1；
- 比值 f(S^K)/f(O) = Σ_t d_t = **W_m(K, η)**。

验证规模：

| 检查 | 覆盖 | 结果 |
|---|---|---|
| F1 对称拆分 η_u = η_o = √η | K ∈ 2..6 × 全部 m × η ∈ {1, 1.1, 1.25, 1.5, 2, 2.5, 3, 4, 6, 10} | **200/200 PASS**，max|比值 − W_m| = 2.2e−16 |

| F4 复现头条值 | (3,1.5)→19/33、(4,1.5)→23/41、(4,2)→23/50、(5,1.5)→433/785、(5,2)→93/205 | 5/5 精确 |

三点含义：

1. **上界方向对一般 K 有了构造。** F4 只有 12 个 LP 顶点作为见证，且没有公式；现在有 (K, m, η) 的闭式族。
   这正是 F4 §9 第 2 条列的任务。
2. **K=5 的三个数不再只是 LP 数值。** F4 §6.1 把它们记成"不相交 O 上的值，严格说是 ρ_5^sub 的上界"；
   现在它们各有一个显式实例达到，"≤"这一侧不再依赖那次退路。
3. **U_K 失效有了实例背书**（推论 A）。29 个网格点 (K ∈ {4,5,6,8,12,20}, η ∈ {1.25,…,4}) 上 min_m W_m > U_K，
   其中 K ≤ 6 的点都能直接用本族的实例见证。

**这个族不能证下界。** 它只说明 ρ_K^sub ≤ W_m 对每个 m 成立。相等还需要 §5 的另一半。
