## 1. 闭式（一句话版本）

`(F, Ghat, G)` 的形状**就是 N4 的闭式**（相位 1 几何 + 相位 2 常数-`d` 尾巴 + 饱和），
Q1 的新内容是**把 `D` 的选择写成 grid 宽度 `X = n - K` 的函数**，于是得到有限 n 的值：

```
k1 = eta(K-1) + 1,   q = 1 - 1/k1,   nu = eta/(eta-1),   j = K + 1 - ceil(eta)
D(m)   = q^j (nu^m/K - 1) / ( eta(nu^m - 1) - m )                 m >= 1
D_base = q^j / (K eta)                                            （尾巴不收口）
D^(X)  = max{ D_base,  max_{1 <= m <= X-j} D(m) },   m^(X) = argmax（取不到则记 None）
T      = j + m^(X)      （m^(X) = None 时 T = +infinity，尾巴在网格边缘被截断）

rho_K^{(n)}(eta) = F(K,0) = 1 - q^j + (K-j) D^(X),      X = n - K
```

序列（`r_x = 1 - F(x,0)`，`g_x = Delta_y F(x,0)`，`d_x = Delta_x F(x,0)`）：

```
0 <= x <= j :   r_x = q^x,                       g_x = q^x / K
j <  x <= T :   r_x = q^j - (x-j) D,             g_x = nu^{x-j} q^j/K - eta D (nu^{x-j} - 1)
x  >  T     :   r_x = 0,                         g_x = 0
d_x = r_x - r_{x+1}   (= q^x/k1 在相位 1，= D 在相位 2，= r_T 在 x = T，= 0 之后)
```

网格函数（split `(eta_u, eta_o) = (eta, 1)`）：

```
F(x,y)   = 1 - r_x                                              y = 0
         = 1 - r_x + g_x + (y-1)(r_x - g_x)/(K-1)               y >= 1
Ghat_s   = (1/eta) sum_{x < s} g_x
         = k1 (1 - q^s) / (K eta)                               s <= j+1
         = [ k1(1-q^{j+1})/K + eta(q^j/K - eta D)(nu^M - 1) + eta D M ] / eta,  M = s-j-1,
                                                                 j+1 <= s <= T+1
         = k1 / (K eta)                                          s > T+1  （见第 4 节的不变量）
G(x,y)   = Ghat_{x+y}                                            y <= 1  （balanced，O-无关）
         = Ghat_{x+1} + ( F(x,y) - F(x,1) )                      y >= 2  （eta_o = 1）
```

极限与超额：

```
n -> infinity:  m^(X) -> m* = ceil(eta K) - 1  [CONJECTURE]，  T -> j + m*
W_K(eta) := lim_n rho_K^{(n)} = V_j(eta) + (K-j)( D(m*) - q^j/(K eta) )  >  V_j(eta)
V_j(eta) = 1 - q^j(1 - (K-j)/(K eta))                       （T6 的段值）
```

## 2. 猜测过程（怎么从数据读出来的）

1. 先看 canonical 顶点的 `d_x = Delta_x F(x,0)` 序列。K=4, eta=5/2, n=32 给出
   `0.117647, 0.103806, 0.078348 × 9, 0.073412, 0, 0, ...`。
   前两项正好是 `1/k1` 与 `q/k1`（`k1 = 8.5`），平台长度 9 = `ceil(eta K) - 1 = m*`，
   平台后是一个比平台略小的收口步，然后全 0。这与 N4 §3 的三相位描述逐字一致，
   所以**不是重新猜，而是确认 N4 的闭式在 `ysmall` + split `(eta,1)` 下仍然逐点成立**。
2. `ghat(x) = Ghat_{x+1} - Ghat_x` 与 `g_x/eta` 逐点相等，`Delta_x F(x,1)` 与
   `ghat(x+1)` 逐点相等。这两条把 `Ghat` 完全定死（不需要额外猜）。
3. `F(x,y)` 在 `y >= 1` 上线性、`F(x,K) ≡ 1`、`F(0,y) = y/K`，从顶点表直接读出。
4. **n 规律**是本夜的新东西。N4 只报告了"`X >= T` 后不变、`X < T` 时掉下去"。
   把 `D` 的定义改成"在网格允许的 `m <= X - j` 范围内取 max"之后，
   有限 n 的值就完全对上了（第 3 节）。直观：相位 2 的尾巴需要 `m` 列才能收口，
   网格放不下就只能不收口，此时最优 `D` 退回 `D_base`，值退回 `V_j`。
5. 由此**预测**（并被 LP 确认）：`rho_K^{(n)}` 是关于 n 的**阶梯上升**函数，
   离开 `V_j` 的第一个 n 是 `K + j + m_0 + 1`（`m_0 = max{m : D(m) <= D_base}`），
   饱和于 `n = K + T`。

### 3.4 导出表达式的符号自检（G 节，[VERIFIED-SYMBOLIC]）

两条 sympy 恒等式，一般 `(K, j, eta)`：

```
objective |_{D = q^j/(K eta)}  -  V_j(eta)  = 0
lim_{m -> infinity} D(m)  -  q^j/(K eta)    = 0
```

第一条说明"尾巴不收口"的分支**精确地**落在 `V_j`（这就是 `n` 小时 LP 值 = `rho_K` 的
代数原因）；第二条说明 `D(m)` 的 `m -> infinity` 极限就是 `D_base`，
于是超额项只能来自有限 `m` 的峰值。

## 4. 附带发现：`sum_x g_x = k1/K`（F 节）

8 组 `(K, eta)` 精确有理验证通过：`g` 的总和与尾巴细节无关，恒为 `k1/K`，
于是 `Ghat` 的饱和值恒为 `k1/(K eta)`，不含 `D`、`m`。
[EXACT 8/8]，一般 `(K, eta)` 的符号证明留给 Q2（应当由相位 2 的 coherence 递推
`g_{x+1} = eta (g_x - d_x)/(eta - 1)` 求和 + 打靶条件 `g_T = r_T` 得到）。

## 5. 失败与不确定处（如实标注）

1. **`j <= 1`（`eta > K-1`）：闭式不是最优解，只是可行上界。** [FAILED]
   实测差距：`(K,eta) = (3,5/2)` 闭式 0.394458 vs LP 0.393006（+1.5e-3）；
   `(3,29/10)` 0.348926 vs 0.344122；`(4,7/2)` 0.284481 vs 0.283756；
   `(3,7/2)`、`(4,9/2)`（`j = 0`）LP 恒为 `1/eta`，闭式高出 1e-2 量级。
   N4 §3 已把 `eta > K-1` 列为已知不匹配区（3/42 点），本夜在 `ysmall` + split `(eta,1)`
   下复现，并补充：`j = 0` 时 LP 值**完全不依赖 n**，等于 `1/eta = V_0 = rho_K`。
   **对 Q2 的建议定义域是 `2 <= j <= K-1`（`eta <= K-1`）**，与 TASKS10 写的
   `1 <= j <= K-1` 不同。`j = 1` 段的正确闭式**未知**，这是 Q3 的一个候选卡点。
2. **`m* = ceil(eta K) - 1` 仍是 [CONJECTURE]**（N4 的 264 点数值 + 本夜的 49 点 n 扫描）。
   本夜的实现不依赖这个公式（`params()` 直接对 `m` 暴力取 max），所以数值结论不受影响；
   但 Q2 若要写成"`m*` 的闭式"，需要证明 `D(m)` 关于 m 单峰且峰值在 `ceil(eta K) - 1`。
3. **`rho_K^{(n)}` 的极限不是 `min_j V_j`。** 这不是"没猜出来"，而是与 TASKS10 目标 (c)
   的陈述冲突。数据（Q0 第 2、7 节）显示：`rho_K^{(n)}` 关于 n 单调不减，
   `n = 2K` 时 = `rho_K`，`n >= K+T` 时 = `W_K > rho_K`。
   父任务预期的"有限 n 修正 `rho_K^{(n)} > V_j` 随 n 衰减"方向相反：修正随 n **增大**
   （从 0 增到超额项），并且在有限 n 处**恰好为 0**。
4. **只测了 `tau = 1`。** F3 已证 `tau >= 2` 时（连 `ysmall` 定义）对任意 delta、任意 n
   不可行，所以不重复。
5. **`eta` 为整数（段边界）没有单独处理。** 本夜用的 `j = K + 1 - ceil(eta)` 约定把
   `eta = 2, K = 3` 归到 `j = 2`（段 `[1,2]` 的右端点）。任务书给的自检点
   "K=3, j=1, eta=2" 在这个约定下不存在（`eta = 2` 对应 `j = 2`；`j = 1` 对应
   `eta ∈ (2,3]`）。自检按 `K=3, eta=2, n=24` 跑，见第 6 节。

## 5b. `j <= 1` 的失败点分析（数据证据，给 Q3）

失败的**机制**已经定位（不是"不知道哪里错"）：**闭式多加了 `F(x,K) ≡ 1` 这条约束**，
而 `j <= 1` 时 LP 最优解不满足它。`opt_norm` 只要求 `F <= 1` 于 `|S| = x+y <= K`，
所以 `F(x,K)`（`x >= 1`）可以超过 1，LP 正是靠这份自由把值压低。
（F3 §caveat 记过 `(5,4)` 的差异"源于闭式多加了 `F(x,K) ≡ 1`"，这里是同一现象的一般化。）

K = 3, eta = 5/2, n = 24 的 LP 顶点（j = 1，LP 值 0.393006377，闭式 0.394458）：

| x | 0 | 1 | 2 | 3 | 4 | … | 9 | 10 | 11+ |
|---|---|---|---|---|---|---|---|---|---|
| `F(x,0)` | 0 | 0.159678 | 0.276342 | **0.393006** | 0.509670 | … | 1.092991 | 1.209655 | 1.279540 |
| `F(x,K)` | 1 | 1.027954 | 1.055908 | 1.083862 | 1.111816 | … | 1.251586 | 1.279540 | 1.279540 |
| `d_x` | 0.159678 | 0.116664 | 0.116664 | 0.116664 | 0.116664 | … | 0.116664 | 0.069885 | 0 |

确定的部分（[VERIFIED-LP]，从顶点与对偶读出）：

1. 三相位结构**仍在**：相位 1 长度 `j`、常数平台 `D'`、一个收口步、然后全 0。
2. `ghat(x) = g_x / eta` 与 `Delta_x F(x,1) = ghat(x+1)`（coherence）**仍处处取等**。
3. `F(x,y)` 在 `y >= 1` 上**仍线性**，`G(x,y) = Ghat_{x+1} + (F(x,y) - F(x,1))`（`y >= 2`）**仍成立**。
4. `F(0,y) = y/K` 仍精确；`submod yy` 只在 `x <= j` 取等（4 条 = `(j+1)(K-1)`，与 `j >= 2` 同律）。
5. **新结构**：`F(x,K)` 是 x 的**线性**函数（`submod xx` 在 `y = K` 上 9 条取等），
   斜率 = 尾端的 `Ghat` 增量（这里 0.027954 = `g_{T'}/eta`）；
   末端出现 `mono y` 取等（`F(x,2) = F(x,3)`，x = 9, 10）。
6. 平台值 `D' = 0.116664` **大于**闭式的 `D = 0.113896`，但目标值**更小**，
   因为相位 1 的第一步 `d_0 = 0.159678` 不再等于 `1/k1 = 1/6 = 0.166667`。
   也就是说 `j <= 1` 时"相位 1 = R7/U_K 实例"这条也不成立。

卡住的部分：定出 `d_0`、`D'`、收口位置与顶行斜率的那组方程（顶点的有理数分母很大，
例如 `d_0 = 390625/2446327 = 5^8/2446327`，含 `nu = 5/3` 的高次幂），需要解一个
带两个打靶条件的耦合系统，本夜没有做出来。这是 Q3_failure_point 的候选条目。
注意 `j <= 1` 对应 `eta > K - 1`，在论文关心的 `eta` 不太大的区间之外，
且该区的 LP 值**更低**（对 hardness 更有利），所以把定理的定义域限制在 `eta <= K-1`
不会削弱结论，只是让定理的 `eta` 范围与 `rho_K` 的分段结构不完全对齐。

## 6. 最小自检（D 节，任务要求）

`K = 3, eta = 2, n = 24`（`j = 2`，`m* = 5`，`T = 7`，`D = 464/4275`）：

```
闭式 F(K,0) = 2003/4275 = 0.468538011696
LP 最优值    = 0.468538011696        diff = +1.1e-16
V_j          = 7/15    = 0.466666666667
超额         = 8/4275  = 1.871e-03
精确有理可行性违反数: 0
抽查: F(1,0) = 1/5,  F(2,1) = 43/75,  Ghat_3 = 61/150,  G(2,2) = 31/50
```

合法性抽查（人工复核上面几个数）：
- `F(1,0) = 1 - q = 1/5` ✓（`q = 4/5`）。
- `F(2,1) = 1 - r_2 + g_2 = 1 - 16/25 + 16/75 = 43/75` ✓。
- `Ghat_3 = (g_0 + g_1 + g_2)/eta = (1/3 + 4/15 + 16/75)/2 = (61/75)/2 = 61/150` ✓。
- `G(2,2) = Ghat_3 + (F(2,2) - F(2,1)) = 61/150 + (59/75 - 43/75) = 61/150 + 16/75 = 31/50` ✓。
- band 在这条边上：`Delta_y G = 16/75`，`Delta_y F = 16/75`，比值 1 ∈ `[1/eta, 1] = [1/2, 1]` ✓
  （`eta_o = 1` 的一侧取等，这正是 unbalanced 的 G 规则）。

## 7. 给 Q2 的注意事项（`notes` 字段的展开）

1. 定义域取 `K >= 3`、`2 <= j <= K-1`、`eta ∈ (K-j, K-j+1]`、`n >= 2K`。
2. 需要逐段检查的边界：`x = j`（相位 1/2 结合处，`d` 从 `q^j/k1` 跳到 `D`，
   要 `D <= q^{j-1}/k1` 才不破坏 `d` 的单调性）、`x = T`（收口步 `d_T = r_T <= D`）、
   `x = T+1`（进入饱和，`d` 从 `r_T` 掉到 0）、`y = 0/1` 结合处、
   `y = 1 -> y = 2` 的 band 边（unbalanced 规则在这里取等）。
3. `submod yy` 在相位 1 内**取等**（`K g_x = r_x`），进入相位 2 后变成严格不等，
   到 `x = T` 时 `g_T = r_T`，`K g_T > r_T`（K >= 2）。所以 `K g_x >= r_x` 在整条链上
   要单独验证（这是 F 在 y 方向 submodular 的条件）。
4. `opt_norm`（`F <= 1` 于 `0 < x+y <= K`）在闭式下等价于 `F(x,y) <= 1`，
   而 `F(x,K) ≡ 1`，所以只需 `y < K` 的点。相位 2 若 `x + y <= K` 也要覆盖。
5. 目标 `F(K,0) = 1 - q^j + (K-j) D` 用到 `j < K <= T`。`K <= T` 成立是因为
   `m* >= ceil(eta K) - 1 >= K`（`eta > 1`），所以 `T = j + m* > K`。这条要在符号侧确认。
6. 不要试图在 `j <= 1` 上验证（会 FAIL，见第 5 节）。
