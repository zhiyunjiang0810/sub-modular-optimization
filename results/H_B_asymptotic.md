## 0. 结论摘要

**(A) 1/K 项的闭式**

    ρ_K(η) = 1 − e^{−1/η} + c(η)/K + O(1/K²),

    c(η) = e^{−1/η} · (2η − 1) / (2η²)     [VERIFIED-SYMBOLIC]

c(η) **不随 ⌊η⌋ 分段**：sympy 展开中 m = ⌊η⌋ 的贡献在 1/K 项上恰好相消
（`d/dm` 的符号导数为 0，脚本 Section 2）。分段的是下一阶：

    ρ_K = 1 − e^{−1/η} + c(η)/K + d(η,m)/K² + O(1/K³),   m = ⌊η⌋,

    d(η,m) = e^{−1/η} · [ 24η³(1−m) + 12η²(m²+m−3) + 20η − 3 ] / (24η⁴)   [VERIFIED-SYMBOLIC]

**(B) 单调性**

    ρ_K(η) 关于 K 非增：K ≤ ⌊η⌋ 时 ρ_K = 1/η（常数），K ≥ ⌊η⌋ 起严格递减，
    且 ρ_K ↓ 1 − e^{−1/η}（从上方收敛，因为 c(η) > 0 对一切 η ≥ 1）。

状态 [VERIFIED-SYMBOLIC，conditional on T6 的 ρ_K = min_j V_j]：证明由三步组成，
其中两步机器验证、一步是初等的逐项级数比较（见 §4）。数值上 7 个 η × K = 2..400
的精确有理差分共 2,793 个符号，负数 0 个。

## 4. 推导

### 4.1 活跃段

固定 η ≥ 1，令 m = ⌊η⌋ ≥ 1。段规则（T6）给出

    K ≤ m      时  ρ_K = V_0 = 1/η
    K ≥ m + 1  时  ρ_K = V_{K−m}(η) = 1 − q^{K−m} · (1 − m/(Kη)),   q = 1 − 1/((K−1)η + 1)

注意 j = K − m 随 K 变，但 m 不随 K 变（η 固定），所以「K 增大时穿过整数断点」的情形
在固定 η 的渐近里**不会出现**；断点只在 η 变化时出现，且那里两段取等（§2）。

### 4.2 1/K 展开（sympy，Section 2）

令 ε = 1/K，x = (K−1)η + 1，u = 1/x：

    u = 1/(Kη) + (η−1)/(K²η²) + O(1/K³)
    (K−m)·(−ln q) = (K−m)(u + u²/2 + …) = 1/η − m/(Kη) + (η − 1/2)/(Kη²) + O(1/K²)

故

    q^{K−m} = e^{−1/η} · [ 1 + ((m−1)/η + 1/(2η²))/K + O(1/K²) ]

再乘 (1 − m/(Kη))，1/K 项上的 m/η 与 −m/η **相消**：

    ρ_K = 1 − e^{−1/η} + e^{−1/η}(1/η − 1/(2η²))/K + O(1/K²)

即 **c(η) = e^{−1/η}(2η−1)/(2η²)**。

sympy 验证（`sp.series(V, epsilon, 0, 3)`）：
- 0 阶 = 1 − e^{−1/η}：**True**
- 1 阶 = e^{−1/η}(2η−1)/(2η²)：**True**；`diff(·, m) == 0`：**True**（不分段）
- 2 阶 = d(η,m) 如 §0；`diff(·, m) != 0`：**True**（分段，见表）

标签 [VERIFIED-SYMBOLIC] 只覆盖「V_{K−m} 的 ε 展开系数 = 上述闭式」这条恒等式本身。

### 5.2 证明（Section 5）

记 P(K) = q^{K−m}(1 − m/(Kη))，则 ρ_K = 1 − P(K)，单调递减 ⟺ P 关于 K 递增。
把 K 放松成实变量，K ∈ [m+1, ∞)：

**第 1 步（sympy 恒等式，机器验证 True）**

    d/dK · ln P = ln(1 − 1/x) + (K−m)/((K−1)x) + m/(K(Kη − m)),    x = (K−1)η + 1

**第 2 步（初等，逐项比较）** 对 x > 1，

    −ln(1 − 1/x) = Σ_{i≥1} 1/(i x^i) ≤ 1/x + 1/(2x²) + (1/3)·Σ_{i≥3} x^{−i}
                 = 1/x + 1/(2x²) + 1/(3x²(x−1))

（第 i ≥ 3 项逐项用 1/i ≤ 1/3；这是唯一的手写步骤，脚本里另做了 8 个 x 的数值抽查。）
注意：只保留两项的更粗的界 1/x + 1/(2x(x−1)) **不够**，在 K=2、η→2⁻、m=1 处失效，
必须保到 1/(2x²) 这一阶。

于是充分条件是

    S(K,η,m) := (K−m)/((K−1)x) + m/(K(Kη−m)) − 1/x − 1/(2x²) − 1/(3x²(x−1)) > 0

**第 3 步（非负系数证书，sympy 精确有理，机器验证）** 作坐标变换把定义域变成第一象限：

    η = m + s,  s ∈ [0,1)      K = m + 1 + u,  u ≥ 0      m = 1 + w,  w ≥ 0
    再令 s = t/(1+t),  t ≥ 0   （把 s < 1 这条双边约束有理化掉）

把 S 通分，分子乘以 (1+t)³ > 0 后展开：

- 分子：**84 个单项式，负系数 0 个，常数项 = 14 > 0**
- 分母：**165 个单项式，负系数 0 个**（在该象限上恒正）

故 S > 0 在整个定义域上成立，于是 d ln P/dK > 0，P 在 [m+1, ∞) 上严格递增，
**ρ_K 在 K ≥ m+1 上严格递减**。

**第 4 步（平台与首降）**
- K ≤ m 时 ρ_K = 1/η 为常数（差 = 0）；
- 从 K = m 到 K = m+1 的一步：ρ_m = V_0，ρ_{m+1} = V_1，而
  V_0 − V_1 = (K−η)/(Kηk_1)（sympy 恒等式 True），在 K = m+1 > η 处严格为正。

**独立数值旁证**（不依赖第 2 步的界）：直接扫 d ln P/dK 的精确值，m = 1..12、
η = m..m+0.95（步长 0.05）、K 从 m+1 起到 m+1+2²¹，共 13,440 点，**非正值 0 个**。

### 5.3 单调性 verdict

> **ρ_K(η) 关于 K 非增；K ≤ ⌊η⌋ 上为常数 1/η，K ≥ ⌊η⌋ 起严格递减，极限 1 − e^{−1/η} 从上方逼近。**
>
> 状态：**[VERIFIED-SYMBOLIC，conditional on T6 的 ρ_K = min_j V_j]**。
> 已检查范围：符号证明覆盖一切实数 η ≥ 1 与一切整数 K ≥ 2（m 也被放松成实数 ≥ 1，比需要的更强）；
> 精确有理数值覆盖 η ∈ {1.25,1.5,2,2.5,3,4,6} × K = 2..400。
> 非机器验证的部分只有第 2 步的逐项级数比较（一行，标准）。

不能声称：ρ_K 关于 K 是凸的或凹的（没查）；关于 η 的单调性（另一回事，V_0 = 1/η 段显然递减，

## 6. 副产品（Section 6，均 [VERIFIED-SYMBOLIC]）

1. **L_K 的同阶常数**：L_K = 1 − e^{−1/η} + c_L(η)/K + O(1/K²)，c_L(η) = e^{−1/η}/(2η²)。
   于是 **ρ_K − L_K = e^{−1/η}(η−1)/η² · (1/K) + O(1/K²)**，在 η = 1 处为 0
   （与 ρ_K(1) = L_K(1) 一致），η > 1 处严格为正（这是「原界对有限 K 严格不紧」的定量版本，
   台账 T6 那条注记要求的 η > 1 限定在这里自动出现）。
2. **U_K 的同阶常数**：c_U(η) = c(η)，**与 ρ_K 的 1/K 项完全相同**。
   这正是 RESEARCH_STATE R7 里「U_K − ρ_K ≈ O(1/K²)」的解释：夹逼的上界与真值在 1/K 阶就已重合，
   差别从 1/K² 才开始。
3. **c(η) 的最大值**：c′(η) = 0 ⟺ 2η² − 4η + 1 = 0，故 **η\* = 1 + 1/√2 = 1.70710678**，
   c(η\*) = **0.23057940**。c(η) 在 η ≥ 1 上先增后减，η → ∞ 时 c ~ 1/η → 0。
   即有限 K 的「超出渐近常数的那一块」在 η ≈ 1.7 附近最大。

## 9. 卡点记录

无阻塞卡点，未触发 45 分钟规则。三处走了弯路，记录下来避免重复：

1. **段号公式**。TASKS6 步骤 2 写的是 j = K − ⌈η⌉，正确的是 j = K − ⌊η⌋。
   按 ⌈η⌉ 展开会得到把 m 换成 m+1 的式子，1/K 项仍然相消（因为 m 本来就消掉了），
   所以 c(η) 不受影响，但 1/K² 系数会错，且非整数 η 的活跃段对不上 LP。已按 LP 对拍改正。
2. **单调性证明的界不能太粗**。用两项界 −ln(1−1/x) ≤ 1/x + 1/(2x(x−1)) 时，
   充分条件在 K=2、η→2⁻、m=1 附近为负（该处 x=2.9，1/x 不小），不是结论错而是界太松。
   保到 1/(2x²) + 1/(3x²(x−1)) 之后证书就闭合了。另外必须先把 s ∈ [0,1) 用 s = t/(1+t)
   有理化，否则直接在 (s,u,w) 上做非负系数论证会剩 9 个负单项式。
3. **一个被证伪的自我假设**。我先前把「不用 LP 做大 K 数值」的理由写成「highs 的残差
   会污染 6 位外推」，实测后发现 LP 在 K ≤ 200 的偏差只有 ~5e−16（§1 表），假设不成立。
   已改写为真实理由（耗时 + 精确有理算术），并把这次实测作为扩展对拍保留下来。
   教训：替换方法的理由本身也要有 oracle，不能凭对求解器精度的印象写。
