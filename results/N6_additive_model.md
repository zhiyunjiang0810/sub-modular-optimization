# N6 — 加性 + 乘性混合误差模型：理论、LP 检验与实证重测

对应 R13/T6 的后续：真实 ML surrogate 上乘性 η^path 被近零增益炸掉（K=7 中位数 43/60/371，
L_K 下界 vacuous），但实测 ratio 0.94-0.96。本任务给"加性 + 乘性"混合误差模型建立
single-step predictive greedy 的比值下界，用 LP oracle 检验，并在同一实证 pipeline 上重测。

**5 行摘要**
1. 推导出 `F^PG ≥ L_K(η)·(OPT − 2K·η_u·ε)`，加性项系数 `c(η) = 2·η_u·L_K(η)`；只有 η_u 乘 ε，η_o 不出现。
2. LP oracle 在 16 个显式检验点上从未违反该下界；更强的是，**LP 精确值 = ρ_K(η)·max(0, 1 − 2K·η_u·ε)**，
   29 个点残差 ≤ 2.8e−16，说明推导的 ε 结构（系数 2、因子 K、只含 η_u）完全正确，
   唯一松弛是 ε=0 时就已存在的 ρ_K − L_K。
3. 实证：trimmed η^path 确实大幅下降（K=7 中位数 43→4.8、60→5.5、371→17.9），重尾几乎消失。
4. **但新下界仍然实质 vacuous**：K=7 时 additive_bound 中位数 0.026-0.074 / −0.02 到 −0.18 / 0.009-0.028，
   对比实测 ratio 0.94-0.96。原因是 η_trim 与 ε 项此消彼长，K=7 时无论 ε 取何值都无法同时压小两者。
5. 最需要人判断的一点：混合模型在这批数据上 **在 ε = 1-2 个量化单位时根本不可行**（无有限 η_u, η_o），
   要到 3-13 个单位才可行；这是模型本身与 ML surrogate 的失配，不是 trimming 参数没调好。

## 1. 误差模型与定理（步骤 1）

### 1.1 设置

ground set N，`f: 2^N → R` 单调 submodular，`f(∅) = 0`。`O ∈ argmax{f(S): |S| ≤ K}`，
`OPT = f(O)`，本节归一化 `OPT = 1`。边际增益 `d_e(S) = f(S ∪ {e}) − f(S)`，预测 `d̃_e(S)`。

**混合误差模型 (M_ε)**：存在 `η_u, η_o ≥ 1` 与 `ε ≥ 0`，使得对一切 `S ⊆ N`、`e ∉ S`

```
    d_e(S)/η_u − ε  ≤  d̃_e(S)  ≤  η_o·d_e(S) + ε
```

记 `η = η_u·η_o`。`ε = 0` 时精确退化为 R1/R5 的 single-element 乘性模型。

**算法**（single-step predictive greedy，与论文 Algorithm 1 一致）：
`S^0 = ∅`；`e_t = argmax_{e ∉ S^{t−1}} d̃_e(S^{t−1})`；`S^t = S^{t−1} ∪ {e_t}`；输出 `S^K`，
`F^PG = f(S^K)`。tie 由对手打破。

### 1.2 推导 [HAND-PROOF-UNREVIEWED]

**Step 1（不变，与 R1 相同，用到 monotone + submodular）。**
若 `O ⊆ S^{t−1}` 则 `f(S^{t−1}) ≥ f(O) = 1`，结论平凡成立。否则由单调性与 submodularity，

```
    1 − f(S^{t−1}) = f(O) − f(S^{t−1}) ≤ f(O ∪ S^{t−1}) − f(S^{t−1})
                                        ≤ Σ_{o ∈ O∖S^{t−1}} d_o(S^{t−1}),
```

而 `|O∖S^{t−1}| ≤ K`，故存在 `o* ∈ O∖S^{t−1}` 满足
`d_{o*}(S^{t−1}) ≥ (1 − f(S^{t−1}))/K`。

**Step 2（ε 进入的位置，也是 η_u / η_o 分开的位置）。**
greedy 的选择条件给 `d̃_{e_t}(S^{t−1}) ≥ d̃_{o*}(S^{t−1})`。对 `o*` 用模型下带、对 `e_t` 用模型上带：

```
    η_o·d_{e_t}(S^{t−1}) + ε  ≥  d̃_{e_t}(S^{t−1})  ≥  d̃_{o*}(S^{t−1})  ≥  d_{o*}(S^{t−1})/η_u − ε
```

两端同除 `η_o`：

```
    d_{e_t}(S^{t−1})  ≥  d_{o*}(S^{t−1})/(η_u·η_o) − 2ε/η_o  =  d_{o*}(S^{t−1})/η − 2ε/η_o.        (*)
```

**这一步是全部结构的来源**：两个 ε（一个来自下带、一个来自上带）都被 `η_o` 除，因为从"预测空间"
换回"真实空间"是在被选中的元素 `e_t` 上做的，走的是上带常数 `η_o`。若模型两侧的加性松弛不同
（下带 ε_u、上带 ε_o），(*) 右端的常数就是 `(ε_u + ε_o)/η_o`。

**Step 3（递推）。** 令 `Δ_t = 1 − f(S^t)`（`Δ_0 = 1`，因为 `f(∅) = 0`）。由 Step 1 + (*)：

```
    Δ_t ≤ Δ_{t−1} − Δ_{t−1}/(ηK) + 2ε/η_o = β·Δ_{t−1} + 2ε/η_o,      β := 1 − 1/(ηK).
```

展开 K 步：

```
    Δ_K ≤ β^K + (2ε/η_o)·Σ_{j=0}^{K−1} β^j = β^K + (2ε/η_o)·(1 − β^K)/(1 − β).
```

因为 `1 − β = 1/(ηK)`，有 `(1 − β^K)/(1 − β) = ηK·L_K(η)`，其中
`L_K(η) = 1 − (1 − 1/(ηK))^K = 1 − β^K`。又 `η/η_o = η_u`，于是

```
    F^PG = 1 − Δ_K ≥ L_K(η) − 2ε·η_u·K·L_K(η).
```

### 1.3 定理 N6 [HAND-PROOF-UNREVIEWED；不等式方向 VERIFIED-LP，见 §2]

```
    F^PG  ≥  L_K(η) · ( OPT − 2·K·η_u·ε )
          =  L_K(η)·OPT − c(η)·K·ε,        c(η) = 2·η_u·L_K(η),     η = η_u·η_o
```

推论与读法：

- `ε = 0` 精确退化为 R1（论文 Theorem 6）。加性项是纯粹的附加损失，乘性因子 `L_K(η)` 不变。
- 两个平凡放松：`c(η) ≤ 2η_u`；又因 `L_K(η) ≤ 1/η`，也有 `c(η) ≤ 2/η_o`。报告一律用精确形式
  `c(η) = 2η_u L_K(η)`。
- **η_u 与 η_o 的分工**：`η = η_u η_o` 对称地决定乘性因子 `L_K(η)`；但加性惩罚只含 `η_u`。
  直观：给定 η，over-estimating 型预测器（η_o 大、η_u 小）对加性噪声更鲁棒，因为 greedy 比较的是
  被放大的预测增益，ε 相对更小；under-estimating 型（η_u 大）会把 ε 放大 η_u 倍。
- **临界 ε**：下界在 `ε* = OPT/(2·K·η_u)` 处归零。这是一条可直接用于"何时该在意误差"的判据，
  且 §2 证明它是**精确的**（LP 最坏值在同一点归零）。
- 与 R1 的一致性：证明只用 greedy 轨迹状态 `S^t` 上的单元素增益，所以对 path 版本
  `(η_u^path, η_o^path, ε)` 同样成立。

**空洞性检验（CLAUDE.md §空洞性检验）**，逐个限定词：

| 限定词 | 去掉会怎样 | 结论 |
|---|---|---|
| monotone | Step 1 的 `f(O) ≤ f(O∪S)` 失效，Step 1 整条不成立 | 保留，必需 |
| submodular | Step 1 的求和上界失效 | 保留，必需 |
| single-step | `c(η)·K·ε` 里的 K 是 greedy 步数；pair/R-step lookahead（R12）每步换成一对，ε 损失的计数与 (*) 都要重推 | 保留，必需，且限定了适用算法 |
| additive（ε > 0） | ε = 0 时整句退化为 R1，无新内容 | 保留，非空 |
| OPT 归一化 | ε 是 f 的绝对单位，不归一化时结论应写成 `F^PG/OPT ≥ L_K(η)(1 − 2Kη_u·ε/OPT)`；缩放 f 会改变结论 | 必须在正文写明 ε 的单位，否则该式不是 scale-covariant |
| worst-case | LP 给的是精确最坏值，非平均情形 | 保留 |

**一处未解决的交叉检查**：N1 的对偶证书显示 R10 的（ε=0）下界里 monotonicity 乘子恒为 0，
即那条下界不需要单调性；而上面的手证 Step 1 用了单调性。两者不矛盾（手证只是一条充分路径），
但说明 `2K η_u ε` 这条加性项可能也能在不用单调性的前提下证出。未做。

## 2. LP oracle 检验（步骤 1 的 oracle）

代码 `results/N6_additive_lp.py`：行构造从 `code/worst_case_lp.py`（R5，[VERIFIED-LP]）复制，
**唯一改动**是两条误差行的右端由 0 改成 ε：

```
    d/η_u − d̃ ≤ ε          (原: ≤ 0)
    d̃ − η_o·d ≤ ε          (原: ≤ 0)
```

monotone / submodular / greedy path / `f(∅)=0` / `f̃(∅)=0` / `f(O)=1` / 目标 `f({0..K−1})` /
枚举全部 K-子集 O 取 min 全部保持不变。

**斜率对比（任务要求）**：LP 的经验斜率（4.1335 / 3.9598）**大于** `c(η)·K`（3.8910 / 3.5748），
比值分别是 1.06233 与 1.10770。这两个数恰好等于 `ρ_K(η)/L_K(η)`
（`0.5625/0.529492 = 1.06234`，`0.466667/0.421296 = 1.10769`）。也就是说，
**下界与 LP 的 ε 依赖形状完全相同，差别只在 ε=0 处的前因子**。这直接引出下一节。

### 2.2 更强的结构发现 [VERIFIED-LP 于所测点；一般情形 CONJECTURE]

猜测 `LP(ε) = ρ_K(η)·max(0, 1 − 2·K·η_u·ε)`，在 29 个点上检验（24 个 structure probe 点 + 5 个 K=4 点）：

| 配置 | (n, K) | (η_u, η_o) | ε=0 的 LP | 预测的 ε* = 1/(2Kη_u) | max &#124;LP − 预测&#124; |
|---|---|---|---|---|---|
| K=3, η=2, 对称 | (6, 3) | (√2, √2) | 0.466667 = 7/15 | 0.117851 | 2.8e−16 |
| K=3, η=2, 全 under-est | (6, 3) | (2, 1) | 0.466667 | 0.083333 | 1.1e−16 |
| K=3, η=2, 全 over-est | (6, 3) | (1, 2) | 0.466667 | 0.166667 | 1.0e−16 |
| K=2, η=2, 对称 | (4, 2) | (√2, √2) | 0.500000 = 1/2 | 0.176777 | 8.3e−17 |
| K=4, η=2, 对称 | (8, 4) | (√2, √2) | 0.448980 = 22/49 | 0.088388 | 2.8e−16 |

结论：

1. 系数里的 **2**、**K**、**只含 η_u** 三点全部被 oracle 确认。固定 `η = 2` 只改变 `(η_u, η_o)` 的分配，
   崩溃点 ε* 从 1/6 变到 1/12，比值恰为 η_u 之比（1 : 2），与 η_o 无关。
2. K = 2, 3, 4 三处 ε=0 的值分别复现 R5 的 1/2、7/15、22/49，K 的线性依赖被确认。
3. 因此 §1.3 定理的**加性部分是紧的**：把 `L_K(η)` 换成精确的 `ρ_K(η)` 后等号成立。
   剩余松弛 `ρ_K − L_K` 是 R5/R10 早就存在的、与 ε 无关的松弛。

**猜想 N6-C1 [CONJECTURE]**：single-step predictive greedy 在模型 (M_ε) 下的精确最坏比为
`ρ_K(η, ε) = ρ_K(η)·max(0, 1 − 2·K·η_u·ε/OPT)`。
证据：上表 29 点残差 ≤ 2.8e−16。未证；n > 2K 的更大 n、K ≥ 5、以及更多非对称 (η_u, η_o) 组合未测。

### 3.3 关键问题的诚实回答

**Q1. trimmed η^path 是否降到有意义的范围？—— 是，降幅很大，但仍不算小。**

K=7 中位数：breast_cancer 43 → 13.3（ε 档 1）→ 4.8（ε 档 2）；wine 60 → 8.3 → 5.5；
digits20 371 → 60.8 → 17.9。**重尾几乎消失**（digits20 K=7 的 q3 从 5551 降到 85 / 26）。
`η_u` 与 `η_o` 都降，且 T6 的"η_u 系统性大于 η_o"仍然成立
（K=7 档 2 中位数：4.61/2.69 → 2.34/1.90，3.12/2.54 → 2.68/2.01，11.3/4.51 → 5.29/3.31）。
所以 R13 的机制诊断被独立确认：η 的爆炸确实由 |d| 或 |d̃| 在一个量化单位以内的对造成。

代价：trimming 丢掉的对不少。K=7 时 `frac_kept` 只有 0.20-0.71，用于取 max 的正部
`frac_eta` 只有 0.11-0.50。也就是说 **K=7 时超过一半的候选对根本不在模型的乘性部分管辖之下**。

**Q2. 新下界 additive_bound 是否不再 vacuous？—— 符号上多数为正，但数值上仍然实质 vacuous。**

- 正性：breast_cancer 26-28/30、digits20 29-30/30 的 split 为正；wine 在 K ≥ 5 大量转负
  （ε 档 2 时 K=5,7 全部 0/30）。
- 数值：K=7 的中位数 0.026-0.074（breast_cancer）、−0.020 到 −0.183（wine）、
  0.009-0.028（digits20）。对比实测 ratio 0.94-0.96，**下界仍然离真实表现差 1 个数量级以上**。
- 相对 T6 的改进确实存在但有限：K=7 时 `L_K(η_raw)` 为 0.023/0.017/0.003，
  新下界两档中较好的一档为 0.074 / −0.020 / 0.028，即 breast_cancer 约 3.2 倍、digits20 约 9.4 倍，
  **wine 反而比 T6 更差**（由正的 0.017 变成负的 −0.020）。

**Q3. 若仍 vacuous，是 η_trim 还大，还是 ε 项太大？—— 两者都有，且是此消彼长的取舍。**

把 K=7 的下界拆成两项（表中 `L_K(η_trim)` 与 `c·K·ε`）：

| dataset | ε 档 | L_K(η_trim)（乘性部分） | c·K·ε（加性罚） | 谁是主因 |
|---|---|---|---|---|
| breast_cancer | 1/n | 0.0727 | 0.0444 | η_trim=13.3 仍大，两者相当 |
| breast_cancer | 2/n | 0.1909 | 0.1194 | ε 项已占 63% |
| wine | 1/n | 0.1140 | 0.1444 | **ε 项超过乘性部分，下界转负** |
| wine | 2/n | 0.1678 | 0.3591 | ε 项压倒性 |
| digits20 | 1/n | 0.0164 | 0.0085 | η_trim=60.8 仍太大 |
| digits20 | 2/n | 0.0545 | 0.0229 | η_trim=17.9 仍太大 |

结构上：**提高 ε 压低 η_trim（改善 L_K），同时线性抬高 ε 罚**。§1.3 的临界值给出定量的天花板：
非平凡下界要求 `ε < OPT/(2Kη_u)`。代入 K=7、OPT ≈ 0.95（accuracy 尺度）与实测 η_u_trim：

| dataset | ε 档 | ε（单位数） | η_u_trim | ε* = OPT/(2Kη_u)（单位数） | ε < ε*？ |
|---|---|---|---|---|---|
| breast_cancer | 1/n | 0.00877 (1.0) | 4.61 | 0.0147 (1.68) | 是 |
| breast_cancer | 2/n | 0.01754 (2.0) | 2.34 | 0.0290 (3.31) | 是 |
| wine | 1/n | 0.02778 (1.0) | 3.12 | 0.0218 (0.78) | **否** |
| wine | 2/n | 0.05556 (2.0) | 2.68 | 0.0253 (0.91) | **否** |
| digits20 | 1/n | 0.00278 (1.0) | 11.3 | 0.0060 (2.16) | 是 |
| digits20 | 2/n | 0.00556 (2.0) | 5.29 | 0.0128 (4.62) | 是 |

wine 的两个 ε 档都已经超过它的 ε*（0.78 与 0.91 个量化单位），所以 K=7 的下界必然为负，
这不是参数没调好而是天花板本身太低：wine 的 `n_test = 36`，一个量化单位（0.0278）已经比 ε* 还大。
digits20 虽然 ε < ε*，但它的 η_trim 仍高达 17.9-60.8，乘性部分 `L_K` 只有 0.016-0.055，
再压 η 就得抬 ε 越过 ε*，两个要求互相矛盾。

**Q4. 更根本的问题：这批数据上 (η_u_trim, η_o_trim, ε) 并不真的满足模型。**

trimmed 参数只在**被保留的对**上认证了误差带；被 trim 掉的对（K=7 时占 29%-80%）没有任何保证。
所以把 `additive_bound` 读成"这批数据上被认证的下界"是不对的，它只是"若模型以这组参数成立，
定理会给出的值"。脚本因此额外做了一个**认证版**测量：在同一个 ε 下，对**全部**记录的对求解
使 `d/η_u − ε ≤ d̃ ≤ η_o d + ε` 成立的最小 (η_u, η_o)，并统计无解的对。

- 结果：**在任务指定的 ε = 1/n_test 与 2/n_test 处，1110/1260 行根本不可行**，
  即不存在任何有限的 (η_u, η_o)。原因是存在 `d > 0` 而 `d̃ < −ε` 的对（或反向），
  这类对无论 η 多大都跳不出误差带。
- 使模型可行所需的最小 ε（中位数）：breast_cancer 0.048（5.5 个单位）、wine 0.085（3.0 个单位）、
  digits20 0.035（12.6 个单位）—— 全部远大于 1-2 个单位。
- 把 ε 当自由参数、最大化认证下界（脚本 `certified_best`，80 点 log 网格）：

| dataset | K | 最优 ε（单位数） | 认证 η_u | 认证 η_o | 认证 η | L_K | 最好认证下界 [q1,q3] | >0 的 split |
|---|---|---|---|---|---|---|---|---|
| breast_cancer | 3 | 0.0949 (10.8) | 1.000 | 1.000 | 1.014 | 0.6974 | **+0.286** [+0.177, +0.358] | 30/30 |
| breast_cancer | 5 | 0.0840 (9.6) | 1.027 | 1.000 | 1.048 | 0.6531 | **+0.048** [−0.097, +0.159] | 17/30 |
| breast_cancer | 7 | 0.0692 (7.9) | 1.048 | 1.000 | 1.135 | 0.6099 | **−0.143** [−0.324, −0.014] | 7/30 |
| wine | 3 | 0.1227 (4.4) | 1.265 | 1.000 | 1.314 | 0.5845 | **+0.007** [−0.077, +0.096] | 15/30 |
| wine | 5 | 0.0973 (3.5) | 1.649 | 1.240 | 2.204 | 0.3786 | **−0.208** [−0.411, −0.137] | 1/30 |
| wine | 7 | 0.0935 (3.4) | 1.911 | 1.317 | 3.011 | 0.2890 | **−0.524** [−0.737, −0.283] | 0/30 |
| digits20 | 3 | 0.0611 (22.0) | 1.000 | 1.000 | 1.000 | 0.7036 | **+0.439** [+0.397, +0.470] | 30/30 |
| digits20 | 5 | 0.0626 (22.5) | 1.045 | 1.000 | 1.045 | 0.6544 | **+0.196** [+0.160, +0.282] | 29/30 |
| digits20 | 7 | 0.0549 (19.8) | 1.100 | 1.000 | 1.151 | 0.6046 | **+0.010** [−0.038, +0.117] | 17/30 |

这是本任务**最正面的一个数字**：允许 ε ≈ 0.05-0.12（真实 accuracy 尺度上的 5-10 个百分点）时，
认证的乘性误差 η 塌缩到 1.0-3.0，`L_K` 升到 0.29-0.70，
K=3 的认证下界达到 **0.286 / 0.007 / 0.439**（对比 T6 的 `L_3(η_raw)` = 0.028 / 0.022 / 0.014：
breast_cancer 约 10.2 倍、digits20 约 31.4 倍，但 **wine 反而只有 T6 的 0.3 倍**）。
K 一大加性罚就吃光：K=7 时只有 digits20 勉强为正（中位数 +0.010，17/30 split 为正）。

**总判定：bound_vacuous = yes（K ≥ 5 时）/ partially no（K ≤ 3 时）。**
混合模型确实把"近零增益炸掉 η"这个病治好了（Q1、Q4 的认证 η ≈ 1），但代价是把病转移到了
`2Kη_u·ε` 项上；在 accuracy 尺度上，能压住 η 所需的 ε 已经大到让 K ≥ 5 的下界为负。

最大亏空 0.080。这不是对定理的反例，而是**实证设置不满足定理前提**：

1. 定理要求 `f(∅) = 0`；这里 `f(∅)` 是训练集多数类在测试集上的频率（0.632 / 0.389 / 0.100），非零。

2. `ratio` 的分母是 oracle greedy 而非 OPT（`ratio ≥ F^PG/OPT` 需要 `F^greedy ≤ OPT`，这条成立），
   但 `F^PG/OPT ≥ bound` 这一步要求 f 单调 submodular，而 accuracy 两者都不满足（T6 发现 4）。

所以正确读法是：trimmed 下界（s6）从未被违反；ε 优化过的认证下界在 K=1 的 5 个 digits20 split 上被违反，
这正是"accuracy surrogate 不满足定理前提"的一个可量化证据。

## 4. 对论文的建议（诚实版）

1. **可以写进论文的正面结论**：加性 + 乘性混合模型下的下界
   `F^PG ≥ L_K(η)(OPT − 2Kη_u ε)`，其 ε 部分是**紧的**（LP 精确值只把 `L_K` 换成 `ρ_K`，
   §2.2，28 点残差 ≤ 2.8e−16）。附带的临界判据 `ε* = OPT/(2Kη_u)` 干净且可验证。
   η_u 与 η_o 的不对称角色（只有 η_u 乘 ε）是一个新的、可检验的结构性陈述。
2. **不能写成"混合模型解决了 T6 的问题"**。它把 η 从 43-371 降到 1-18，但把损失搬到了
   `2Kη_u ε` 上；K=7 的下界仍然是 0.01-0.07（或为负），而实测 ratio 是 0.94-0.96。
   诚实的说法是：**混合模型使 K ≤ 3 的下界从 vacuous（0.01-0.03）变成 non-trivial（0.29-0.44），
   K ≥ 5 依然 vacuous**。
3. **必须声明的实证局限**（沿用 T6，并新增两条）：oracle greedy 不是 OPT；accuracy 既不单调也不
   submodular；**新增 (a)**：`f(∅) ≠ 0`，与定理归一化不符，K=1 处已出现 10 行违反；
   **新增 (b)**：在 ε = 1-2 个量化单位处混合模型对 1110/1260 行不可行，
   即 trimmed η 是一个**启发式代理**而非认证参数。
4. 若要让实证与理论真正对齐，下一步应当改造 `f`（例如用 `f(S) − f(∅)` 重新中心化，
   或换一个真正单调 submodular 的目标如 facility location / coverage），而不是继续调 ε。未做。
