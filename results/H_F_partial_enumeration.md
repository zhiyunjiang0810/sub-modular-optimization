## 1. 算法与模型

**PE_R（R=1）**：对 ground set 的每个单元素 v，以 {v} 为起点跑 predictive greedy 直到 K 个元素，
得到 T_v；输出 argmax_v f̃(T_v)。这是 NW 1978 第 7 节 "枚举所有 R-子集各接 greedy 取最好" 的
预测版。对手权力（与 thm:exact 一致）：**每个起点的每一步 greedy argmax 的 tie 由对手挑**，
**最后 argmax_v f̃(T_v) 的 tie 也由对手挑**。

**模型**（`paper/sections/model.tex`）：f 单调 submodular、f(∅)=0、不可查询；f̃ 任意、f̃(∅)=0；
全局 band d_e(S)/η_u ≤ d̃_e(S) ≤ η_o d_e(S) 对**所有** S 与 e∉S 成立（Definition 1 的
single-element 形式）；η=η_u η_o。

**归一化**：与 `code/worst_case_lp.py` 同法，固定最优集 O、令 f(O)=1、对 O 取 min。
（任一实例按 f(O*) 归一后是 O=O* 的 LP 的可行点；反之 LP 最优解的真实比 ≤ 目标值，两个 min 相等。）

**对称拆分的合法性（T0 卡要求的一行 scaling 论证）**：若 (f, f̃) 满足 (η_u, η_o)-band，
对 c>0 令 f̃' = c·f̃，则 f̃' 满足 (η_u/c, c·η_o)-band，乘积 η 不变。取 c = √(η_u/η_o) 得到
对称拆分 (√η, √η)；此时 η_u/c = c·η_o = √η ≥ 1，故新拆分合法（c ≤ η_u 与 c ≥ 1/η_o
都等价于 η_u η_o ≥ 1）。而 f̃' 与 f̃ 有**完全相同的每步 argmax 集合与完全相同的 f̃(T_v) 大小序**
（正数标量乘不改变 argmax 与序），故 PE_1（以及 predictive greedy）在对抗 tie 下的可能输出集合
逐字不变，f 不变，最坏比不变。所以最坏值只依赖乘积 η，全文可固定 η_u=η_o=√η。
数值旁证见 §4.4：(η_u,η_o) = (1,2)、(2,1)、(√2,√2) 在 n=6 上给出同一个值 1/2。

## 2. 便宜的第一步：PE_1 打在已知的 ρ_K-attaining 实例上

TASKS6 建议先在已知达到 ρ_K 的实例族上跑 PE_1。结果是**这一步不能结案**：

| 实例族 | K=3, η=1.5 | η=2 | η=2.5 |
|---|---|---|---|
| N2 三块族 j=0,1,2,3（greedy 恰好取到 V_j） | PE_1 = **1.0** | 1.0 | 1.0 |
| U_K 族（`code/check_explicit_instance.py`，greedy 取到 L_K） | PE_1 = **1.0** | 1.0 | 1.0 |

原因（可以手算，用 N2 的记号 k_1=(K−1)η+1、q=1−1/k_1、对称拆分 s=√η）：从一个 O 元素出发时，
下一个 O 元素的预测增益是 s/K，C 元素是 (K−1)s/(K k_1)，P 元素是 q^j/(K s)；
比值 O/C = k_1/(K−1) > 1、O/P = η/q^j > 1（η ≥ 1 > q），所以 O 元素**严格**最优，
以 O 元素为起点的 greedy 走完整个 O；又 f̃(O)=W(0)=k_1/(K η_u) 大于 greedy 集的 f̃
（差为 q^j(W(0) − (K−j)/(K s)) ≥ 0，因 k_1 ≥ K > K−j），故 PE_1 直接输出 O，比值为 1。

结论：**枚举把 greedy 的已知最坏实例全部打穿**，必须真做 LP。wall time：5 秒（三个 η 全部）。

## 3. 方法：profile 上的 LP + 分支定界

最坏值 = **对组合选择 profile 取 min 的 LP 值**。profile 固定：每个起点 v 的两步 greedy 选择，
以及最终胜出的起点 v*。给定 profile 的 LP（变量是 2^n 个 f(S) 与 2^n 个 f̃(S)）：

- f 单调、submodular，f(∅)=f̃(∅)=0；
- band：对所有 (S,e) 的两条不等式；
- 轨迹最优性写成**不等式**（选中元素的预测增益 ≥ 其余候选），这正是"tie 由对手挑"的松弛；
- 最终选择：f̃(T_{v*}) ≥ f̃(T_v) 对所有 v；
- 归一化 f(O)=1；目标 min f(T_{v*})。

三个把 profile 空间压下来的手段：

**(a) 重标号对称**：固定 v*=0、T_0={0,…,K−1} 且 greedy 顺序 0→1→…→K−1。剩余对称群是
Sym({K,…,n−1})，用它把 O 的枚举从 C(n,K) 降到 K-子集的轨道代表（n=6,7 都是 8 个）。
合法性：min over profiles 在轨道上是常值，因为 LP(σO, σ·profile) = LP(O, profile)。

**(b) last-step collapse（关键，把 profile 空间从 (n−1)(n−2) 降到 n−1）**：
对起点 v、首选 a，第二步 b 的存在性要求是
"∃b：b ∈ argmax_e d̃_e({v,a}) 且 f̃(T_0) ≥ f̃({v,a,b})"。
因 argmax_e d̃_e({v,a}) = argmax_e f̃({v,a,e})，最强的 b 就是 argmax 本身，故该要求**等价于**
不含 b 的线性方程组 f̃(T_0) ≥ f̃({v,a,e})（对所有 e ∉ {v,a}）。所以**只有第一步需要分支**。
K=3、n=6 时 profile 从 20^5 降到 5^5。
交叉验证见 §4.5（把两步都分支重跑，得到同一最优值）。

**(c) profile-free 松弛做界**：对尚未分支的起点 v，用
f̃(T_0) ≥ f̃(T_v) ≥ f̃({v,e})（对所有 e≠v；后一步用 d̃ ≥ 0）
这一族不含 (a_v,b_v) 的线性约束。它是每个子结点的松弛，因此每个结点的 LP 值是其子树的合法下界，
可以直接做分支定界的 bound。（该松弛单独用太弱：n=6 上根松弛在三个 η 上恰为 2/(3η)，
即 4/9、1/3、4/15，远低于 ρ_3，所以必须真分支。）

DFS，子结点按 LP 值排序先走小的，用当前 incumbent 剪枝。

## 4. 闸门与自检（全部通过）

**4.1 复现 ρ_3**：用同一套 row builder 加上"从 ∅ 开始的第一步也是 argmax"，**n=6、7、8**
的全格点 LP 都给出 9/16、7/15、7/18，与 ρ_3(η) 差 ≤ 6.7e−16。
（**这条很重要：它证明 greedy 的最坏值在 n=6→7→8 完全不动，所以 §6 里 PE_1 的下降是 PE_1
自己的性质，不是"n 变大所有算法都变差"的普遍效应**。也和 thm:exact 的 reduced LP 无 n 依赖一致。）

**4.2 η=1 复现 NW 1978 的经典常数**：本 LP 在 η=1（此时 band 强制 f̃=f）给出
**PE_1 = 5/6**，正是 NW 7.1 的 1 − ((K−R)/K)·β(K−R)，β(m)=(1−1/m)^m，R=1,K=3：
1 − (2/3)(1/2)² = 5/6。同一 LP 在 R=0（plain greedy）给 19/27 = 1 − (1−1/3)³。
**两个经典值同时对上**，是整套机器的外部校验。n=7 时 η=1 仍是 5/6（经典结论不依赖 n）。

**4.3 certificate 检查**：把每个 LP 最优解取出来，在 2^n 格点上直接验证 f 单调、f submodular、
band 成立，并**重新跑一遍带对抗 tie 的 PE_1**（重新枚举每个起点的所有 tie-consistent 轨迹、
重新做最终 argmax 的对抗选择、重新按 max_{|A|≤K} f(A) 归一）。九个主结果点
（n=6,7,8 × 三个 η）全部 `CONSISTENT`（LP 值与实例上实跑值差 < 1e−6）。
所以 ≤ 方向有显式实例证书，不只是 LP 数字；≥ 方向靠分支定界跑完（status OK）。

**4.4 η 拆分**：n=6、乘积 2 时，(η_u,η_o)=(1,2)、(2,1)、(√2,√2) 都给 1/2。与 §1 的 scaling 论证一致。

**4.5 last-step collapse 交叉验证**：把两步都分支（每个起点 20 个轨迹）重跑 n=6，incumbent 播种在
collapsed 最优值之上 1e−6：η=2 得 0.500000000（status OK，8,240 次 LP，156 秒）、
η=2.5 得 0.400000000（OK，7,700 次 LP，144 秒）。η=1.5 在 380 秒预算内跑了 19,060 次 LP 未找到更小值

### 最坏实例的机制（从 certificate 直接读出）

f̃ 被造成让**每一个起点的 greedy 都恰好走到 f̃ 值相同的 K-集**：六个起点的 T_v 的 f̃ 全等于 0.76019，
于是最终 argmax 是一个六路 tie，对手直接挑 f 最小的那个（f(T_0)=19/29）。
枚举把候选放进来了，f̃ 的分辨率却把它们全压成同一个数，**枚举的收益被 f̃ 的选择步整个抹掉**。

**n=7, η=2（值 4/9）：诱饵元素。** O={3,4,5}（各 f=1/3），T_0={0,1,2}，多出来的元素 6 是诱饵：
它的单元素预测增益最大（f̃({6})=0.27499 > 0.23570 = f̃({o}), o∈O），所以从**任何**起点 v≠0，
元素 6 都可以是第一步的 argmax；一旦走进 6，那条轨迹的 f̃ 就被封顶在 0.62854，
恰好等于 f̃(T_0)。起点 3,4,5 本来能走到 {3,4,5}（f̃=0.94281，f=1），被对手用诱饵拽走。
于是又变成全体打平、对手挑 f 最小者，f(T_0)=4/9。
**n=6 放不下"O(3) + T_0(3) + 诱饵(1)"，这正是 n=7 严格更差的原因。**

## 6. n 依赖性

ρ_K 是 n-free 的（§4.1 在 n=6,7,8 上逐点验证）。PE_1 不是。下表三个 n 全部是跑完的精确值
（status OK）且每格有显式实例 certificate [VERIFIED-LP]：

| η | n=6 | n=7 | n=8 | ρ_3（n-free） |
|---|---|---|---|---|
| 1.5 | 19/29 = 0.655172 | 16/27 = 0.592593 | 16/27 = 0.592593 | 9/16 = 0.562500 |
| 2.0 | 1/2 = 0.500000 | 4/9 = 0.444444 | 4/9 = 0.444444 | 7/15 = 0.466667 |
| 2.5 | 2/5 = 0.400000 | 43/120 = 0.358333 | **16/45 = 0.355556** | 7/18 = 0.388889 |

η=1.5 与 η=2 在 n=7→8 已不再变化；**η=2.5 仍在下降**（43/120 → 16/45），所以
**不能断言 PE_1 在 n=7 就稳定**，也没有证据说它有下确界。n=8 的三格都还在 ρ_3 的
相对位置上不变（1.5 仍在上方，2 与 2.5 仍在下方）。

**这一条对论文的措辞很关键**：ρ_K 是"对所有实例（不限 n）"的最坏值。若要在同一量词下比较，
PE_1 的最坏值 ≤ min{PE_1(n=6), PE_1(n=7), PE_1(n=8)} = PE_1(n=8)，于是
**η ∈ {2, 2.5} 时 PE_1 在同量词下严格劣于 greedy，η ≥ 1.75 亦然（n=7 已足够）**。
只有把 n 钉死在 2K 时，PE_1 才在三个 η 上都严格更好。这也说明"PE_1 打不打得过 greedy"
这句话本身在本模型里是 ill-posed 的，必须把 n 写进量词。

## 7. 闭式猜想（n=6）　[CONJECTURE]

n=6=2K、K=3 上，15 个 η 网格点（1.0, 1.1, 1.2, 1.25, 1.4, 1.5, 1.6, 1.75, 1.9, 2.0, 2.1, 2.25,
2.5, 3.0, 4.0）全部与下式逐位相符（其中 5 个点用于拟合、其余 10 个是样本外确认）：

```
PE_1^{n=2K}(K=3, η) = min { 1/η ,  (9η − 4) / (2(3η² + η − 1)) }
```

分段点是两支相等处 3η² − 6η + 2 = 0 的根 **η* = 1 + 1/√3 ≈ 1.577350**；η ≥ η* 时取 1/η。
（下面几条代数恒等式经 sympy 确认 [VERIFIED-SYMBOLIC]：1−v = (2η−1)(3η−2)/(2(3η²+η−1))；
B(1)=1/4；v=1/η 的根为 1 ± 1/√3；3η²+η−1 的判别式 = 13；v(1)=5/6, v(3/2)=19/29, v(2)=7/13。
这些只是闭式自身的代数性质，**不构成闭式成立的证明**。）

与 NW 7.1 的形状对照：把低支写成 1 − ((K−R)/K)·B(η)，得
B(η) = 3(2η−1)(3η−2) / (4(3η² + η − 1))，且 **B(1) = 1/4 = β(K−R) = (1−1/2)²**，
即 η=1 端点正好退化成 NW 的 β。但 B(η) 的分母 3η²+η−1 判别式为 13，**不能有理分解**，
所以它不是 (1 − 1/(cη))^{K−R} 那种"每步一个因子"的形状；把 η 因子塞进 β 的朴素猜法
1 − ((K−R)/K)(1 − 1/(η(K−R)))^{K−R} 在 η=1.5 给 19/27 = 0.7037，与真值 19/29 = 0.6552 不符，
**已被否证**。

n=7 只有 6 个 η 点（§5），不足以拟合；未提猜想。

**禁止声称**：该闭式对 n>6 成立（**已被 n=7 证伪**：η=1.5 时闭式给 19/29 = 0.6552，
n=7 的真值是 16/27 = 0.5926）；对 K≠3 成立；对 R≥2 成立。

## 8. 结论句（逐 η，按 TASKS6 的两分支写法）

- **η = 1.5**：n=6 上 PE_1 = 19/29 > ρ_3 = 9/16，差 **+0.0927**；n=7 与 n=8 上 PE_1 = 16/27 > 9/16，
  差 **+0.0301**。**属于"PE_1 > ρ_3"分支**：在已算到的 n（6,7,8）上枚举严格有收益，收益随 n 掉了约 2/3
  后在 n=7→8 稳住。是否对所有 n 都 > 9/16 未知。
- **η = 2.0**：n=6 上 PE_1 = 1/2 > ρ_3 = 7/15（差 **+0.0333**，且恰好等于确定性天花板 1/η）；
  但 n=7 与 n=8 上 PE_1 = 4/9 < 7/15（差 **−0.0222**）。
  **属于"PE_1 ≤ ρ_3"分支（n ≥ 7）**：最终按 f̃ 取 argmax 的 η 损失不但抵消了枚举收益，还超额抵消。
- **η = 2.5**：n=6 上 PE_1 = 2/5 > ρ_3 = 7/18（差 **+0.0111**，等于 1/η）；n=7 上 PE_1 = 43/120 < 7/18
  （差 **−0.0306**），n=8 上进一步降到 16/45（差 **−0.0333**）。
  **同 η=2，属于"PE_1 ≤ ρ_3"分支（n ≥ 7）**，且在 n=8 仍未见底。

**给 open problem 段与 Tianming 讨论的一句话**：在这个预测模型里，"枚举起点"这一步的收益和
"用 f̃ 选最终答案"这一步的损失是两件独立的事；n 足够大时后者占优，所以 NW 1978 的有限-K 改进
**不能原样搬到 prediction-augmented 设定**。这构成 greedy 在有限 K 的最优性的**正面证据**
（在 R=1、K=3、n ≤ 8 的范围内），但不是证明。若要救 partial enumeration，应改最终选择规则
（例如输出 f̃ 最大的**同时**要求它是某个 greedy 轨迹的终点并加 η 修正，或直接对 K-子集穷举，
