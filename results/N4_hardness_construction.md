## 0. LP 的确切形式（与 T2 一致，为自足起见重述）

变量 `F(x,y)`，`x = |S∖O| ∈ 0..n−K`，`y = |S∩O| ∈ 0..K`；balanced 区域上 `G = Ĝ_{x+y}`，
其余 `G(x,y)` 自由。约束：`F` 单调、submodular（四类二阶差分 ≤ 0）、`F(0,0) = 0`、
`F(0,K) = 1`（OPT 归一化）、`F ≤ 1` 于 `0 < x+y ≤ K`、单元素误差带
`ΔF/η_u ≤ ΔG ≤ η_o ΔF`（δ = 0，`η_u = η_o = √η`）、`Ĝ_0 = 0`。目标 `min F(K,0)`。

两个 balanced 定义：`true` 为 `|y − K|S|/n| ≤ τ`，`ysmall` 为 `y ≤ τ`。

## 3. 闭式（步骤 2 + 3 的答案）

记

```
k1 = η(K−1) + 1,      q = 1 − 1/k1,      ν = η/(η−1)
j  = K + 1 − ⌈η⌉      (截断到 [0, K])
m* = ⌈ηK⌉ − 1,        T = j + m*
D  = max{ q^j/(Kη),  q^j (ν^{m*}/K − 1) / ( η(ν^{m*} − 1) − m* ) }
```

则 LP 的 n→∞ 极限值为

```
value(K, η) = 1 − q^j + (K − j)·D
            = V_j(η) + (K − j)·( D − q^j/(Kη) )          （V_j 是 R10 的闭式）
```

最优解（`τ = 1`；`τ ≥ 2` 未测，见 caveats）由三条序列给出，
`r_x = 1 − F(x,0)`（残差）、`g_x = Δ_y F(x,0)`（o 元素单元素增益）、`d_x = Δ_x F(x,0)`：

```
相位 1（0 ≤ x ≤ j）:     r_x = q^x,          g_x = q^x/K,        d_x = q^x/k1
相位 2（j < x ≤ T）:     r_x = q^j − (x−j)D,  g_x = ν^{x−j} q^j/K − ηD(ν^{x−j} − 1),  d_x = D
尾部（x > T）:           r_x = 0,             g_x = 0,            d_x = 0
```

（在 x = T 处三者闭合：`g_T = r_T = d_T`，这正是定出 D 的方程。）

由此

```
F(x,y) = 1 − r_x + [y ≥ 1]·g_x + max(y−1, 0)·(r_x − g_x)/(K − 1)
Ĝ_s    = (1/η_u) · Σ_{x < s} g_x                （balanced，只依赖 |S|）
G(x,y) = Ĝ_{x+1} + η_o·( F(x,y) − F(x,1) )      （y ≥ 2，unbalanced）
```

几点解读：

- **相位 1 逐字是 R7 / U_K 实例**：把上式代入得 `F(x,y) = 1 − q^x(1 − y/K)`，
  即 RESEARCH_STATE R7 的 `1 − a^x(1 − y/K)`，其中 `a = q = 1 − 1/(η(K−1)+1)`
  正是 R7 的 `a = 1 − 1/(âK)`、`âK = η(K−1)+1`。[VERIFIED-SYMBOLIC]
- **相位 1 的三个约束同时取等**：coverage（`K g_x = r_x`，即 F 在 y 上线性）、
  coherence lemma R3(ii)（`g_{x+1} = η(d_x + g_{x+1} − g_x)`）。这两条给出
  `d_x = r_x/k1`，于是 `r_{x+1} = q·r_x`。[VERIFIED-SYMBOLIC]
- **相位 2**：`d` 冻结为常数 D，coherence 仍取等，于是 `g` 以 `ν = η/(η−1) > 1` 的
  速率**发散式下降**：`g_x = ηD − (ηD − q^j/K)·ν^{x−j}`。链条必须在 `g` 变负之前
  用完残差，这就是 `g_T = r_T` 这一"打靶"条件，它唯一定出 D。[VERIFIED-SYMBOLIC 恒等式]
- `Ĝ` 的形状：`Ĝ_{s+1} − Ĝ_s = g_s/η_u`（band_lo 在 (s,0) 的 y 方向处处取等）。
  相位 1 内 `Ĝ_s = k1(1 − q^s)/(K√η)`，饱和值 `k1/(K√η)`；相位 2 内衰减更慢再收尾。
- `j` 与 `m*` 本身也是闭式：`j = K+1−⌈η⌉`（与 R10 的分段 `η ∈ [K−j, K−j+1]` 一致），
  `m* = ⌈ηK⌉ − 1`。[VERIFIED-LP]：在 264 个 (K, η) 点上，暴力 `argmax_m D(m)` 与
  这两个公式逐点相符（`results/N4_check.py` C 节，K = 3..24，η ∈ {5/4, 4/3, 3/2, 7/4,
  2, 9/4, 7/3, 5/2, 3, 7/2, 4, 5}）。

```
ρ_K^LP(η) = V_j(η)  ≤  relaxF 极限  <  U_K(η),      超额 = (K−j)(D − q^j/(Kη)) → 0（极快）
```

所以这套 balanced 对称化 + η 带的技术在固定 K 下能证到的最好常数**就是** predictive greedy
的 reduced-LP 最坏值 `ρ_K^LP`（外加一个 K ≥ 16 就已在 1e−12 以下的修正），
**不是** `U_K`。K → ∞ 时两边都 → `1 − e^{−1/η}`，与 R8 一致。

**这同时解释了 T2 的"意外观察"**（(n,K) = (8,3)、τ=1、`y ≤ τ` 时 relaxF 值逐点 = ρ_3(η)）：
K=3 的相位 2 尾巴长度是 `T = j + m*`（η=1.5 时 T=6，η=2 时 T=7），而 n = 8 只给出
`X = n − K = 5` 列，**尾巴放不下**，族 L 的长程链因此不存在，LP 值恰好掉回
`V_j = ρ_3^LP(η)`。把 n 加到 10（X = 7 ≥ T）值立刻升到闭式：

## 4. 紧约束清单（步骤 4；即使 PASS 也按要求交出）

`results/N4_duals.py` 输出第一阶段 LP 的全部非零对偶乘子，并按结构族归类
（族的定义用第 3 节的 `j`、`T`）。完整数据在 `results/N4_tight.json`。

### 4.1 极限 LP（`y ≤ τ`，η = 2，τ = 1）——**全部紧约束 100% 落入 8 个族**

| 族 | 约束 | 位置 | 个数 | 含义 |
|---|---|---|---|---|
| A | `band_lo` 方向 y | `(x,0)`，x = 1..T | T | `Ĝ_{x+1} − Ĝ_x = g_x/η_u` |
| B | `band_up` 方向 x | `(x,1)`，x = 0..T−2 | T−1 | coherence R3(ii) 取等 |
| C | `submod` 方向 yy | `(x,i)`，x ≤ j，i = 0..K−2 | (j+1)(K−1) | F 在 y 上线性（coverage 取等） |
| D | `submod` 方向 xx | `(x,0)`，j ≤ x ≤ T−2 | m*−1 | 相位 2 的 `d_x` 冻结 |
| E | `mono` 方向 x | `(x,K)` | K−2 | 顶行 `F(·,K) ≡ 1` |
| F | `submod` 方向 xx | `(x,K)` | 2K | 顶行平坦 |
| G | `mono` 方向 y | `(T,y)` | K−2 | 尾部 `F(T,·)` 平坦 |
| L | `band_up (j,1) y` + `band_up (x,2) x`（x = j..T−1）+ `band_lo (T,1) y` | — | m*+2 | **y=2 长程链** |

计数验证（η=2，τ=1）：

| K | j | T | 总数 | A | B | C | D | E | F | G | L | 未分类 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 3 | 2 | 7 | 38 | 7 | 6 | 6 | 4 | 1 | 6 | 1 | 7 | 0 |
| 4 | 3 | 10 | 58 | 10 | 9 | 12 | 6 | 2 | 8 | 2 | 9 | 0 |
| 5 | 4 | 13 | 80 | 13 | 12 | 20 | 8 | 3 | 10 | 3 | 11 | 0 |
| 6 | 5 | 16 | 104 | 16 | 15 | 30 | 10 | 4 | 12 | 4 | 13 | 0 |

**族 L 是关键新发现**。A + B + C + D 复现的正是 reduced LP（R6/R10）的四类约束：

- A + B（在同一个 `Ĝ` 增量上一上一下）⟹ `Δ_y F(x+1,0) ≤ η·Δ_x F(x,1)`，
  配合 submod 给出 `d_t ≥ g_{t,i}/η`；
- 同一个 `Ĝ_{x+1}` 同时服务 `(x,0)→(x+1,0)` 与 `(x,0)→(x,1)`（因为 balanced 区域上
  `G` 只依赖 `|S|`，两个邻居的 `|S|` 都是 `x+1`），这**正是 poly-query 对称化的全部作用**；
- C 给 coverage，D 给 `d` 单调。

而族 L 在 reduced LP 里**没有对应物**：它是一条穿过 unbalanced 的 y=2 行的长程链

```
Ĝ_{T+1} − Ĝ_{j+1} + Δ_y F(T,1)/η_u  ≤  η_o·[ F(T,2) − F(j,1) ]
```

（把 `band_up (j,1) y`、`band_up (x,2) x` 沿 x = j..T−1、`band_lo (T,1) y` 相加即得）。
`Ĝ` 的增长率是 `g/η_u`，右边的增长率是 `η_o·Δ_x F(·,2)`，二者在 `g = ηd` 时正好相等
（刀锋），于是端点项决定一切——这就是 `D` 被顶高到 `> q^j/(Kη)`、
LP 值被顶高到 `> V_j` 的机制。**这是"技术极限 = ρ_K^LP + 超额"里超额项的来源。**

## 5. 对论文的影响（需人工判断）

1. T2 结论 3 的措辞需要改：不是"hardness 值贴着 `U_K`"，而是"贴着 `ρ_K^LP = V_j`，
   严格小于 `U_K`"。n = 8K 的数值未收敛。
2. 好消息：hardness 侧的极限与算法侧 R10 的 reduced-LP 值**几乎重合**，
   而 R10 已有 K = 2,3,4 的对偶证书（N1 若成功则一般 K）。这意味着
   "poly-query 最优比 = `ρ_K`（渐近 `1 − e^{−1/η}`）"这个陈述的两边都有解析形式。
3. 本节的显式 (F, G) 可以直接写进论文作为 hardness 实例族的候选：它 monotone、
   submodular、误差恰好在 η 带内（δ = 0）、`G` 在 `y ≤ τ` 上只依赖 `|S|`。
   但要变成真正的 poly-query 定理还需要 N5 的 concentration 论证把
   `true` band 换成 `y ≤ τ`，并承担相应的 δ（T2 结论 1 的闭式
   `1 + δ = (a^τ K/(K−τ))²`）。**本节的构造只对 `y ≤ τ` 的 balanced 定义是可行的**；
   在有限 n 的 `true` 定义下它不可行（y ≥ 2 的远端 balanced 块会强制
   `G(x,y) = Ĝ_{x+y}`，而构造里那里取的是 `Ĝ_{x+1} + η_o(...)`）。

## 6. Caveats / 未完成

- `τ = 2` 未系统测试；`j`、`m*` 的闭式只在 τ = 1 下验证。η 的拆分只测了
  `η_u = η_o = √η`（T2 曾报告拆分不影响，但本节未复核）。
- `η > K−1`（`j ≤ 1`）时闭式只是上界；(K, η) = (5, 4) 是 `η ≤ K−1` 内唯一
  差 3.2e−7 的点，机制未查明。
- 族 L 的长程不等式给出了超额项的**机制**，但没有把超额项独立地解析求解出来；
  第 3 节的 D 是通过"打靶条件 `g_T = r_T` + `m* = ⌈ηK⌉−1`"得到的，
  后者是数值猜测（264 点），不是证明。
- 全部 LP 都是网格（对称化）LP。T2 已在 (8,3) 上用全格点 oracle 交叉验证过对称化
  在 relaxF 模式下正确；本节没有重做全格点交叉验证。
- 一般 K 的 submodularity / opt_norm 只有 42 组参数的精确有理逐点验证，
  没有一般 K 的符号证明。
