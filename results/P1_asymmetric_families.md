## 0. 记号与 LP 骨架（与 N4 / T2 一致，为自足重述）

隐藏集合 `O`，`|O| = K`，ground set 大小 `n`。族 (a) 把 `O` 再划分成 `g` 个块
`O_1..O_g`（大小 `blocks`），`N∖O` 是背景块。状态是计数向量
`v = (x, y_1, ..., y_g)`，`x = |S∖O|`、`y_i = |S∩O_i|`；`g=1` 就是原来的 `(x,y)` 族。

变量：`F(v)`、`Ĝ(s)`（`s = 0..n`）、以及区域外的自由 `G(v)`。约束：

| 约束 | 形式 |
|---|---|
| mono | `Δ_i F(v) ≥ 0`，每个方向 `i ∈ {x, 1..g}` |
| submod | `Δ_ℓ Δ_i F(v) ≤ 0`，每个有序对 `(i,ℓ)`，含 `i=ℓ` |
| opt_norm | `F(v) ≤ 1` 于 `0 < |S| ≤ K` |
| eq | `F(0⃗) = 0`、`F(O) = 1`、`Ĝ(0) = 0` |
| band | `ΔF/η_u ≤ ΔG ≤ η_o ΔF`，每条边；`η_u = η_o = √η`，`δ = 0` |
| O-free | `G(v) = Ĝ(|S|)` 对区域内的每个 `v` |

目标 `min F(K, 0⃗)`。

**submodularity 的充分条件与集合层面的关系**：mono + submod 两行正是
`paper/sections/appendix_proofs.tex` 的 `lem:app-count` 的假设。该引理**本来就是对一般 r-块划分
陈述的**（`N = N_1 ∪ … ∪ N_r`，`h(S) = H(|S∩N_1|,…,|S∩N_r|)`），所以它**逐字适用**于族 (a) 的
`r = g+1` 块划分，不需要任何推广：`Δ_i H ≥ 0`（全部 i、全部 v）加上
`Δ_ℓ Δ_i H ≤ 0`（全部有序对）蕴含 `h` 单调 submodular。本任务没有在集合层面另做数值抽查，
因为引理已覆盖；引理本身在论文里的标签是 [HAND-PROOF-UNREVIEWED]（三行论证，无 oracle）。

**band（O-无关区域）的精确定义。** 对大小为 `s` 的固定查询 `S` 与均匀随机的（带标号的）
`O_1..O_g`，计数向量服从**多元超几何分布**，类大小 `(p_1,…,p_g, n−K)`、样本量 `s`：

```
Pr[y⃗ | |S| = s] = [ Π_i C(p_i, y_i) ] · C(n−K, s−Σy) / C(n, s)
```

两个区域（都用精确有理数算，`math.comb` + `Fraction`，无浮点）：

- `typ(s)`：按概率降序贪心累加，直到尾概率 `≤ 1/(4Q)` 为止的**最小典型集合**（分布单峰，所以贪心
  给出的就是区间）。这是"`Q` 次查询全部落在区域内的概率 `≥ 3/4`"所需要的最小区域。
- `typmin(s) = { y⃗ : Pr[y⃗ | s] > 1/(4Q) }`：**任何**尾质量 `≤ 1/(4Q)` 的区域都必须包含它。
  于是 `typmin ⊆ 任何合法区域`，而区域越小约束越少、LP 最小值越低，所以
  **`LP(typmin) ≤ LP(任何合法 size-based 区域)`**，`LP(typmin)` 是对整族的下界。

对照用的两个非概率区域：

- `f3`：`{Σy ≤ 1} ∪ {x > t*}`，即 `results/F3_hardness_full.tex` / `app:hardness-anysize` 的区域，
  `t* = j + m*`。
- `ysmall(τ)`：`{Σy ≤ τ}`；`twosided(τ)`：`{ |Σy − K|S|/n| ≤ τ }`。

`Q = n^c`，主参数 `c = 2`（TASKS9 指定 `Q = n²`）。

## 1. §1 前置判断：一般 (x,y) 对称 LP

### 1.1 第一个必须先说清楚的事：这个 LP 永远可行

`f(S) = |S∩O|/K + |S∖O|/(Kη)`、`f̃(S) = |S|/(K√η)` 是 modular 的，`f̃` 处处只依赖 `|S|`，
所以它对**任何**区域都是可行点，误差恰为 `η`，`F(K,0) = 1/η`。这正是
`app:necessity`（prop:necessity）的实例。

**推论：`LP ≤ 1/η` 恒成立，"不可行 / IIS"不是这条路线的正确产物，正确的产物是 LP 的值。**
下面全部按值报告。值越小 = hardness 越强；`1/η` 相当于什么新东西都没证出来。

### 1.2 指定点 K=3, n=48, c=2, η=2（Q = n² = 2304, 1/(4Q) = 1.085e−4）

   （变量布局、区域、band 都重写），所以这是对 N4 主结论的一次独立复算。[VERIFIED-LP]
2. **精确 typical-set band 把值顶到恰好 `1/η = 0.5`**，即塌缩到 modular 实例，`> ρ_3(2)`，

**一句人话引理（impossibility 观察，[VERIFIED-LP 有限参数]）**

> 如果构造的 O-无关区域只依赖查询大小与计数向量（即 size-based），并且要求 `Q = n^c` 次查询
> 以概率 ≥ 3/4 全部落在区域内，那么当 `c ≥ 1.5` 时，count-grid LP 的最优值恰为 `1/η`：
> 这样的构造证不出任何比 prop:necessity 的 modular 实例更强的东西。
> 机制：`Pr[|S∩O| = 2 | |S| = s] ≈ C(K,2)(s/n)²`，要把 `y = 2` 排出区域需要
> `C(K,2)(sK/n)² ≤ 1/(4n^c)`，在 `s ≈ K`、`c ≥ 2` 时对**一切 n** 都不成立；
> 一旦 `y = 2` 进入区域，`x` 方向与 `y` 方向的单元素增益在每个 `s ≤ K` 上被同一个
> `Ĝ` 增量夹住，`F(K,0) ≥ F(0,K)/η = 1/η`，而 modular 实例给出上界 `1/η`。

这条观察**不排除定理本身**（任意大小查询下最优常数仍可能是 `1 − e^{−1/η}`），
它排除的是"用 size-based typical band 的 count-grid 构造"这一条证明路线。
`app:hardness-anysize` 之所以还能拿到 `W_K(η)` 且 `Q = Θ(n²)`，正是因为它的区域
`{y≤1} ∪ {x > t*}` **不是** typical set：它的正确性论证不是"每个大小的查询都典型"，
而是"跳出区域必须同时满足 `y ≥ 2` 与 `s ≤ t*+K`"，于是那个 `Θ(n²)` 里的常数
`1/(2K²(t*+K)²)` 是必需的，`Q = n²` 字面值（TASKS9 的写法）本身不可达。

### 1.4 对候选族 (b) 的前置判断

族 (b) 是一般 `(x,y)` 对称族的**子族**（`F` 被写死成 `1 − a^x(1−y/K) + φψ`，`G` 自由）。
因此 `LP(b) ≥ LP(一般 (x,y))`。在 `typ` band 下后者已经 `= 1/η`，所以：

> **(b) 在精确 typical band 下不可能给出优于 `1/η` 的常数。**

这就是 TASKS9 要求的前置判断，结论是**否定**。§3 仍然跑了 (b)，目的是拿到 IIS 与闭式条件。

两半解释，标签不同：

- **等大小、块大小 = 1（`(1,1,1)`、`(1,1,1,1)`）：有严格论证。** 置换块标号是全部约束、区域
  （多元超几何分布对块置换对称）与目标 `F(K,0⃗)` 的对称性；LP 约束线性，所以把任一可行解
  对 `g!` 个置换取平均仍可行、目标不变，平均解只依赖 `{y_i}` 的 multiset，而块大小为 1 时
  multiset 就等价于 `Σy_i`。故值必然等于 `(x,y)` 族。[HAND-PROOF-UNREVIEWED]，但 LP 数值一致。
- **块大小 ≥ 2 或不等大小（`(2,1)`、`(2,2)`、`(3,1)`）：只有数值。** 这时 multiset 严格细于
  `Σy_i`（例如 `(0,2)` 与 `(1,1)` 都有 `Σ=2` 却是不同状态），对称化论证不适用，
  但 LP 值仍逐点相同。[VERIFIED-LP 有限参数 28 点]，一般参数下是 [CONJECTURE]。

### 2.3 关键检查点：`S ⊇ O` 处 `F` 的 `x`-边际

TASKS9 点名的死点是"`F` 在 `y=K` 处对 `x` 平坦（零边际）"。56 个解上 `Δ_x F` 在
`y⃗ = 满块`（`S ⊇ O`）处的取值分布：

| 区域 | `Δ_x F(满块)` = 0 的解 | `> 0` 的解 | LP 值 |
|---|---|---|---|
| `f3` | **28 / 28** | 0 | `W_K(η)`（强） |
| `typ` | 16 / 28 | **12 / 28**（0.0789…0.2222，如 K=3,η=2 的 1/(Kη) = 0.166667） | `1/η`（空） |

LP 最优是退化的，所以同一个值上既有零边际也有正边际的顶点；关键是**哪一侧出现正边际**：

> `f3` 区域（值 = `W_K(η)` < `1/η`）下，`Δ_x F(满块) = 0` 在全部 28 个解上成立；
> 只有当值退到 `1/η` 时才出现正边际（modular 解的 `Δ_x F = 1/(Kη)`）。

即：**正的 `x`-边际做得到，但只在值已经塌缩到 `1/η` 的解上做得到。**
分块没有把这两件事解耦。这正面回答了 TASKS9 的检查点：不是"做不到正边际"，
而是"正边际与非平凡常数在 count-grid 里不共存"。
（严格讲这是 56 个 LP 顶点上的观察，不是"零边际是 `W_K` 的必要条件"的证明，标 [CONJECTURE]。）

## 3. §3 族 (b)：非饱和 F

### 3.1 LP 化的选择与理由

`F(x,y) = 1 − a^x(1 − y/K) + φ(x)·ψ(y)`，`φ` 与 `ψ` 同时自由时乘积项是**双线性**的，
不是 LP。TASKS9 给的三个可 LP 化的办法里选**固定 `ψ` 的形状、自由优化 `φ`**，理由：

1. 反过来（固定 `φ`、自由 `ψ`）把 `x` 方向的衰减写死，而 `x` 方向正是 band 出问题的方向
   （N4 的相位 2 就是在改 `x` 的衰减率），自由度放错了地方。
2. "直接自由 `C(x,y)`"就是 §1 的一般 `(x,y)` LP，其值已在 §1 得到；按 TASKS9 的逻辑，
   只有在前置判断可行时做结构化才有意义，而前置判断（§1.4）是否定的，
   所以做 (b) 的唯一价值是**拿 IIS 与闭式条件**，不是拿更好的常数。
3. 固定 `ψ` 后 `φ(x)` 有 `n−K+1` 个自由变量，仍然是一族而不是单点，符合"让 LP 在整族里搜"。

测试的 `ψ` 形状：`ψ ≡ 1`（纯 `x` 加性修正）、`ψ(y) = y/K`、`ψ(y) = 1[y=K]`（只动顶行）、
`ψ(y) = (y/K)²`。`a ∈ {q = 1 − 1/(η(K−1)+1), 1 − 1/(ηK)}`。

### 3.3 两个 2-行 IIS 及其闭式含义

IIS 用 deletion filter（先按约束族成组删，再 64/16/4/1 分块逐行删）得到。

**IIS-b1（`ψ = 1[y=K]`，η=2, a=q, f3 区域；2 行）**

```
K=3, n=48 (margin 7.91e-3):  band_up 在 (44, 2) 的 x-边  +  band_lo 在 (45, 1) 的 y-边
K=4, n=64 (margin 9.27e-3):  band_up 在 (59, 3) 的 x-边  +  band_lo 在 (60, 2) 的 y-边
一般形状：           band_up 在 (x, K−1) 的 x-边  +  band_lo 在 (x+1, K−2) 的 y-边
```

两条边终点的 `|S|` 相同（`= x+y+2`），区域内 `G = Ĝ(|S|)`，所以它们共用同一个 `Ĝ` 增量，相加得

```
Δ_y F(x+1, y)  ≤  η · Δ_x F(x, y+1),      y+1 ≤ K−1
```

对 `F = 1 − a^x(1−y/K)`（`ψ` 在 `y ≤ K−1` 上为 0，修正项在这两条差分里消失）代入并在
`y = K−2` 取最紧，sympy 化简得 `η·Δ_x − Δ_y = a^x(η − aη − a)/K`，即条件

```
a ≤ η/(1+η)
```

而 `q − η/(1+η) = η(K−2) / ((η+1)(Kη−η+1)) > 0` 对**一切 K ≥ 3、η > 0**。
所以：

> **一句人话引理 [VERIFIED-SYMBOLIC]：** 以 `a = q` 的 R7/`U_K` 实例为底、修正项只支撑在
> `y = K`（"只把顶行抬起来"）的族，对一切 `K ≥ 3` 与一切 `η > 1` 都违反 band，
> 违反发生在 `y = K−2 → K−1` 的 `y`-边与 `y = K−1` 行的 `x`-边之间，与 `n`、与修正项的大小无关。

这解释了 N4 记录的"单一修正项破带"：破带点不在 `(K,0)` 而在顶行下面两行，
并且它是**结构性的**（`a` 太大），不是修正项调小就能绕开的。

**IIS-b2（`ψ ≡ 1`，η=1.5, a=q, f3 区域；2 行）**

```
K=3, n=48 (margin 2.84e-3):  band_lo 在 (43, 2) 的 y-边  +  band_up 在 (45, 0) 的 y-边
K=4, n=64 (margin 2.99e-3):  band_lo 在 (57, 3) 的 y-边  +  band_up 在 (60, 0) 的 y-边
一般形状：           band_lo 在 (x, K−1) 的 y-边  +  band_up 在 (x+K−1, 0) 的 y-边
```

两条边同样落在同一个 `Ĝ` 增量上（`|S|` 都从 `x+K−1` 走到 `x+K`），相加得

```
Δ_y F(x, K−1)  ≤  η · Δ_y F(x+K−1, 0)
```

`ψ ≡ 1` 时修正项在每个 `y`-差分里抵消，代入得 `η a^{K−1} ≥ 1`，即

```
a ≥ η^{−1/(K−1)}
```

sympy 给出 `η·Δ_y^右 − Δ_y^左 = a^x(η a^{K−1} − 1)/K`。[VERIFIED-SYMBOLIC]

**闭式条件 vs LP 状态（f3 区域，`ψ ∈ {≡1, 1[y=K]}` × 2 个 `a` × 2 个 `n` × 4 个 (K,η)
= 32 个点，`32/32` 逐点一致）**

`a = q` 的一角（`a = 1 − 1/(ηK)` 的 16 点同样全对，见 JSON 的 `S3_certificates`）：

| K | η | `q` | `η^{−1/(K−1)}` | `η/(1+η)` | `ψ≡1` 预测 / LP | `ψ=1[y=K]` 预测 / LP |
|---|---|---|---|---|---|---|
| 3 | 1.5 | 0.7500 | 0.8165 | 0.6000 | INFEASIBLE / INFEASIBLE | INFEASIBLE / INFEASIBLE |
| 3 | 2 | 0.8000 | 0.7071 | 0.6667 | FEASIBLE / FEASIBLE | INFEASIBLE / INFEASIBLE |
| 4 | 1.5 | 0.8182 | 0.8736 | 0.6000 | INFEASIBLE / INFEASIBLE | INFEASIBLE / INFEASIBLE |

## 4. §4 泄漏检查记录

对每个可行解跑两个攻击。**读这张表必须同时看"是否在区域内"这一列**：

- 若 N∖{e}（或 N∖{e,f}）的全部身份类都落在 O-无关区域内，则 `G` 在这些点上被约束成
  `Ĝ(|S|)`，`PASS` 是**构造性的**（区域定义本身就禁止泄漏），这才是真正的通过。
- 若它们落在区域外，`G` 在那里是自由变量，某个 LP 最优解碰巧取成相等**不能**说明族不泄漏；
  显式闭式族在那里就是泄漏的（见 4.3）。

### 4.1 N∖{e} 攻击（J5）

对每个块 `i` 取 `e ∈ O_i`（状态 `(n−K, …, p_i−1, …)`）与 `e ∉ O`（状态 `(n−K−1, p⃗)`），
比较 `G` 值。

共检查 78 个可行解（`S1` 6 个 + `S2` 56 个 + `S3` 16 个），**0 个 LEAK**。
按区域分（括号是该区域的解数）：

| 区域 | 全部身份类在区域内？ | `G` 值最大差 | 判定 |
|---|---|---|---|
| `typ`（37） | **是**，37/37 | 0.0 | **PASS（构造性）** |
| `typmin`（1） | **是** | 0.0 | **PASS（构造性）** |
| `f3`（37） | **是**，37/37（`x ≥ n−K−1 > t*`） | 0.0 | **PASS（构造性）** |
| `twosided τ=1`（1） | N∖{e} 是；N∖{e,f} **否** | 0.0 | N∖{e} PASS（构造性）；(n−2) 不可用 |
| `ysmall τ=1/τ=2`（2） | **否**（`s = n−1, n−2` 时区域为空） | 0.0 | PASS**仅对该 LP 解成立**，不可用 |

为什么 `typ` 的 `s = n−1` 一定在区域内：`Pr[e ∈ O_i] = p_i/n`、`Pr[e ∉ O] = (n−K)/n`，
都远大于 `1/(4n²)`，所以贪心典型集在 `s = n−1` 处包含全部 `g+1` 个身份类。
`f3` 则因为 `x ≥ n−K−1 > t*` 而全部落在 `{x > t*}` 里。

### 4.2 全部 (n−2)-集合类攻击

身份组合：两个都在背景、一个背景 + 一个在块 `i`、两个都在块 `i`（`p_i ≥ 2` 时）、
分别在块 `i` 与块 `j`。对 `blocks = (2,2)` 共 6 类，`(1,1,1)` 共 4 类，`(3,)` 共 3 类。

结论：`typ`/`typmin`/`f3` 全部**构造性 PASS**（所有类都在区域内，
`Pr ≳ p_i p_j/n² ≫ 1/(4n²)`，`f3` 则靠 `x > t*`）；`twosided τ=1` 的
"两个都在同一块"类落在区域外（该类的 `Σy = K−2`，超出 `|Σy − K|S|/n| ≤ 1`），
`ysmall` 全部落在区域外，这两种区域的 (n−2) 检查不可用。

汇总：**78 个可行解，0 个 LEAK；其中 75 个是构造性 PASS（攻击点全在 O-无关区域内），
3 个（`ysmall` 2 个、`twosided` 的 (n−2) 检查 1 个）是"仅对该 LP 顶点成立"，不可引用。**
逐行记录在 JSON 的 `S4_leak`（含 `Nminus1_in_region` / `Nminus2_in_region` 两列）。

### 4.3 对 `app:hardness` 显式闭式族的 J5 攻击（复核，非本任务的解）

`app:hardness` 的 `G_O` 在 `y ≥ τ` 分支是 `1 − a^{x+τ}(K−y)/(K−τ)`，其 O-无关区域是
`{y ≤ τ}`，不覆盖 `s = n−1`。代入：

```
e ∈ O :  x = n−K, y = K−1  ⟹  G = 1 − a^{n−K+τ}/(K−τ)
e ∉ O :  x = n−K−1, y = K  ⟹  G = 1
差 = a^{n−K+τ}/(K−τ) > 0
```

所以该族在精确算术下**确实泄漏**（差是 `n` 的指数小量但非零，精确值 oracle 下一次查询即可
区分）。这与 `app:hardness-anysize` 把区域扩成 `{y≤1} ∪ {x > t*}` 的动机一致：扩区域后
`s = n−1` 落进 `{x > t*}`，泄漏被堵上。**本节确认 J5 攻击只打 `app:hardness`（查询 ≤ K 的定理，
那里 `s = n−1` 根本不是合法查询，所以攻击不构成对定理的反例），不打 `app:hardness-anysize`。**
[HAND-PROOF-UNREVIEWED]（两行代入，无 oracle；本任务没有为它写脚本）。

## 5. §5 IIS / 闭式

### 5.1 `F(K,0) ≥ 1/η` 的对偶证书（typ band 下塌缩的"人话"机制）

不可行性在这里不存在（§1.1），所以对应 IIS 的产物是**下界的对偶证书**：
`typ` band、K=3、n=48、η=2 的最优对偶只有 **10 个非零乘子**，等式乘子是
`(F(0,0)=0) ↦ 0.5`、`(F(0,K)=1) ↦ 0.5`、`(Ĝ(0)=0) ↦ 0`，即证书直接把 `1/η = 0.5` 
写成 `0.5 × F(0,K)`：

| 约束 | 位置 | 方向 | 乘子 |
|---|---|---|---|
| `band_up` | (1,0) | x | −0.707107 = −1/√2 |
| `band_lo` | (1,0) | y | −0.707107 |
| `band_up` | (2,1) | x | −0.707107 |
| `band_lo` | (2,1) | y | −0.707107 |
| `band_lo` | (2,2) | y | −0.707107 |
| `band_up` | (1,3) | x | −0.707107 |
| `submod` | (2,0) | (x,y) | −1.000000 |
| `submod` | (0,0) | (x,y) | −0.500000 |
| `submod` | (0,1) | (x,x) | −0.500000 |
| `submod` | (0,3) | (x,x) | −0.500000 |

结构：`band_up`（x 方向）与 `band_lo`（y 方向）在同一个 `Ĝ` 增量上成对出现，
每一对给出 `Δ_x F ≥ Δ_y F / η`；`submod` 把这些不等式沿网格搬运到同一条链上；
求和得到 `F(K,0) ≥ F(0,K)/η`。K=4、η=2 的证书是 15 行、同样的结构
（JSON 的 `S5_duals`）。这是 §1.3 引理的**有限参数证书**，标 [VERIFIED-LP 有限参数]。

`(x,y)` 情形下 count-grid LP 根本不可行的场合（N4 记录的 `τ ≥ 2`）指的是**固定闭式族**

唯一真正的 IIS 出现在族 (b)，而它的两行恰好是 `(x,y)` 网格上的两条边，
分块在这里没有引入任何新的不可行模式，这与 §2.2 的"块结构一无所获"是同一件事。

### Caveats（诚实标注）

- 全部 LP 都是 `δ = 0`、`η_u = η_o = √η` 的对称拆分；其它拆分未测。
- LP 不对 `G` 施加 submodularity（沿用 N4/T2 的约定）。塌缩结论对此不敏感：
  modular witness 的 `G(S) = |S|/(K√η)` 本身就是 modular，所以 `1/η` 的上界不变，
  而加约束只会把下界推高。`f3` 区域下的 `W_K` 值在加 `G`-submodularity 后可能变大，未测。
- `c = 0.5` 那几行（`n = 192/256`）的值低于 `W_K`，是因为 `1/(4Q)` 太松导致区域退化，
  不对应有意义的查询模型；只作趋势读，不要引用为可达常数。
- `c = 1` 到 `c = 1.5` 之间的**精确临界指数**没有定位（只知道 `c ≥ 1.5` 全塌缩，
  `c = 1` 未必），K=4、η=1.5 在 `c = 1.5` 时还是 0.63–0.66 而非恰好 `1/η`。
- 族 (a) 只测了 `g ≤ 4`、`K ≤ 4`、`n ≤ 32K`；`K ≥ 5` 与更细的划分未测。
- 族 (b) 只测了 4 个 `ψ` 形状与 2 个 `a`；"固定 `φ`、自由 `ψ`"这条 LP 化路线未测。
- 本任务全程没有做集合层面（全格点）的 submodularity 交叉验证，依赖 `lem:app-count`。
- 卡点：无（预算内完成；唯一放弃的分支是"`φ` 固定、`ψ` 自由"的 LP 化，理由见 §3.1）。
