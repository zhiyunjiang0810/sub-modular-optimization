## 1. 模型与 LP

### 1.1 模型（TASKS8 M3.2 的措辞）

基础集 N = [8]，budget K = 4，η = 3/2。

- f 与 f̃ **都**要求单调 submodular，f(∅) = f̃(∅) = 0；
- Definition 1 的 single-element 误差带：对每个 S 与每个 e ∉ S，d_e(S)/η_u ≤ d̃_e(S) ≤ η_o·d_e(S)，η_u·η_o = η = 3/2；
- single-step predictive greedy，**固定 K = 4 步**（零增益也继续选），tie 由对手打破；
- ρ^sub_{8,4}(3/2) := min over instances of f(T)/max_{|S| ≤ 4} f(S)，T 为 greedy 的输出。

### 1.2 三步归约（把模型化成一族 LP）

**(R1) 拆分归一化。** 给定误差带 (η_u, η_o)、η_u η_o = 3/2 的实例，令 f̃′ := f̃/η_o。
则 f̃′ 仍单调 submodular、f̃′(∅) = 0，每一步的 argmax 与 tie 集合不变（正数缩放），误差带变为 (η_u η_o, 1) = (3/2, 1)，f 不动、目标值不动。
所以**只需在有理拆分 (η_u, η_o) = (3/2, 1) 上求解**，LP 数据全部是有理数，对偶才可能精确化。
这是 Lemma 0′ 的缩放双射在本模型里的一句话版本（M1.2 要求的写法）。闸门：§3 的 A3 在三个有理拆分上给出同一个 LP 值。

**(R2) 分支钉住。** greedy 的输出是 4 个不同元素的有序序列；用一个 relabeling σ 把它映成 (0,1,2,3)。
模型的所有约束在 relabeling 下不变，目标值不变。所以可以把"greedy 每步选谁"这一分支结构**固定**为 S^t = {0,…,t−1}、第 t 步选 t，
并把对抗 tie 编码成**弱不等式** d̃_t(S^t) ≥ d̃_e(S^t)，即

    f̃(S^t ∪ {e}) − f̃(S^t ∪ {t}) ≤ 0,    t = 0..3, e ∉ S^t ∪ {t}.

剩下要枚举的只有 **O 相对于这条轨迹的位置**（§2）。

**(R3) OPT 的处理。** f 单调，故 max_{|S| ≤ 4} f = max_{|S| = 4} f。取一个 4-元最优集 O，把 (f, f̃) 同除以 f(O)（两函数同比例缩放，band、单调、submodular、greedy 全不变），
得到 f(O) = 1、目标值 = f(T)。所以任一实例在**某个** O 上是 LP(O) 的可行点，于是

    ρ^sub_{8,4}(3/2) ≥ min_{O ⊆ [8], |O| = 4} LP(O)，

反过来 LP(O) 的最优解若同时满足 OPT = f(O)（§4 的实例满足），则 ρ^sub ≤ 该值。两侧夹住时取等。

OPT = 0（即 f 在所有 |S| ≤ 4 上为 0）的实例按 §0 的既有约定排除，不在本文件的量词里。

(R1)(R2)(R3) 三条都是初等缩放/重标号论证，**状态 [HAND-PROOF-UNREVIEWED]**；(R1) 另有 §3 的 LP 闸门 A3、(R2) 另有 §2 的 70 点全枚举闸门 A1。
(R2) 与 (R3) 不是本任务新引入的：`code/worst_case_lp.py` 的 docstring 已经把它们写成该文件的语义
（"WLOG greedy picks 0,1,...,K−1 in order (ties broken adversarially)" 与 "Worst-case ratio (adversarial ties)
= min over all K-subsets O of the LP value"），本文件只是把这套语义原样搬到 f̃ 也 submodular 的模型上，
并把 (R1) 这一条新的（拆分归一化）显式写出来。行族的写法与 `code/worst_case_lp.py` 逐条一致（见 §1.3），
只多出 f̃ 的 `mono_g` / `submod_g` 两块。

变量：f(S)、f̃(S)（S ⊆ [8]，S ≠ ∅），共 2·(2⁸ − 1) = **510 个自由变量**（f(∅) = f̃(∅) = 0 直接代入消去）。

脚本里保留了 `cap_rows()` 备用。

### 1.4 对偶与下界的判据

LP(O)：min c′x，s.t. Ax ≤ 0，e_{f(O)}′x = 1，x 自由。对任意 λ ≥ 0 与标量 y，若

    A′λ = y·e_{f(O)} − c,                                    (★)

则对每个可行 x：c′x = (y e_{f(O)} − A′λ)′x = y − λ′(Ax) ≥ y。
所以**(★) 加 λ ≥ 0 就是 LP(O) ≥ y 的证书**，与 LP 求解器无关，只要在 Fraction 下核对 (★) 的每一个坐标即可。§5 给的就是 y = 23/41 的这种证书。

## 2. 分支/轨道结构与闸门

(R2) 把分支钉死之后，LP(O) 的行集合、目标、归一化在**保持 0,1,2,3 逐点不动**的置换下不变，也就是在 Sym({4,5,6,7}) 下不变。
于是 target set O 的等价类由不变量

    (O ∩ {0,1,2,3}  作为具体子集,  |O ∩ {4,5,6,7}|)

完全决定。子集 A ⊆ {0,1,2,3} 一旦定下，|O \ A| = 4 − |A| 个元素在 {4,5,6,7} 里任取，Sym({4,5,6,7}) 对它们传递。
所以**轨道数 = 2⁴ = 16**，轨道大小为 C(4,|A|)，合计 Σ_a C(4,a)² = 1+16+36+16+1 = **70 = C(8,4)**，与全部 target set 一一对应。
这 16 就是 T7 卡与 J5 提到的"16 个轨道代表"的来源。

**闸门（不靠轨道论证的独立验证）**：§3 对**全部 70 个** O 各解一次全格点 LP，检查值在每个轨道内一致。
另外 §5 不是只验证 16 个代表：每个代表的对偶向量都被**搬运**（λ′_{σ(r)} := λ_r）到轨道内其余成员并重新逐坐标核对 (★)，
所以下界侧的 Fraction 级验证覆盖的是 **70/70** 个 target set，轨道归约在最终证书里**不承担任何信任**。

## 5. 下界侧对偶证书逐轨道状态（Part C，本任务的关键交付）

### 5.1 做法

对每个轨道代表 O：

1. 用稳定子群 G_O = {σ ∈ Sym({4..7}) : σ(O) = O} 把 LP 的**对偶**方程按变量轨道压缩。
   对偶乘子可以沿 G_O 平均而不损失可行性与目标值，所以可以只找**在行轨道上取常值**的 λ。
   压缩后的方程数 = 变量轨道数（158 至 286），未知数 = 行轨道数（1498 至 3454）。
2. 固定 y = 23/41，解压缩后的可行性 LP（目标 min Σμ，取稀疏顶点），得到数值支撑集（17 至 47 个行轨道）。
3. 在支撑集上用 **Fraction 稀疏 Gauss 消元**精确求解 μ，并检查剩余方程的一致性。
4. 把 μ 提升回**完整的 7702 行**（同一轨道内的行取同一乘子），在 Fraction 下逐坐标核对 (★)，并检查 λ ≥ 0。
5. 把证书搬运到轨道内其余 target set（λ′_{σ(r)} := λ_r），再次逐坐标核对。

第 4、5 步是**独立于对称性归约**的：核对发生在完整 LP 的完整行集上，第 1 步只是"怎么找到"这个向量的启发式。

## 6. 对照与结论

### 6.1 对照数（全部精确有理，Part D）

| 量 | 精确值 | 浮点 |
|---|---|---|
| **ρ^sub_{8,4}(3/2)** | **23/41** | 0.5609756098 |
| U_4(3/2) = 1 − (9/11)⁴ | 8080/14641 | 0.5518748719 |
| ρ_4(3/2) = min_j V_j（原模型，argmin j=3） | 1447/2662 | 0.5435762585 |
| L_4(3/2) = 1 − (1 − 1/6)⁴ | 671/1296 | 0.5177469136 |
| min_m W_m(4, 3/2)（argmin m\* = 2） | 23/41 | 0.5609756098 |

精确比较（交叉相乘，整数）：

    23·14641 = 336743  >  331280 = 41·8080      即   23/41 > U_4(3/2).

同理 23/41 > 1447/2662（23·2662 = 61226 > 59327 = 41·1447），即 submodular surrogate 模型下的最坏值**严格高于**原模型的 ρ_4(3/2)。

### 6.2 能断言什么

> **ρ^sub_{8,4}(3/2) = 23/41**，其中
> 上界侧由 §4 的显式有理实例给出 [VERIFIED-SYMBOLIC-EXACT]，
> 下界侧由 §5 的 70 个有理对偶证书给出 [VERIFIED-EXACT-DUAL]，
> 二者之间的归约 (R1)(R2)(R3) 是三条初等缩放/重标号论证 [HAND-PROOF-UNREVIEWED]，各自另有 LP 闸门。
>
> 由此 **U_4(3/2) 不是 ρ^sub_4 的上界**（23/41 > 8080/14641），
> 而且这条结论现在**有下界方向的证据**，不再是 J5 指出的那种方向错误的"实例背书"。

### 6.3 不能断言什么（must-not-claim）

1. **不能**说 ρ^sub_K(η) = min_m W_m 一般成立。本任务只闭合了 **(K, η, n) = (4, 3/2, 8) 这一个点**。
   H-C §5 的卡点（路径变量 reduced LP 值仍为 min_j V_j）没有被本任务触碰。
2. **不能**由本文件推出 n > 8 时同值。restriction + padding 的论证是 M1.3 的条目，本任务**没有做**；
   本文件全部结果的量词是 n = 8。
3. **不能**说"对每个 η 都严格改进"。本任务只在 η = 3/2 一点上给出精确值。
4. **不能**把 §5.3 的对偶表说成一般 K 的模式，或说成唯一的证书（对偶面退化）。
5. **不能**说本文件复核了 J5 的证书。J5 的 `submodular_K4_exact_duals.json` 未送达，没有做过任何比对。
6. **不能**说"要求 surrogate submodular 让算法更好"。变的是最坏值（对手被剥夺一类实例），不是同一实例上的表现。
7. §3 表格里除 23/41 与 1 之外的**逐轨道分数读数是浮点 `limit_denominator` 的猜测**，没有精确验证，
   不要引用为精确值；本文件对这些轨道声称的**只有** LP(O) ≥ 23/41（这一条是精确的）。

### 6.4 建议给 T7 卡的改法（本文件不改台账）

> - **下界方向（K=4, η=3/2, n=8）[VERIFIED-EXACT-DUAL]**：ρ^sub_{8,4}(3/2) ≥ 23/41，
>   证据为 16 个轨道代表的有理对偶证书（并搬运核对到全部 70 个 target set），
>   恒等式 A′λ = (23/41)e_{f(O)} − c 在 Fraction 下逐坐标验证；`results/M3_rhosub_K4_exact.md` §5、
>   `results/M3_rhosub_K4_exact.json` 的 `C_duals`。
> - **上界方向（同点）[VERIFIED-SYMBOLIC-EXACT]**：显式有理实例，比值精确 23/41；同上 §4。
> - 合并：**ρ^sub_{8,4}(3/2) = 23/41 > U_4(3/2) = 8080/14641**（23·14641 = 336743 > 331280 = 41·8080）。
>   删掉"显式实例背书"这一措辞（方向错误，实例只给 ≤），改为"上界侧实例 + 下界侧有理对偶"。
> - 一般 K 的下界方向仍 [CONJECTURE]/[OPEN]，H-C §5 的卡点不变；94 个全格点 LP 点的数值吻合照旧。
> - 新增禁止声称：不能由本点的精确值推广到一般 (K, η) 或 n > 8。
