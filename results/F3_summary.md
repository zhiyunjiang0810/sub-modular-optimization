## 0. flatness verdict（任务要求的首条发现）

**N4 的 F 在 y=K 处确实是 x 方向平坦的，而且平坦区域比 R9 的还大；但 R11(b) 的证书杀不掉它。**

从 N4 闭式直接推（`F(x,y) = 1 − r_x + [y≥1]g_x + max(y−1,0)(r_x−g_x)/(K−1)`）：

```
F(x,K) = 1 − r_x + g_x + (K−1)(r_x − g_x)/(K−1) = 1        对一切 x
```

也就是顶行恒等于 1，与 R9 的候选一样平坦。更强的是，N4 的 F 在 `x > T` 上**整片**饱和
（`r_x = g_x = 0` ⟹ `F(x,y) ≡ 1`），并且在 `x = T` 处因为 `g_T = r_T`（打靶条件）有
`F(T,y) = 1` 对一切 `y ≥ 1`。

R11(b) 的证书是"`Δ_x F = 0` 但 `Ĝ` 严格递增"。它对 N4 **不适用**，因为 N4 的
`Ĝ_s = η_u^{-1} Σ_{x<s} g_x` 在 `s > T` 之后**饱和**（`g_x = 0`），所以在同一片平坦区上
`ΔĜ = 0`，band_up 不被违反。这一点由 oracle 直接确认：`τ=1` 且 `n > K(T+1)` 时，N4 的
(F, G) 在**真 balanced 带**下无泄露、`δ = 0` 可行（见第 1 节表里 `K=4, n=16K/32K, τ=1`
与 `K=6, n=32K, τ=1` 的行）。

结论：**平坦本身不是罪。R9 死于 F 平坦而 Ĝ 不平坦；N4 让两者一起平坦，因此活过了 R11(b)
的那把刀。它只在另一把刀下才倒（τ ≥ 2，或 τ=1 而 n ≤ K(T+1)），见第 2 节。**

## 1. 主结果表（步骤 1 的两条路）

## 2. 不可行性证书（步骤 3 的核心交付）

### 2.1 普适的 2 约束证书（δ-free，IIS 大小 = 2）

设 `T` 为 N4 尾巴长度（`x > T` 时 `r_x = g_x = 0`；`r_T = g_T > 0` ⟹ `F(T,y) = 1` 对
`y ≥ 1`）。取整数 `1 ≤ m ≤ K−2`，看三个点

```
P1 = (T,   m  )        level T+m
P2 = (T−1, m+1)        level T+m
P3 = (T,   m+1)        level T+m+1
```

与两条边

```
flat 边  P1 → P3 :  ΔF = F(T,m+1) − F(T,m) = 1 − 1 = 0
live 边  P2 → P3 :  ΔF = 1 − F(T−1,m+1) = (r_{T−1} − g_{T−1})·(K−1−m)/(K−1) > 0
```

若 P1、P2、P3 都 balanced，则**无泄露约束**把它们的预测值钉成 `Ĝ_{T+m}, Ĝ_{T+m}, Ĝ_{T+m+1}`，
于是

```
band_up(flat 边)  ⟹  Ĝ_{T+m+1} − Ĝ_{T+m} ≤ η_o√(1+δ)·0 = 0
band_lo(live 边)  ⟹  Ĝ_{T+m+1} − Ĝ_{T+m} ≥ ΔF/(η_u√(1+δ)) > 0
```

矛盾。**这两条不等式就是最小不可行子集（IIS，大小 2）**，对**每个 δ**、对 unbalanced 区域上
`G` 的**任何**取法都成立，因此也就是"路 A 与路 B 结论一致"的原因。

**触发条件**（即 P1,P2,P3 同时 balanced）：

| balanced 定义 | m=1 的触发条件 |
|---|---|
| `y ≤ τ` | `τ ≥ 2`（与 n 无关） |
| 真带 `|y − K|S|/n| ≤ τ` | `K(T+1)/n ≥ 2 − τ`，即 τ=1 时 `n ≤ K(T+1)`，τ≥2 时恒成立 |

`m ≥ 2` 的成员覆盖 n 很小、带中心 `K|S|/n` 在 level T 之前就爬过 y=2 的情形。

**验证**（`python3 results/F3_check.py cert`，G 节）：K ∈ {3,4,5,6,8} × η ∈ {3/2,2,5/2,3} ×
τ ∈ {1,2} × n ∈ {8K,16K,32K} × defn ∈ {true, ysmall} 共 **240 个配置，240 PASS / 0 FAIL**。
逐点核验三件事：(i) flat 边的 ΔF 用精确有理算术恰为 0；(ii) live 边的 ΔF 严格为正；
(iii) 一个**独立的、与 δ 无关的图论 oracle**（把所有 flat 边与同 level 的 balanced 点做并查集
收缩，再在收缩图上找含 live 边的环）报告不可行，**当且仅当**上面这族证书里有一个成员触发。
状态：[EXACT]（ΔF 的符号）+ [VERIFIED-LP]（240 点等价性）+ [HAND-PROOF-UNREVIEWED]（一般 (K,η,m) 的推导）。

### 2.2 紧约束清单（在可行的那一侧）

在 τ=1、`n > K(T+1)` 的可行区，最小可行 δ = 0，**紧约束集应当与 N4 §4.1 的八族逐族相同**
（A band_lo-y、B band_up-x（coherence 取等）、C submod-yy（coverage 取等）、D submod-xx、
E/F/G 顶行与尾部的 mono/submod、L 长程 y=2 链）。理由：真带在原点附近退化成 `y ≤ 1`，
而 `n > K(T+1)` 恰好保证这个退化一直延续到 F 饱和之后（level T+1），因此真带 LP 与
`ysmall` LP 的约束集在**起作用的那一段**完全重合。
状态：[HAND-PROOF-UNREVIEWED]——本晚**没有**在真带上重跑 `results/N4_duals.py` 取对偶乘子；
oracle 支持只有两条间接证据：(i) 两个定义下 relaxF 的值逐点相等（第 3 节 C 栏，K=6、n=192、
τ=1 时差 ≤ 1e−15）；(ii) 冻结 F 的可行性 LP 在两个定义下都给出 δ = 0（第 1 节 B 栏）。
要坐实"逐族相同"需要跑一次 `N4_duals.py --defn true`，本晚未做。

### 2.3 与 N4 族 L 的关系（任务要求的对比）

族 L 是一条**穿过 unbalanced 的 y=2 行**的长程链：`band_up (j,1) y` + `band_up (x,2) x`
（x = j..T−1）+ `band_lo (T,1) y`，端点项决定超额 D。上面的 2 约束证书**就是族 L 的远端端点，
把 unbalanced 的松弛拿掉之后剩下的东西**：真带（或 τ≥2）把 `(T−1,2)`、`(T,2)` 从 unbalanced
拉进 balanced，于是链条最后一段 `band_up (T−1,2) x` 不再有自由的 `G` 可以吸收，直接与
`Ĝ` 的 level 结构撞车。

一句话：**族 L 在 `ysmall`、τ=1 下只是把 LP 值顶高一点点（超额项 → 0）；在真带越界或 τ≥2 时，
同一条链退化成硬矛盾。**

两种读法都指向同一个结论：**这套 balanced 对称化技术的可证常数随窗口宽度单调变差，
`τ ≈ ⌈K/η⌉` 处归零。这是技术极限，不是构造的问题。**
状态：[VERIFIED-LP]（表内 8 行 × 至多 5 个 τ 的 relaxF LP 点）+
[HAND-PROOF-UNREVIEWED]（concentration 侧的量级）+ [CONJECTURE]（τ\* 的闭式）。

### 3.3 远场自动无泄露：真带其实是过强的形式化（本晚最有用的一条）

`results/F3_check.py` 的 **H 节** [EXACT，12/12 个 (K,η) 点，精确有理算术]：

> N4 的预测器满足 `G(x,y) = Ĝ_{x+y}` **不仅在 y ≤ 1 上，而且在整个 `x > T` 上**，
> 最大偏差恰为 0；因此**会泄露的集合全部满足 `|S∩O| ≥ 2` 且 `|S| ≤ T+K`**
> （实测最大泄露 `|S|` = T+K−2）。

理由（[HAND-PROOF-UNREVIEWED]，一行）：`x > T` ⟹ `r_x = g_x = 0` ⟹ `F(x,y) ≡ 1`
⟹ `G(x,y) = Ĝ_{x+1} + η_o(1−1) = Ĝ_{x+1}`；而 `Ĝ` 从下标 `T+1` 起饱和，故
`Ĝ_{x+1} = Ĝ_{x+y}`。

**这改变了 F3 的结论。** 真 balanced 带（"`G` 在整条双侧带上只依赖 `|S|`"）是一个**比实际需要更强**
的形式化：hardness 论证只需要"算法**实际问到的**集合上答案与 `O` 无关"。对一个大小为 `s` 的查询，
好事件是 `{y ≤ 1} ∪ {x > T}`，其补集要求 `y ≥ 2` **且** `s ≤ T + y ≤ T+K`。于是

```
Pr[单次查询泄露] ≤ C(K,2)·((T+K)/n)² ≤ K²(T+K)²/(2n²)     （对一切查询大小一致）
Q 次 union bound (≤1/4) + Pr[T₀ ∩ O ≠ ∅] ≤ K²/n (≤1/8)  <  1
  ⟸  Q ≤ n²/(2K²(T+K)²)  且  n ≥ 4K(T+K)（蕴含 n ≥ 8K²，也保证 Q ≥ 8 非空）
```

`T+K ≤ (2+η)K+1`，所以 **`Q = Ω(n²/((2+η)²K⁴))`，即 `n^{2−o(1)} `次任意大小的查询**。
这就是 `results/F3_hardness_full.tex` 里 Theorem 的内容（四步：concentration → 构造 →
取值 → Yao；每步标状态；已编译）。

**为什么指数卡在 2**：`Pr[y ≥ 2]` 的指数就是 2；要拿到 `Q = n^c`（c ≥ 3）就得把无泄露窗口
放宽到 `y ≤ τ`、`τ ≥ 2`——而 2.1 的证书说那时构造对任意 δ 不可行。所以**指数 2 是这个族的内在
上限，不是分析的松弛**。[VERIFIED-LP + EXACT]

另一条已量化的退路（`mode = D_cap`）：如果**改成**只对大小 ≤ smax 的查询要求"在真带上"无泄露，
N4 的 F 能撑到 `smax ≈ T`（K=4, η=2, n=32, τ=1：`smax* = 10 = T`，最小 `δ = 0.5333`；
K=6, η=2, n=96：`smax* = 16 = T`，`δ = 2.006`）；`smax = K`（N5 定理的查询模型）处 δ=0。
这条路要付 δ > 0 的代价，比 3.3 的路差，记录备查。

## 4. 对 N5 / 论文的影响（需人工判断）

1. `results/N5_bounded_query_hardness.tex` 的第 0 节用的是 **R9** 的族，第 1 节的 concentration
   引理只处理 `|S| ≤ K` 的查询。在这个查询模型下，真带在 `s ≤ K` 上退化成 `y ≤ τ`

   | 查询大小 | 必须 `≤ K` | **任意** |
   | 查询次数 | `Q = n^c`，任意常数 c | `Q = O(n²/((2+η)²K⁴))`，**指数卡在 2** |
   | 得到的常数 | `L_K(η̂)`，`η̂ = Φ^{-1}(η) < η` | `W_K(η) = V_j(η) + 超额`，用的是真 η |

3. N4 §6 的 caveat "τ=2 未系统测试"应升级为**明确的负面结果**：N4 闭式在 τ ≥ 2 下
   （即使旧的 `y ≤ τ` 定义）对任意 δ 不可行，证书见 2.1。
4. R11(b) 的措辞可以精确化：证书的本质不是"F 在 y=K 平坦"，而是"**同一个 level 上同时存在
   平的 balanced 边和不平的 balanced 边**"。R9 是 `ΔF=0` 撞 `ΔĜ>0`（Ĝ 固定），N4 是

## 5. Caveats

1. **`results/F3_hardness_full.tex` 的定理不是"任意多项式次查询"**：预算是
   `Q = O(n²/((2+η)²K⁴))`，指数卡在 2（原因见 3.3 末）。写正文时这个限定词必须显式出现，
   不能用裸的 "poly-query"。定理的装配步骤（concentration 的 union bound、模拟归纳、Yao 平均）
   全部是 [HAND-PROOF-UNREVIEWED]，没有 oracle 跑过；有 oracle 的只有实例族本身
   （[EXACT] 42 点）与远场无泄露（[EXACT] 12 点）。
2. Corollary（randomized）里用到的不等式 `F_O(x,y) ≤ W_K + y/K` 本晚**没有**任何脚本核验过。
3. 全部是网格（对称化）LP，没有重做全格点 oracle 交叉验证（T2 已在 (8,3) 上验证过对称化在
   relaxF 模式下等价；本节沿用）。
4. `η` 只测了 `η_u = η_o = √η` 的对称拆分；`η ∈ {1.5, 2, 3}`，`K ∈ {4, 6}`（G/H 节扩到
   `K ∈ {3,4,5,6,8}`，F 节扩到 `K ∈ {6,8,12}`）。
5. 一般 (K, η) 的 `n_min = K(T+1)+1`（12 点）、`τ* = ⌈K/η⌉`（8 行）都是 [CONJECTURE]。
   `T = j+m*` 里的 `j`、`m*` 闭式本身也只是 N4 的 [CONJECTURE]（264 点）。
6. 2.1 的证书对一般 `(K, η, m)` 的推导是 [HAND-PROOF-UNREVIEWED]；oracle 只在 240 个配置上
   确认了它与图论不可行判据的等价。

   范围内没有找到不可行的 cap"，不是"任意大的 cap 都可行"。
