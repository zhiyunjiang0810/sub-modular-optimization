# F2.1  (K, η) = (5, 4) 异常点的精确算术判定

复现脚本：`python3 results/F2_54_exact.py`（约 40 秒；加 `full` 参数把 E 节网格扩到 K=8，约 4 分钟）。
数据：`results/F2_54_exact.json`。

## 结论（一句话）

**真实差异，不是数值假象。** N4 的闭式构造在 (K, η) = (5, 4) 处不是 relaxF LP 的最优解：
存在一个**精确有理**的 LP 可行点，其目标值比闭式构造低 3.05e−7（有精确证书）；
HiGHS 报出的最优值比该可行点还低 1.4e−8。
机制是构造多加了一条 LP 并不要求的约束 `F(x, K) = 1`（等价地 `F(x, 0) ≤ 1`）。

状态标签：

| 断言 | 标签 |
|---|---|
| 闭式构造在 (5,4) 非最优（LP 最优值 < 构造值） | [VERIFIED-LP]（精确有理可行性证书，Fraction 零舍入） |
| 差异不是 HiGHS 容差假象 | [VERIFIED-LP]（证书独立于 HiGHS 的最优性断言） |
| 机制 = 构造多加了 `F(x,K) = 1`；加回该约束后 LP 值 = 闭式值 | [VERIFIED-LP]（差 ≤ 5.6e−17；(5,4) 与 E 节全部网格点） |
| (5,4) 是 η ≤ K−1 内唯一的异常点 | [VERIFIED-LP]（K=3..8 × 16 个 η，见 E 节）；**为什么只在这一点触发仍未查明** |
| LP 最优值精确等于 0.247490369495778 | 未证（只证了 LP 最优值 ≤ 0.247490383108187） |

## 为什么这一点可以做精确算术

η = 4 有理，且 `√η = 2` 是精确二进制浮点，所以 `results/N4_relaxF_solve.py::build`
生成的 LP 矩阵的全部系数落在 {−2, −1, −1/2, 1/2, 1, 2}，右端项是 0 或 1。
又因为**每个 IEEE double 本身就是二进有理数**，`Fraction(x)` 是对浮点向量的
无损读取：对任意浮点解，可以零舍入地精确计算它对每条约束的残差。
（这与 N4_check.py 的 EXACT 部分是同一个技巧的对偶用法：那里是把 `Gs := √η·G`
存起来消掉 √η，这里是直接利用 √4 = 2。）

## A. 闭式构造在该点的精确值

```
q = 16/17,  j = 2,  m* = 19,  T = 21,  D = 68881049499904/1550166542280575
构造值 = 383651784815487/1550166542280575 = 0.247490688485035887
V_j(R10 reduced LP 闭式) = 21/85          = 0.247058823529411775
```

`N4_check.check_exact(5, 4, X=31)` 复跑：**0 条违反**，构造确实是 LP 的可行点
（所以它给出 LP 最优值的一个上界，这一点不变）。

## B. HiGHS 最优值的稳健性（先排除明显的数值故障）

| X (格宽) | n | LP 最优值 | 构造 − LP |
|---|---|---|---|
| 12 | 17 | 0.247058823529412 | 4.32e−4 |
| 20 | 25 | 0.247352024922118 | 1.39e−4 |
| 21 | 26 | 0.247477744807122 | 1.29e−5 |
| **22** | 27 | **0.247490369495778** | **3.19e−7** |
| 24 / 28 / 31 / 40 | | 0.247490369495778 | 3.19e−7 |

X = 22 是第一个放得下长度 T = 21 尾巴的格宽，之后值完全稳定（差 < 1e−15）。
换算法（highs / highs-ds / highs-ipm / 关 presolve / 把 primal 容差压到 1e−10）
得到同一个值到 1e−15，返回解的浮点最大残差 ≤ 3.6e−15。
这些都只是"没有明显故障"的旁证，不构成证明；证明在 C 节。

## C. 精确证书（决定性的一步）

**要证的是**：LP 的最优值 < 构造值。因为 LP 是极小化，只需给出**一个可行点**，
其目标值严格小于构造值即可，完全不需要相信 HiGHS 的最优性断言。

做法：把全部不等式右端项收紧 `eps`（`b → b − eps`），并把 HiGHS 的
primal feasibility 容差强制设为 1e−10 < eps，于是返回的浮点向量对**原始** LP
是带 eps 余量可行的。然后用 `Fraction` 精确审计这个浮点向量。

| eps | primal 容差 | 精确最大残差 | 违反数 | 等式精确 | G<0 | 精确目标值 | 是否成立 |
|---|---|---|---|---|---|---|---|
| 0 | 默认(1e−7) | +8.88e−16 | 60 | 是 | 0 | 0.247490369495778 | 不精确可行 |
| 1e−9 | 默认(1e−7) | +2.00e−9 | 8 | 是 | 0 | 0.247490383078146 | 不精确可行 |
| **1e−9** | **1e−10** | **−1.00e−9** | **0** | **是** | **0** | **0.247490383108187** | **可行且优于构造** |
| 3e−9 | 1e−10 | −3.00e−9 | 0 | 是 | 0 | 0.247490410333005 | 可行且优于构造 |
| 1e−8 | 1e−10 | −1.00e−8 | 0 | 是 | 0 | 0.247490505619866 | 可行且优于构造 |
| 1e−7 | 1e−10 | −1.00e−7 | 0 | 是 | 0 | 0.247491730736654 | 可行但已高于构造 |

证书（第三行）：一个显式二进有理向量 x*，精确满足

- 全部 1198 条不等式，且每条**都有 ≥ 1e−9 的余量**（不是"刚好不违反"）；
- 全部 3 条等式（F(0,0)=0、F(0,K)=1、Ĝ_0=0）精确成立；
- 全部预测器变量 ≥ 0；

目标值 = 0.247490383108186746（精确二进有理，分母 17 位十进制），

```
构造值 − 证书值 = 3.053768e−07 > 0
```

注意第一行：不收紧时 HiGHS 的返回向量本身有 60 条约束在 1e−16 量级被违反
（浮点解都会这样），所以"直接对 HiGHS 解做精确审计"是通不过的；
必须先要一个有余量的解。这也是把 `eps` 从 1e−9 一路扫到 1e−7 的原因：
eps = 1e−7 时余量已经吃掉了全部 3.2e−7 的差距，证书失效，说明这个差距
虽然真实，但只有 3e−7 量级，用"松一点的可行点"是够不着的，必须精确记账。

**判定：真实差异。** 构造在 (5,4) 非最优。

## D. 机制：构造多加了 `F(x, K) = 1`

LP 最优解与构造解的逐列对比（`r_x = 1 − F(x,0)`，`g_x = F(x,1) − F(x,0)`）：

| x | r_x (LP) | r_x (构造) | g_x (LP) | g_x (构造) | F(x,K) − 1 (LP) |
|---|---|---|---|---|---|
| 0 | 1.0000000000 | 1.0000000000 | 0.2000000000 | 0.2000000000 | 0 |
| 1 | 0.9412074428 | 0.9411764706 | 0.1882765904 | 0.1882352941 | 1.755e−4 |
| 2 | 0.8858629472 | 0.8858131488 | 0.1772427931 | 0.1771626298 | 3.510e−4 |
| 10 | 0.5302541026 | 0.5303362494 | 0.1721944648 | 0.1719867448 | 1.755e−3 |
| 21 | 0.0412919413 | 0.0415555127 | 0.0449776329 | 0.0415555127 | 3.686e−3 |
| 22 | −0.0031591643 | 0.0000000000 | 0.0007020365 | 0.0000000000 | 3.861e−3 |

两个解形状完全一样（相位 1 + 常数 d 的相位 2 + 尾巴），差别只有一条：
LP 最优解的 `F(x, K) − 1 = x·ε`，斜率 `ε = 1.755091e−4 > 0`，而构造恒取
`F(x, K) ≡ 1`（即 `ε = 0`）。相应地 LP 的残差 `r_x` 允许走成负数
（`F(x, 0) > 1`，x = 22 > K 时合法），构造则强制尾巴在 `r_T = 0` 闭合
（第 3 节的"打靶条件" `g_T = r_T`）。

把这条自加的约束显式放回 LP：

| 变体 | LP 最优值 | 减去构造值 |
|---|---|---|
| 原 LP | 0.247490369495778 | −3.19e−7 |
| + `F(x,K) = 1` (∀x) | 0.247490688485036 | −2.78e−17 |
| + `F(x,0) ≤ 1` (∀x) | 0.247490688485036 | −5.55e−17 |
| + 两者 | 0.247490688485036 | −5.55e−17 |

也就是说：**构造是"F 在覆盖 O 之后饱和"这个子类里的精确最优解**，
闭式公式没有错；错的是"这个子类无损"这个隐含假设，它在 (5,4) 处首次失效。

为什么这是合法的松弛：LP 的归一化只写在 `0 < x+y ≤ K` 的格点上（OPT 是 K-子集的最大值），
`F` 在 size > K 的集合上没有上界，单调性只强制 `F(x,K) ≥ F(0,K) = 1`。
构造取了这条边界；最优解则让真实函数在 O 已被覆盖之后仍保留一个常数的 B 方向增益。

## E. (5,4) 有多孤立

E 节网格（K = 3..8，η ∈ {5/4, 3/2, 7/4, 2, 9/4, 5/2, 11/4, 3, 7/2, 15/4, 4, 17/4, 9/2, 5, 6, 7}
中 η ≤ K−1 的部分，共 68 个点；**K = 7 与 K = 8 的行只在 `python3 results/F2_54_exact.py full`
下计算**，默认运行只跑 K = 3..6）：除 (5,4) 的 3.19e−7 外，其余 67 点全部
|构造 − LP| ≤ 4.1e−11（最大值在 (8,5)；K = 8 的几行在 1e−11 量级，属大规模 LP 的
正常噪声；K ≤ 7 全在 3.3e−16 以内）。

K = 5 上沿 η 的细扫（η → 4⁻）：

| η | j | 构造 | LP | 差 | LP 解的 F(1,K)−1 |
|---|---|---|---|---|---|
| 19/5 | 2 | 0.259079602692 | 0.259079602692 | −5.6e−17 | 0 |
| 39/10 | 2 | 0.253156366854 | 0.253156366854 | +5.6e−17 | 0 |
| 399/100 | 2 | 0.248046312054 | 0.248046312054 | +5.6e−17 | 0 |
| **4** | **2** | **0.247490688485** | **0.247490369496** | **3.19e−7** | **1.755e−4** |
| 401/100 | 1 | 0.247089375054 | 0.246937271177 | 1.52e−4 | 4.05e−5 |
| 21/5 | 1 | 0.236565514792 | 0.236486033000 | 7.95e−5 | 4.91e−3 |

即：`ε > 0` 的松弛在 η 严格小于 4 时不被使用（差恰为 0，`F(1,K)−1 = 0`），
在 η = 4 处首次被使用，η > 4 = K−1 之后就是 N4 已记录的"闭式只是上界"区。
所以 (5,4) 不是孤立的怪点，而是**已知失效区 η > K−1 的左端点**：
失效在整数 η = K−1 处**已经**开始，而不是在它之后。

**但是**：同样是 η = K−1 的其他点（(3,2)、(4,3)、(6,5)、(7,6)、(8,7)）差全部 ≤ 1.1e−16，
构造在那里仍然最优。所以"为什么只有 K = 5 的左端点触发"没有答案，
本节只把 N4 的 caveat 从"机制未查明"降级为"松弛的身份已查明（`F(x,K) = 1`），
但触发条件未查明"。

## 对论文的影响

- N4 的闭式在 η ≤ K−1 时"= LP 最优值"这条断言应改写为：
  **闭式是 `F(x,K) ≡ 1` 子类内的精确最优值；在测试的 68 个 η ≤ K−1 的点中，
  除 (5,4) 外它都等于无约束 LP 的最优值**。
- 定量影响可忽略：偏差 3.2e−7，而 N4 的结论（技术极限 = ρ_K^LP + 快速衰减的超额项，
  严格小于 U_K）在该点的超额项本身是 4.3e−4，方向和数量级都不受影响。
- 但它是一个"上界方向"的偏差：闭式在该点**高估**了 LP 的最优值，
  因此凡是把闭式当作"这套技术能证到的最好常数"的下界性陈述，都要加"在
  `F(x,K) ≡ 1` 的子类内"这个限定，或者改成 `≥`。

## Caveats

- 本节只证了 `LP最优值 ≤ 0.247490383108187 < 构造值`。**没有**证明 LP 最优值
  精确等于 HiGHS 报的 0.247490369495778（那需要一个精确对偶证书，未做）。
- 证书是在 X = 22（n = 27）的格上给出的。B 节显示 X ≥ 22 时值不再变，
  但"n → ∞ 极限"本身仍是数值结论（与 N4 同）。
- E 节的网格是 τ = 1、`y ≤ τ` 定义、`η_u = η_o = √η`，与 N4 同口径；
  τ ≥ 2 未测。
- 触发条件（为什么只有 (5,4)）未查明，属公开问题。
