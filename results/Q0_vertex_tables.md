## 1. 结论摘要

1. **[VERIFIED-LP]** 52/52 个 LP 的 canonical 顶点全部通过合法性复核（monotone、submodular
   四类、band、O-无关、`F(0,0)=0`、`F(0,K)=1`、`F <= 1` 于 `0 < |S| <= K`），
   浮点残差 `< 1e-7`（见 `Q0_vertex_tables.json` 的 `viol` 字段，全部为空 dict）。
2. **[VERIFIED-LP]** LP 值只通过 `X = n - K` 依赖 n，**关于 n 单调不减**，并在
   `n >= K + T`（`T = j + m*`，`m* = ceil(eta K) - 1`）之后不再变化。
3. **[VERIFIED-LP]** `n = 2K` 时 LP 值**恰等于** `rho_K(eta) = min_j V_j(eta)`：
   45/45 个 `(K, eta)`（K = 3..7）误差 `<= 3.3e-16`。
4. **[VERIFIED-LP]** `n -> infinity` 的极限**严格大于** `rho_K`，等于 N4 的闭式
   `W_K(eta) = V_j + (K-j)(D - q^j/(K eta))`。因此 TASKS10 目标 (c)
   "`rho_K^{(n)} -> min_j V_j`" 与数据矛盾（第 7 节）。
5. **[VERIFIED-LP]** 顶点的形状与 N4 闭式逐点一致（`j >= 2` 时最大偏差 `1.2e-13`，

形状（与 TASKS10 的先验一致，且比先验更具体）：

- `t < j`：`d_t = q^t / k1` 几何衰减（0.117647 = 1/8.5，0.103806 = q/8.5）。
- `j <= t <= T-1`：`d_t = D` **常数平台**（不是到 `t = K` 就结束，平台一直延伸到

- `t = T`：一个**收口步** `d_T = r_T`（0.073412），这是 `g_T = r_T` 的打靶条件。
- `t > T`：`d_t = 0`，`F(x,y) ≡ 1` 整片饱和。

先验里"`t >= K` 之后与尾巴/阈值 T 相关的模式"应该修正为：平台从 `x = j` 开始，
**跨过 `x = K` 不变**，一直到 `x = T`，`K` 在形状上不是分界点，只是目标读数的位置。

### 4.2 ghat 与两类边际的关系（balanced 区域 O-无关的机制）

三条等式在顶点上处处成立（[VERIFIED-LP]，浮点 `1e-15`；[EXACT] 见 Q1）：

```
ghat(x) = Ghat_{x+1} - Ghat_x = g_x / eta_u          (band_lo 在 (x,0) 的 y 方向取等)
Delta_x F(x,1) = ghat(x+1) = g_{x+1}/eta_u           (band_up 在 (x,1) 的 x 方向取等)
=> Delta_y F(x+1,0) = eta * Delta_x F(x,1)           (coherence R3(ii)，prop:rigidity 的那条)
```

也就是：同一个 `Ghat_{x+1}` 同时服务 `(x,0) -> (x+1,0)`（非 O 元素）与
`(x,0) -> (x,1)`（O 元素），这两条边的 `|S|` 都是 `x+1`，balanced 区域的 O-无关把它们
钉在一起。这正是先验说的"预测增益打平"，量化形式是上面第三式：在平台段
`g_{x+1}/d_x = eta`（带饱和），在相位 1 内 `g_x = r_x/K` 与 `d_x = r_x/k1` 给出
`g_x/d_x = k1/K = (eta(K-1)+1)/K`，小于 eta。

一条额外的不变量（[EXACT]，8 组 `(K, eta)` 精确有理验证，见下文脚本片段）：

```
sum_x g_x = k1 / K        =>      Ghat 的饱和值 = k1 / (K eta)
```

也就是说，尾巴怎么收口不影响 `g` 的总和，它永远等于相位 1 无限延伸时的总和。
这条对 Q2 有用：它把 `Ghat` 的封顶值变成一个不含 `D`、`m` 的表达式。

### 4.3 y 方向

`F(0,y) = y/K` 精确（0, 1/3, 2/3, 1）。对每个 x，`F(x, ·)` 在 `y >= 1` 上线性：

```
F(x,y) = 1 - r_x + g_x + (y-1)(r_x - g_x)/(K-1),    y >= 1
```

于是 `F(x,K) ≡ 1` 对一切 x（顶行平坦，F3 已记录；`Ghat` 在同一片区域也平坦，
所以 band_up 不被违反）。

## 7. 与 TASKS10 前提的偏差（必须读）

(a) **TASKS10 目标 (c) 与数据矛盾。** 任务书要求
`rho_K^{(n)}(eta) -> rho_K(eta) = min_j V_j`（n -> infinity）。实测 `rho_K^{(n)}` 关于 n
**单调不减**，`n = 2K` 时等于 `rho_K`，`n >= K + T` 后等于 `V_j + 超额 > rho_K`。
超额很小（K=4, eta=2 时 3.2e-4；K=8 时 5.9e-7）但严格为正。
父任务描述里的"N4 的 relaxed-F LP 已数值确认极限 = min_j V_j"与
`results/N4_hardness_construction.md` 主结论 3 不符，后者写的是"极限 = `V_j` + 一个正的超额项"。
本夜独立复现了 N4 的结论。

(b) **方向性后果。** hardness 要的是**小**比值，n 越大 LP 值越大，所以
"n -> infinity 的精确 hardness 常数"是 `W_K(eta) = V_j + 超额`，不是 `rho_K`。
`rho_K` 只在 `n <= K + j + m_0`（约 `(eta+2)K`）的**有限窗口**里取到，而 transcript
论证的并集界 `K^5/(2n)` 要求 `n >> K^5`，两者不相容。
夹逼区间因此只能闭合到 `[rho_K, W_K]`，宽度 = 超额项。这一点与 F3 的 hardness 草稿
（常数写作 `W_K(eta) = V_j(eta) + 超额项`）一致，不是新的坏消息，而是对
TASKS10 目标陈述的更正。

(c) **`j <= 1`（即 `eta > K-1`）仍未解决。** 这些参数上 LP 值低于 N4 闭式，
闭式只是可行上界（N4 §3 已列为 3/42 不匹配点，本夜在 `(3,5/2)`、`(3,29/10)`、
`(4,7/2)`、`(3,7/2)`、`(4,9/2)` 上复现）。TASKS10 给 Q1 的定义域是 `1 <= j <= K-1`，
其中 `j = 1` 正好落在这个未解决区。可交付的定义域应写成 `2 <= j <= K-1`
（等价于 `eta <= K-1`）。

(d) `j = 0`（`eta >= K`）时 LP 值 = `1/eta` 且**完全不依赖 n**（K=3, eta=7/2 与
K=4, eta=9/2 的整行都是常数），与 `rho_K = 1/eta` 一致。
