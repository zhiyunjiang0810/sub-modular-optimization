## 0. 净结论（先读这段）

**R10 的闭式现在是 ρ_K(η) 的精确最坏值，不再只是 reduced LP 的值**，唯一还缺 oracle 的一步是 R6 的手证（见下表第一行）。

| 方向 | 内容 | N2 之前 | N2 之后 |
|---|---|---|---|
| ρ_K ≥ min_j V_j | reduced LP 的每条约束对任意实例有效（R6）+ LP ≥ V_j（N1） | R6 [HAND-PROOF-UNREVIEWED] + N1 [VERIFIED-SYMBOLIC] | 未触碰，状态不变 |
| **ρ_K ≤ min_j V_j** | 存在实例达到 V_j | 只有 j=0（R2，值 1/η）和 j=K（R7，值 U_K > V_{K−1}）；**中间 j 无实例**，K ≤ 4 的有限点靠全格点 LP 数值 | **每个 (K, j) 一个显式 (f, f̃)**，一般 K [VERIFIED-SYMBOLIC，模一次分支枚举] + K ≤ 6 全格点 [VERIFIED-LP] |

于是可以写成：

> **[VERIFIED-SYMBOLIC]（一般符号 K；"一般 K" 的确切含义见 §6）**
> 对每个 K ≥ 2、每个 0 ≤ j ≤ K、每个 η ≥ 1，存在 n = 2K 上的显式 (f, f̃)，f 单调 submodular，
> 单元素误差与 all-pairs 误差都恰为 (η_u, η_o)（任意满足 η_u η_o = η 的拆分），
> single-step predictive greedy 在对抗 tie 下的输出满足 f(S^K)/f(O) = V_j(η) = 1 − q^j(1 − (K−j)/(Kη))。
> 取 j = j\*(η)（即 η ∈ [K−j\*, K−j\*+1]）得 **ρ_K(η) ≤ min_j V_j(η)**。

配合 N1 与 R6：

> **ρ_K(η) = min_{0≤j≤K−1} V_j(η)，分段点恰为整数 2..K**，
> 其中 "≥" 方向依赖 R6 的手证 [HAND-PROOF-UNREVIEWED]，"≤" 方向（本任务）是 oracle 验证的。

三个附带结论：

- **推论 1（实例族的统一）**：V_j 的实例族以 j 为参数，**j = 0 就是 R2 的 modular 实例**（值 1/η），**j = K 就是 R7 的实例**（f 与 `code/check_explicit_instance.py` 的 F 逐点相同，值 U_K = 1 − q^K = V_K）。中间 j 是新的。这直接补上 N1 §6.3 指出的缺口：R7 族只到 U_K，而 U_K − V_{K−1} = q^{K−1}(η−1)/(Kηk1) > 0（η > 1）。
- **推论 2（R5 表全部复现）**：R5 记录的 25 个精确最坏值（K=2,3,4）由显式实例逐点重现，最大偏差 3.5e−07（来自 R5 表本身只记了 6 位小数；有理数点上偏差 ≤ 2.2e−16）。所以 R5 的数值现在既有 LP 也有实例作证。
- **推论 3（tie 是本质的）**：达到 V_j 的实例在**每一步**都与 O 元素预测值打平（K 步 K 个 tie），并且在 t ≥ j 的步上这个 tie 被误差带**强制**（上下界同时紧）。改成严格偏好后值变成 V_j(η′)，η′ < η，取 η′ ↑ η 给出同一个 inf。详见 §4。

## 1. 构造（本任务的主结果）

记 k1 = (K−1)η + 1，q = (K−1)η/k1 = 1 − 1/k1，η_u η_o = η（默认 η_u = η_o = √η，与 R5 一致）。

**基础集**（n = 2K，元素编号与 `code/worst_case_lp.py` 的约定一致：greedy 依次选 0..K−1，O = {K..2K−1}）：

    C = {0, ..., j−1}      j 个 "coherence 步" 元素
    P = {j, ..., K−1}      K−j 个 "prediction 步" 元素
    O = {K, ..., 2K−1}     K 个最优解元素

对 S 记 x = |S∩C|，z = |S∩P|，y = |S∩O|。定义

    δ  = q^j / (Kη)                        （P 元素的真实增益）
    δ̃  = η_o · δ = q^j / (K η_u)           （P 元素的预测增益）
    W(0) = k1 / (K η_u),   W(y) = (K−y) η_o / K   (1 ≤ y ≤ K，故 W(K) = 0)

    f(S)  = 1 − q^x (1 − y/K) + z · δ · χ(y)
    f̃(S) = W(0) − q^x W(y)   + z · δ̃ · χ(y)

χ 有两个版本，两个都完整验证过：

| 版本 | χ(y) | 单调 submodular 的条件 | 备注 |
|---|---|---|---|
| **capped**（脚本默认） | [y < K] | η ≥ K−j（即 j 的段及其右侧） | 与 `worst_case_lp.py` 解出的 LP 最优面一致；y=K 时 f ≡ 1 |
| **uncapped** | ≡ 1 | 无条件（一切 η ≥ 1） | 公式更简单；j=0 时**就是** R2 的 modular 实例 |

两者的 greedy 轨迹、误差、OPT、比值完全相同，都等于 V_j(η)。capped 版在 η = K−j（段左端点）处 monotonicity 恰好取等（O 元素的最后一个增益为 0），这正是分段点出现的机制；uncapped 版没有这个现象，说明**分段点来自 min_j V_j 的比较，而不是来自实例的可行性**。

**greedy 轨迹（这就是构造的全部内容）**：记 S^t = 前 t 个被选元素。

| 步 t | 状态 (x,z,y) | 真实增益 d_t | 预测增益 | 同状态下 O 元素的真实/预测增益 |
|---|---|---|---|---|
| t < j（C 步） | (t,0,0) | q^t/k1 | q^t/(K η_u) | q^t/K  /  q^t/(K η_u) |
| t ≥ j（P 步） | (j,t−j,0) | q^j/(Kη) | q^j/(K η_u) | q^j/K  /  q^j/(K η_u) |

即 **f̃ 把 greedy 状态上每个候选的预测值都压成 (O 元素真实增益)/η_u**：这是误差带允许 O 元素取的最小值，同时又恰是 P 元素能取的最大值（因为 η_o·δ = q^j/(Kη_u)），于是每一步都打平，对抗 tie 就选走 C 或 P。C 步的预测值 q^t/(Kη_u) 落在带内（比值 k1/(Kη_u) ∈ [1/η_u, η_o]，两端分别等价于 η ≥ 1）。

于是 f(S^K) = (1 − q^j) + (K−j)·q^j/(Kη) = V_j(η)，而 f(O) = 1。

**误差**（脚本逐条验证）：所有单元素比值 d̃/d 只取三个值 —— η_o（C 方向 y ≥ 1、P 方向、O 方向 y ≥ 1）、1/η_u（O 方向 y = 0）、k1/(Kη_u)（C 方向 y = 0）。所以 max d̃/d = η_o、max d/d̃ = η_u 都**恰好达到**，η = η_u η_o 是精确的、不是上界。因为 f 单调且 f、f̃ 都是计数函数，任意 (A,B) 的增量都是若干单元素增量之和，比值是加权平均，所以 **all-pairs 误差 = single-element 误差**（脚本对 2K ≤ 12 全枚举验证）。

**一个具体例子**（K=3, j=1, η=2.5，即 R5 的 7/18 那一格；完整表在 `results/N2_examples.json`）：
k1 = 6, q = 5/6, δ = 1/9, δ̃ = 0.175682, W(0) = 1.264911。

    f:  (x,z,y)=(0,0,0)→0     (1,0,0)→1/6      (1,1,0)→5/18     (1,2,0)→7/18 = V_1
        (0,0,1)→1/3   (0,0,2)→2/3   (0,0,3)→1 = OPT     (1,0,1)→4/9
    f̃:  (0,0,0)→0     (1,0,0)→0.210819  (0,0,1)→0.210819（与 (1,0,0) 打平）

## 2. 构造是怎么读出来的

按 TASKS2 的步骤 1，用 `code/worst_case_lp.py` 在 K=3、n=6、single-element 误差、η_u=η_o=√η 下解 η=1.5（段 j=2）与 η=2.5（段 j=1），并做第二阶段（固定目标值后 min / max ΣF+ΣG）取干净极点。读出来的结构与 N1 给出的 reduced LP primal 完全吻合：

- d_t：η=2.5 得 (1/6, 1/9, 1/9)，正是 q^0/k1, q/(Kη), q/(Kη)；η=1.5 得 (1/4, 3/16, 1/8) = q^0/k1, q/k1, q²/(Kη)。
- O 元素增益 G_t = q^{min(t,j)}/K 逐点吻合。
- **关键的结构观察**：LP 最优解里 f 在 B 上是 modular 的，而 O 元素的增益只被"前 j 个被选元素"打折（乘 q），后 K−j 个被选元素不打折。这就是把 greedy 集合拆成 C 与 P 两类、并让 P 元素的增益与 x 无关的动机。
- LP 最优面退化（pass1 的解甚至对 O 不对称），所以直接抄 LP 的数不行；上面的公式是对称化后的猜测，再独立验证。

作为 sanity check：K=2 时本构造的 f 与第一晚存下的全格点 LP witness（`results/k2_witness_instances.json`，η=1.25/1.5/1.75）**逐个元素相同**（max|diff| ≤ 4.6e−07，即该文件 6 位小数的舍入）；f̃ 不同（同一退化最优面上的另一个点），比值都是 3/(2(η+1)) = V_1。

## 4. tie 的必要性，以及 strict 变体

在这个实例里 greedy 的每一步都是 tie（对每个 j、每个 η 都恰好 K 个跨类型 tie，脚本记录在 `greedy_ties`）。这不是构造偷懒：

- 在 t ≥ j 的步上，误差带**强制**打平：预测值必须满足 d̃_{P} ≤ η_o·d_P 且 d̃_{O} ≥ d_O/η_u，而 primal 的 prediction 约束在最优解处取等（d_P = d_O/η，见 N1 §2 的紧/松表），于是 η_o d_P = d_O/η_u，两个界重合。任何达到 V_j 的实例都必须在这些步上打平。
- 在 t < j 的步上，本构造的 W(0)、W(1) 也被两个条件夹死（W(1) ≥ q·W(0) 与 W(1) ≤ (K−1)η_o/K 同时取等），所以这里的 tie 在本族内也是强制的。**注意**：这是关于本族的一段手推 [HAND-PROOF-UNREVIEWED]，不是"任何最优实例都必须在 C 步打平"的证明，后者未验证。

**strict 变体**：用 η′ < η 造实例（capped 版要求 η′ ≥ K−j），但把误差带按 η 声明。此时 f̃ 取

    W(0) = k1(η)/(K η_u),  W(y) = (K−y) η_o/K,  δ̃ = η_o · δ(η′)

（即 f 用 η′，带用 η），全部预测偏好变成**严格**不等式，误差仍恰为 (η_u, η_o)，比值为 V_j(η′) > V_j(η)。脚本在 6 组 (K,j,η) × ε ∈ {0.05, 0.001} 上验证：严格性成立、误差恰为 η、比值 = V_j(η−ε)，且 η−ε → η 时比值 → V_j(η)（ε=0.001 时超出量 ≤ 2.4e−04）。

结论：**对抗 tie 模型下 ρ_K(η) = min_j V_j(η) 且被达到；严格 tie 模型下同一个值是 infimum、不被达到。** 论文里如果不想引入对抗 tie，就把陈述写成 "for every ε > 0 there is an instance with ratio ≤ min_j V_j(η) + ε"。

## 6. 状态标签与诚实声明

1. **[VERIFIED-SYMBOLIC]**：Part C 的 44 条是关于符号 K, j, x, y, z 的精确 sympy 结论（精确有理算术）。与 N1 §4 同样的保留：把这些分支恒等式拼成"每个状态恰好落入一个已验证分支"的**有限分类枚举**是纯组合记账（x<j / x=j；y=0 / 1≤y≤K−2 / y=K−1 / y=K；z<K−j / z=K−j），没有代数内容，本身不是 oracle 验证的。Part A（K ≤ 6 全格点）与 Part B（K ≤ 8 精确算术）是这一步的机器化确认。严格表述：**"K = 2..8 完全 [VERIFIED-SYMBOLIC]；一般 K [VERIFIED-SYMBOLIC，模一次分支枚举]"**。
2. **本任务没有触碰** R6 的手证方向（"reduced LP 的每条约束对任意实例都有效"，故 ρ_K ≥ LP 值）。§0 的等式仍以它为前提，状态 [HAND-PROOF-UNREVIEWED]。它同时也是"n = 2K 足够"的理由：reduced LP 对任意 n 有效，所以 n > 2K 不可能更差；本任务没有独立验证这一点。
3. 只覆盖 η ≥ 1（模型本身如此）。
4. 实例的 OPT 唯一在 O 处达到（Part A 验证 max_{|S|≤K} f = 1 = f(O)）。
5. **f̃ 单调但不 submodular**（Part G 诊断，K=3,4,5 各点确认）：违反发生在 O 方向 y=0→1 与 y=1→2 之间。模型（`code/worst_case_lp.py`）只对 f 施加 submodularity，R7 的实例同样不 submodular（其 G 在 y=0→1 处也有跳跃），所以这不是本构造的额外弱点，但**它是一个真实的限定词**：如果论文的模型要求 f̃ 也是单调 submodular，则 ρ_K 可能更大，本任务不覆盖那个模型。这是明确的下一个问题。
6. 与 poly-query hardness（R9/R11）无关：本实例的基础集只有 2K 个元素，f̃ 对 pair 查询会泄露 O，和 R7 一样不是 poly-query 意义下的困难实例。

## 7. 空洞性检验（CLAUDE.md §空洞性检验）

对 §0 的定理陈述逐个限定词做检验：

- 去掉 "ties broken adversarially"：真值改变（严格 tie 下 V_j 不被达到，只是 infimum）。必须保留，§4 已写清差别。
- 去掉 "single-step"：陈述变成关于别的算法（R12 说 pair greedy 在 K=4 达到 ρ_2）。必须保留。
- 去掉 "n = 2K"：陈述更强（对一切 n），真值大概率不变但依赖 R6 的手证。保留，理由写在 §6.2。
- 去掉 "误差恰为 η"（改成 ≤ η）：真值不变但结论变弱（ρ_K 是"误差 ≤ η 的全部实例"上比值的 inf；实例误差恰为 η 是更强的陈述，说明这个界不是靠"实际误差比声称的小"骗来的）。保留。
- 去掉 "monotone submodular"（对 f）：真值改变（无约束的 f 可以更差）。保留。
- 去掉 "f̃ 不要求 submodular"（即改成要求）：真值未知，见 §6.5。这是唯一一个"说不清就不准用"的地方，所以在 §6 明写为限制，不写进定理。
- 去掉 "0 ≤ j ≤ K"：只取端点就退回 R2/R7，得不到 min_j V_j。必须保留。
